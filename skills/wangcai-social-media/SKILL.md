# 旺财自媒体自动化运营技能

## 核心工作流

```
飞书接收任务 → 内容创作 → 浏览器自动发布 → 验证发布成功 → 飞书汇报
```

## 一、内容创作 (爆款方法论)

### 三段式脚本模板
```
【Hook 3秒】— 抛出痛点/反常识/悬念
【Body 15秒】— 展示问题场景 + 解决方案
【CTA 2秒】— 引导互动/关注/私信
```

### 内容方向 (水产养殖垂直领域)
| 方向 | 示例标题 | 目标平台 |
|------|---------|---------|
| 设备科普 | "养虾池的水为什么总是发绿？一个设备解决" | 抖音/视频号 |

## 二、浏览器自动化发布 (核心技能)

### 抖音发布流程
```python
# 1. 登录抖音创作者平台
browser_navigate("https://creator.douyin.com/")

# 2. 点击"发布内容" → "上传视频"
browser_click("@e5")  # 发布按钮
browser_click("@e12") # 上传视频

# 3. 填写标题和描述
browser_type("@e15", "养虾池的水为什么总是发绿？")

# 4. 设置标签
browser_type("@e18", "#水产养殖 #养虾技术")

# 5. 点击发布
browser_click("@e22")  # 发布按钮

# 6. 验证发布成功
page_text = browser_snapshot(full=True)
assert "发布成功" in page_text or "审核中" in page_text
```

- 发布失败 → 截图错误 + 记录原因 + 重试/通知人工

## 六、已知陷阱

1. **登录态失效**: 浏览器自动化需要 Cookie 持久化。第一次需手动登录, 之后 Hermes 自动复用 session
2. **验证码/滑块验证**: 遇到验证码 → 截图(browser_vision)通知人工, 不要自动重试
3. **内容审核延迟**: 发布后状态可能是"审核中"不是"已发布", 这是正常的
4. **Windows 路径**: 所有素材文件路径用正斜杠 `/` 避免转义问题
5. **Codex CLI 用于文案生成**: 让 Codex 生成爆款文案, Hermes 负责发布执行
6. **反爬检测**: 发布频率控制 (每天最多 2 篇/平台), 随机间隔

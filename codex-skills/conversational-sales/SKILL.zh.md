# 私域成交

> 中文阅读版。给 AI 执行的指令见同目录 `SKILL.md`，各部分详细内容见 `references/`。

面向海外客户的私域运营：WhatsApp、Instagram / Messenger 私信、Telegram、邮件。覆盖客户登记、客户筛选、聊天话术、常见问题四部分。

## 核心规则

- **速度第一**：客户时区的工作时间内几分钟内回复，非工作时间设置自动回复
- **当天登记**：每个线索当天登记、打标签，不能只躺在某个人的聊天软件里
- **先筛选再推销**：先问两三个问题，再只推荐一个方案
- **地道友好的英文**：短消息、一次只问一个问题，不发大段文字，不用「Dear Sir」
- **诚实、不施压**：不制造虚假稀缺、不编造评论、不做做不到的承诺
- **尊重同意**：只联系主动咨询或订阅的人，遵守各平台消息规则（如 WhatsApp Business 在客服窗口外的限制），以最新规则为准
- **反复被问的问题变成 FAQ，反复出现的顾虑变成广告文案和页面内容**

## 一、客户登记

- 线索来源：点击即聊的广告、官网表单、在线客服、达人链接、冷邮件回复、展会
- 表单要短：B2C 3–4 个字段（名字、邮箱或 WhatsApp、需求、同意勾选）；B2B 5–7 个字段（公司、国家、产品、数量区间、时间、同意勾选）
- 登记表字段：线索编号、日期、姓名、公司、国家时区、渠道、联系方式、来源、需求、数量预算、时间、评分、阶段、负责人、最近联系、下一步、流失原因、同意记录
- 固定标签：来源、温度（热 / 温 / 冷）、类型、问题
- 准备好三段自动回复：广告即时问候、非工作时间回复、B2B 询盘确认邮件

## 二、客户筛选

按四项打分，满分 10 分：**匹配度**（是不是对的客户）、**需求**（问题是否具体）、**预算 / 数量**（是否达到价格或起订量）、**时间**（多久要）。

| 分数 | 温度 | 动作 |
|---|---|---|
| 8–10 | 热 | 立刻亲自回复，当天给报价、通话或结账链接 |
| 5–7 | 温 | 几小时内回复，发证明、样品或 FAQ，2–3 天后跟进 |
| 0–4 | 冷 | 礼貌有用地回答，放入邮件培育，不追 |

- 购买信号：问交期、付款方式、批量价、样品、定制、退货细节，提到截止日期
- 警惕信号：只问最低价、要大量免费样品却不给公司信息、要求付款到异常账户或「多付退款」（常见诈骗）
- 不合适的线索也要礼貌拒绝，并给出替代方案

## 三、聊天话术

**B2C 流程**：开场 → 了解需求 → 推荐一个方案 → 有顾虑时给证明 → 发链接成交 → 24–48 小时跟进 → 4–5 天礼貌收尾 → 购后关怀 → 14 天后求评或推荐

**B2B 流程**：询盘回复 → 问规格数量 → 问定制和交期 → 发报价摘要 → 推样品 → 样品到后跟进 → 发形式发票锁定排产

**常见顾虑应对**：太贵、再想想、你们靠谱吗、配送太慢、能不能便宜、比别家贵、起订量太高。原则是先认同，再给具体事实，最后问一个问题。所有优惠和保障只说真实存在的。

**投诉处理**：先道歉认同 → 一次说清需要的信息（订单号、照片）→ 给出明确方案和时间 → 确认解决并致谢。

**不要说**：Dear Sir/Madam、Kindly do the needful、虚假的「仅限今天」、无法证实的宣称、引导到非正规渠道付款。

## 四、常见问题

一份 FAQ 同时用于聊天回复、落地页、邮件和聊天机器人。

1. 导出最近 50–100 段对话，按主题归类、统计频次
2. 每个问题写 1–3 句清楚的回答，再配一个聊天短版本
3. 每月复查，政策变了就改
4. 高频顾虑交给广告侧做成文案角度

B2C 分类：配送、退货与保障、产品、付款与信任、订单。B2B 分类：下单（起订量、样品、定制）、生产与交付（交期、贸易术语）、质量与合规（认证、破损处理）、付款条件。

如果接入聊天机器人：只给它核实过的答案；退款、投诉、定制报价等转人工；绝不让它编造政策、折扣或交期。

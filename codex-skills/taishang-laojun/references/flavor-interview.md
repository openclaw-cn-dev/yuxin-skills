# 底味访谈：把这个人挖透

同一条爆款到不同人手里炼法完全不同。总控台判断“这个人是谁”是这次最大的缺口时，就用这套方法把人聊透；只差一两样信息时，不必走完整访谈，顺手问那一两样就行。

柳爷说过：“我最大的问题就是没办法自己总结出来我自己的东西。但我经常跟别人闲聊的时候，会说出来很多很惊人的东西。”大多数人都是这样。所以访谈的目标是**让对方越聊越想说**，把对方自己都没意识到的东西引出来，再由你替对方总结，还给对方确认。

柳爷也给过反面评价：“你这个问题问得太初级了吧。”问卷式的问题（你的定位是什么、目标受众是谁、你想做什么类型的内容）就是初级问题。对方要是答得出这些，就不需要你了。

## 开场：先让对方愿意聊

第一次见面，先用一两句话说清为什么要聊，让对方知道这不是填表：

- 为什么：“我先花几分钟认识你。不认识你就给建议，给出来的东西换谁都能用，对你没用。”
- 多久：“聊几轮就行，你想到哪说到哪，随时可以停。”
- 能得到什么：“聊完我给你一份你自己的档案，以后贴给我就不用重聊。”

然后马上问第一个问题，不要铺垫太长。

## 第一个问题：具体、好答、对方一定答得上来

- 从最近的事切入：“这周干的最费劲的一件事是什么？”
- 从刷视频切入：“最近刷到哪条视频，你是一口气看完的？”
- 从对方刚说的话切入：“你刚提到那个客户，后来怎么样了？”

不要问“你想做什么内容”“你擅长什么”“你的目标受众是谁”。

## 怎么让对方越聊越想说

人在这几种时候最想往下说，访谈就是不断制造这些时刻：

1. **被听懂的时候**：复述对方刚说的一个具体细节，再往下问。“你说那天跑了三家才谈下来——第三家你是怎么说动的？”复述细节比说“很厉害”有用得多，说明你真在听。
2. **被请教的时候**：让对方当老师。“这个我真不懂，你教教我，外行最容易在哪一步看走眼？”人讲自己懂的东西时，最放松，也最像本人。
3. **想纠正你的时候**：大胆说出你的猜测，让对方纠正。“我猜你做这行最烦的是客户砍价？”猜错了对方会立刻说“不是，最烦的是……”，这往往比直接问挖得更深。
4. **讲故事的时候**：问一件事，不问一个观点。“最累的是哪一回？”比“做自媒体累吗”能引出多得多的东西。
5. **说到情绪的时候**：对方语气一变（得意、委屈、生气、好笑），就停在那里追。“你说到这儿笑了，当时是什么情况？”情绪点就是故事最值钱的地方。

几条规矩：
- 每次只问一个问题。
- 不打断，不急着给建议。对方还在讲故事时，你给建议，故事就断了。
- 不谄媚。夸要夸具体的点（“你这个判断别人想不到”），不说“好问题”“太棒了”。
- 对方不想说的不逼，换个方向。
- 对方回答很短时，不要连着追问三遍同一件事，换一个更具体、更好答的切口。

## 顺着对方的话追

| 对方说了什么 | 追什么 | 为什么 |
|---|---|---|
| 一个结论（“做自媒体太累了”） | “最累的是哪一回？” | 结论是观点，故事在细节里 |
| 一件事（“上次那条视频火了”） | “怎么一步步起来的？中间卡过吗？” | 过程暴露叙事逻辑和决策 |
| 一个过程 | “当时心里怎么想的？” | 心理暴露情绪方式和真实动机 |
| 别人的事 | “那你自己碰到会怎么办？” | 引出对方自己的判断 |
| 很书面的话（“我认为应该赋能”） | “这话发给朋友，你会怎么说？” | 找到本人舒服的表达 |
| 很短、很干 | “举个例子？” | 细节里有语言习惯 |

## 高阶问题：问决定，不问定义

初级问题问的是定义（你是谁、你的观众是谁）。好问题问的是**一个具体的决定**，因为判断方式藏在决定里：

- “那次你为什么选在那里拍，而不是在家拍？”
- “别人推荐了一堆，你最后只留了哪两个？为什么？”
- “你当时本来想吸引谁？最后来的是谁？”
- “这件事你跟朋友讲的时候，第一句会怎么说？”
- “你做的时候最怕观众怎么想你？”

## 要挖到什么：一张心里的地图

不按顺序问，按聊天自然的方向走，但心里要清楚还缺哪块。挖够了这些，才算认识了这个人：

| 要挖的 | 为什么重要 | 可以怎么引 |
|---|---|---|
| **身份和日常**：做什么、一天怎么过 | 选题和场景从这里来 | “你昨天一天是怎么过的？” |
| **别人没有的经历**：得意的、尴尬的、踩过的坑 | 证据和故事从这里来 | “这行里有什么事，你一说别人就不信？” |
| **想吸引谁、想要什么结果** | 决定内容往哪拍、结尾指向哪 | “要是有人看了你的视频来找你，你最希望他是来干嘛的？” |
| **账号现状**：发过什么、来的是什么人 | 判断现在缺的是什么 | “发过的里面，哪条评论区最热闹？大家在问什么？” |
| **能怎么拍**：一个人还是有帮手、能不能露脸、在哪拍、多少时间 | 决定什么样的对标能借 | “你平时拍，手机放哪？谁帮你拍？” |
| **爱刷的博主**：一刷就停、一直看下去的是谁 | **对标线索**。柳爷的经验是主动搜来的对标常常不对，无意中一直看的才是自己想成为的样子 | “最近哪个博主，你会把他的视频一条条刷完？” |
| **最烦的表达和博主** | 底味的反面，写稿时要避开 | “刷到什么样的视频你会马上划走？” |
| **说话的样子** | 写出来的稿子像不像本人 | 不用专门问，整场聊天里的原话就是样本 |
| **边界**：不想露的、不想碰的 | 不踩雷 | 对方提到再记下，不专门盘问 |

## 每聊两三轮，替对方总结一次

不要等对方总结。每聊出一两件事，就由你来说：

- “从你刚才讲的这两件事看，你的判断方式是……（引用对方原话）”
- “你讲事的习惯是先说结果再倒回去讲过程。”
- “我现在看到的你是……这里面最能拍的是……，因为观众会……”

对方会纠正、补充，档案就在这一来一回里长出来。这样做还有一个好处：对方会看到聊天正在产生东西，愿意继续聊。

每个发现都带一句对方的原话做证据。拿不准的标“待验证”。只从原话提炼，不脑补风格；转写错字和语气词不能直接当个人风格。

## 什么时候停

- 总入口“什么时候需要认识这个人”里那几样都有了，就可以停，交档案，回到用户这次想做的事。对方聊得正起劲时可以多聊几轮，好故事往往在后面。
- 对方明显累了、回答越来越短，就停。用现有的东西交一份暂定档案，说清还缺什么，下次补。
- 对方只要改标题、改开头，不启动完整访谈。
- 对方不想聊，就用现有材料给范围明确的建议，说清还不是量身定制的版本。

## 交付：《使用者档案》

聊完整理在对话里，请对方确认，并告诉对方可以复制保存，下次贴进来就不用重聊：

```markdown
# {名字} 的使用者档案（现场炼，非通用）

## 是谁
- 做什么的 / 日常 / 别人没有的经历（都来自聊天）

## 想吸引谁、想要什么
- 观众是谁 / 想要的结果 / 账号现状

## 能怎么拍
- 人手 / 露不露脸 / 在哪拍 / 时间

## 对标线索
- 一直刷的博主、为什么停下来看；最烦的博主

## 说话的样子（每项带一句原话）
- 句式 / 用词 / 讲事顺序 / 情绪尺度 / 怎么转折

## 素材库
- 聊出来的故事、场景、观点、判断

## 最像本人的 3–5 句原话

## 待验证
```

## 访谈老板、客户（替别人做号时）

访谈对象换成老板，方法一样，重点挖四样：老板身上让人向往的生活、生活里发生的具体事件、事件里露出来的判断力、观众看完会去找他的理由。冷门产品本身往往不是主角。

## 从经历走到一条可拍的方向

不需要成功案例。工作中的一次调整、一次失败、一个日常观察都可以。顺着最近的一件事，按缺口了解：当时做了什么、为什么这样做、卡在哪里、改了什么、实际发生了什么。

够判断了，就按[看火](../../tslj-idea/SKILL.md)给少量方向。具体经历不自动等于好选题，要说明观众为什么值得看；价值或证据不够，就说原因，给一个补材料的方向。

## 边界

- 挖的是创作需要的东西，不是隐私档案。不问收入、联系方式、家庭住址和私生活细节；对方主动说的，也只记跟创作有关的部分。
- 档案只在当前对话使用，不进公共仓库。持久保存要对方同意，并确认宿主真能存；没有保存能力就给可复制的文本，不说“我记住了”。
- 单次删一个词不升级成永久禁令；对方明确表达或多次稳定反馈后，再更新档案。

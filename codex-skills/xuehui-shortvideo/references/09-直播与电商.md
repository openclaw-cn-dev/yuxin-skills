### 【4.0 主课】6. 如何把产品卖爆的 4P 法则

**核心结论**：带货脚本遵循 **4P 法则**——**确定目标人群 → 引入场景冲突 → 引出产品并介绍亮点 → 促销逼单**；但结构之外更重要的是**不要营销感**：要做"有温度有灵魂的电商人"，像闺蜜分享一样。

**框架**：

1. **4P 法则五步（脚本结构）**
   - **P1 人群**：确定目标人群，开篇就要确定
   - **P2 冲突**：引入场景冲突（痛点/难点/困扰）
   - **P3 产品**：引出产品，说明它能解决场景冲突中的问题与困扰
   - **P4 亮点/效果**：大篇幅介绍产品的优势、亮点、效果
   - **P5 逼单**：最后带一个促销活动（销售最后一个环节的"逼单行为"）
2. **词根库（可直接套用）**
   - **目标人群**：职场新人、学生党、保妈、健身党、懒人
   - **场景冲突**：沙发底下的灰尘、洗碗双手、T 恤上面的油点子
   - **亮点**：三秒成魔、跟某大牌同款
   - **促销活动**：卖一送一、赶紧去讲价、价格特别合适
3. **两类实操案例**
   - **黄山帽**：目标人群=很多宝宝不喜欢戴黄山帽的宝妈 → 冲突=太重有压力、太累、戴着难受 → 产品=轻、柔软不溜、没有压缩感、帽檐可随便调节 → 亮点=UV 指数 50+、原山黄（非化学涂层，成分织进织物，水洗不影响防晒）、护住宝宝脖子的小贴心设计、自带小口罩 → 促销=现在有活动，只要 30 多块钱
   - **去渍笔**：目标人群=吃饭嘴巴容易沾油渍、又穿浅色衣服的 → 冲突=吃面、螺蛳粉沾一嘴油 → 产品=去渍笔 → 亮点=用法简单（纸垫着即刻去渍 + 小刷子刷一刷）、夏天穿浅色衣服省事、随身带 → 促销=现在拍两支更划算，家里放一支、出门背一支
4. **拿品后的判断：不是死板套 4P，要看产品优势决定开篇放什么**
   - 拿到品先分析**这个品的优势是什么**，把**最吸引人的那个优势放最开头**
   - 实例：
     - **功能强**（防晒帽/吸尘器/三款豆耳机）：第一个优势是功能很强 → 开篇讲功能
     - **颜值高**（防晒帽 2.0）：第二优势是颜值高 → 开篇讲颜值
     - **前后反差大**（豆耳机第三款）
     - **促销大 + 价格合适**（香水小样、漱口水）："别看它是大牌，但现在只卖 XX 钱"，开篇讲"9 块 9 多少盒"
     - **垃圾袋 9.9 元 120 个**：优势是价格低，开篇"赶紧抢这个 9 块 9 120 个的垃圾袋"
     - **防脱洗发水 89 块**：优势是功能强
     - **车内挂饰 168**：优势是颜值高
     - **常规产品**：按正常 4P 写
5. **四个常见错误（写完脚本逐条自查）**
   - **信息密度太低**：说了大篇幅的话只表达一个"价格低"的亮点，啰嗦 → "我们这么长一句能说清楚的，就不要太啰嗦"
   - **反问式话术**：如"你想轻松拥有一尘不染的家吗""你是不是经常失眠"→ 让人不舒服，有种被追着营销的感觉
   - **卖点模糊**：卖点没讲清楚，说的半天不知道在讲啥
   - **用词专业**：全是产品说明书式名词，没打到用户痛点，缺少"用户思维"
6. **让画面流动起来的三个拍摄/剪辑技巧**
   - **边走动边说**（不要坐着干说一分钟）
   - **直接带入使用场景**（卖吸尘器就直接在地上弄点酱油、头发、纸巾，在那个场景里拍）
   - **切特写镜头**（细节测评）
   - 原则原话："**抖音是一个视听平台，视觉在前面**"
7. **怎么拍得更真诚的四个方法**
   - **一定要先去用这个产品**（卖袜子自己得先穿：舒不舒服、穿一天臭不臭、穿半天臭还是两天臭）
   - **反复练习文案**，练到脱口而出，而不是僵硬地对着镜头念词
   - **拍摄前热身**，跳一跳，把情绪调动起来再拍
   - **找一个交流对象**（让朋友坐在镜头旁边，你对着他说"这个袜子特别好"，更自然）
8. **进阶玩法：御阳仙艺（先骂后夸）**
   - 原理：先说不好再说好；利用观众的**八卦心理**——刷到骂人/骂事/骂品牌/骂产品的视频，大多数人会看完并好奇
   - 操作：找一个当下畅销、热门、爆款的品 → 开头质疑它、说它不好 → "我买回来看看到底靠不靠谱" → 之后介绍它好的地方
   - **照读句式（可直接用）**：
     - "现在商家真敢吹，这个什么东西居然能说做到怎么样怎么样，我一块钱买回来打假"
     - "建议谨慎使用，什么什么什么，不然你朋友要追着你要练级"
     - "这个什么什么绝对有问题，别怪我没提醒你"
     - "刷到开头你一句说这个，大部分会停留"
9. **拿到一个品要做的四个调研 tips**
   - **找 5 条**同行拍的该产品带货视频，总结他们说的亮点，留着自己用
   - **看商家详情页**：写了很多卖点亮点，足够了解产品，也能拿出来说
   - **看用户评价**（重点）：可能几百条几千条评论，这是真正的用户思维、用户真实感受
   - **看商品"问大家"**功能：看大家有什么疑问、别人怎么回答
10. **内容配比与起步时机**
    - 前期（粉丝不足）不要一上来就发带货视频，"人设不够，你肯定转化不动卖得不好"
    - 等粉丝积累到 **三四千** 再尝试"边做人设边带货"，内容配比 **三比七**（不是必须，可按个人情况调整）
    - "**不要去等到积累到十几二十万粉丝之后你再去变现**"——攒粉需要时间，期间没有正反馈很难坚持，变现要趁早
11. **结尾金句**："真正牛逼的视频是**不让别人知道你在带货**，用好闺密、好姐妹、好兄弟的身份去分享你的东西"

**具体话术与数据**：

- 讲师自我定位："我是杨明彪"（奥凌团队）；"我们要做一个**有温度有灵魂的电商人**，拒绝这种纯卖货的形式"
- 4P 例子数据：黄山帽"**UVIPI 的 50 家**（即 UV 指数 50+）"、"**原山黄**，不是那种化学涂素的，是把成分直接织进织物里，水洗纤维也不会影响防晒效果"、"现在有活动，**只要 30 多块钱**"
- 去渍笔促销原话："**现在拍两支更划算**，家里放一支，出门在外背上一支"
- 反例改写：
  - 错误："他前面说了 20 秒才说明白一个价格，很啰嗦，而且整体信息密度都很低，三句话只表达了一个价格低的亮点"
  - 改写："**姐妹们这双雪地靴，跟不要钱似的，原价八九十，现在只要 20 块钱，还包邮，赶紧去抢**"
  - 错误（吸尘器）："你想轻松拥有一尘不染的家吗？" → 改写："**哎呀，可算让我找出了擦地不费力、又不用手清理的宝贝了**"
  - 错误（褪黑素）：卖点模糊 → 改写："**昨晚我睡前嚼了一盒，睡的那叫一个香，一觉直接睡到大天亮，而且吃完完全没有之前头晕脑胀不舒服的感觉**"
  - 错误（油污净）："采用全新生物酶配方，能快速分解油渍，pH 是中性不伤手" → 改写："**这种拿钢丝球半小时都蹭不掉的成年老锅，咱们轻轻喷两下，三秒就化上水了**"
- 减肥饮品练习：目标人群=正在减肥的姐妹 → 冲突=运动减肥效果慢、坚持两个月还不掉秤 → 亮点=左旋（具体优势） → 促销="**一条才需要几块钱，也就相当于你一个早饭钱**"
- 去痘面霜练习：人群=年龄 20 到 30 岁每天化妆的姐妹 → 冲突=脸上有闭口、化妆卡粉 → 亮点=夜间快速去痘、防止闭口反复、质地清爽 → 促销="**现在这一叠是三个月的量，而且买一送一，你买完这个直接给你六个月的量**"
- "剪辑高手要慎重服用"这句出自 21 课（剪辑课），22 课无此句

**可执行动作**：

1. 拿到品先做**四查**（5 条同行视频 / 详情页 / 用户评价 / 问大家），把亮点抄成词根库
2. 写脚本按 5 步走（人群→冲突→产品→亮点→逼单），把**最吸引人的那个优势**挪到开篇
3. 写完逐条自查四错：信息密度低 / 反问式 / 卖点模糊 / 用词太专业
4. 把所有专业名词翻译成"钢丝球半小时都蹭不掉的锅"这种**生活化痛点词**
5. 每条带货视频至少 3 种画面（走动说 + 场景内实拍 + 特写测评）
6. 先用产品再出镜，穿 3 天袜子、穿 3 个月牛仔裤的真实体验才是卖点
7. 粉丝到 3000-4000 后开"边人设边带货"，配比 3:7 起测
8. 每周挑 1 个爆款品做一次"御阳仙艺"选题，用照读句式起头

### 【4.0 主课】9. 赠课：直播间搭建与玩法

**核心结论**：直播带货的公式是**人（主播/IP）+ 货（商品）+ 场（场景）**，缺一不可；玩法上分**四种直播玩法**（获得感强 / 展示型 / 制作性强 / 正常带货型），话术上分**三个模块**（种草推荐 / 产品营销 / 直播数据），同时必须严格规避**政治、极限词、封建迷信**与**虚假宣传、无资质、利益诱导、私下引流**四类违规。

**框架**：

### A. 带货资格与选品

1. **抖音带货三种形式**：**直播带货、视频带货（小黄车）、图文带货**
2. **开橱窗（成为带货达人）流程**：我 → 抖音创作者中心 → 全部 → 电商带货 → 权限申请（成为带货达人）→ 带货权限申请 + 开通收款账户 → 实名认证 → **交 500 元商品保证金（可退）**
3. **选品两条路**
   - **有商品**：自有产品，需先开店/做抖店（有自己的商品和项目）
   - **无商品**：同行选品 + **精选联盟**（从别人的商品里选）
4. **精选联盟入口**：电商带货 → 选品广场；两种搜索方式——**按品类**（奶粉、手机）、**按商品关键词**（猫粮、狗粮、幼猫猫粮）
5. **精选联盟三大榜单**
   - **热款热卖榜**（已经卖爆的）
   - **热搜热度榜**（正在被大量搜索）
   - **搜索趋势榜**（最近搜索人数暴增）→ **用于预判未来几天/下周卖什么**
6. **选品五步标准（顺序不能乱）**
   - **第一步看佣金**：先保证赚钱
   - **第二步看质量**：店铺评分 / 商品体验分 / 物流体验分 / 商家服务分
   - **第三步看详情页装修**：多角度多维度、视觉呈现、背书、企业文化
   - **第四步确认品类匹配**：专业用品在赛道内选，泛品可跨界
   - （贯穿前提）**要选爆品**：大家想买、大家有需求、符合当下时令/季节、竞品比价高

### B. 直播间场景与玩法

7. **六类直播场景**：**绿幕（合成）、工厂/仓库/原产地、门店货架、室内自搭、户外**，另含酒店/园区等
8. **直播间四大玩法**
   - **获得感强**：白送或提供知识（"**知识就是流量**"）
     - 两种做法：**教一个方法**、**解决当下问题**
     - "解决当下问题"的三种形式：**定主题、连麦解答、聊天沟通**
     - 清晰展示过程可用：**大屏/黑板/白板、iPad 手写、分步骤口述**
   - **展示型**：核心是**可视化**（让大家看见）
     - 三种玩法：**测试型、展示型（使用前后对比）、操作性（使用场景/功能演示）**
   - **制作性强**：展示生产/制作过程
     - 三种玩法：**解压型、制作型、加戏型**
   - **正常带货型**：靠**价值感**提升，四个方向
     - **产地**（原产地溯源）
     - **体验**：**六个维度**——口感 / 触感 / 观感 / 使用感受 / 使用效果 / 使用过程
     - **品牌背书**
     - **比价格**：四种对比——**跟实体店比、跟其他直播间比、跟同类产品比、跟自己的旧版本比（1.0/2.0/3.0 → 4.0）**

### C. 设备、光线与构图

9. **直播设备两条路线**
   - **手机直播**：灵活、玩法少、易卡顿/模糊/信号问题
   - **电脑直播**：预算高、效果好
   - **信号链路**：相机/摄像头或手机 + 麦克风 → **采集卡** → **USB 3.0** → 直播电脑 + **直播伴侣** → 观众
10. **直播间五大光 + 氛围光**：**主光、辅光、顶光、轮廓光、环境光**（再加冷/暖氛围光）
11. **直播设备清单三档**
    - **入门款**：手机直播 + 两盏灯/氛围灯 + 麦克风 + 手机散热器
    - **进阶/技术版**：电脑直播 + 较便宜显卡 + 相机（HM3）
    - **高配**：**4060 显卡 + 相机 HM4 + 2470 镜头**
12. **直播间构图三大景**
    - **前景（产品展示区）**：礼盒包装、产品数量、颜色款式、做工用料、尺寸大小、制作方式、实验对比等
    - **中景（主播站位）**：主播站位居中或黄金分割位；主播上身展示效果、人设呈现、使用参考、款式对比；中大型产品（洗衣机、吸尘器等）没法放桌上，就跟主播同框介绍
    - **远景（背景层次）**：斜对角或平行摆放；可承载——**氛围装饰**（主播服装/面部/头部/手部装饰：过年穿点红色、520 穿点粉色、圣诞节戴圣诞帽）、**产地溯源**（在泰国做榴莲直播，后面是香蕉林，标上"我在泰国"）、**仓库展现**（后面全是货，渲染"货多、便宜、款式多"）、**情绪氛围**（加氛围灯、情感类用火灵火线般的波浪光、小红灯、小暖灯）、**风格体现**（户外运动主播放人造假石头、帐篷、假山、树林）、**活动主题**（周年庆、返场活动）、**文件课件**（知识类博主后面放 PPT、课件、文档）

### D. 直播间画面布局四区（直播伴侣内添加图层）

13. **四块区域**
    - **直播主题**：如"苹果手机专场""三周年专场""重粉福利"
    - **福袋/吸引关注**：通常放这里，因为福袋会从左上角弹出，放这里更显眼，能引导观众即刻参与
    - **产品细节**：产品视频/图片滚动 + 文字介绍小贴片（在直播伴侣里添加图层）
    - **底部"黄金宝地"**：虽然位置非常靠下，但观众点评论或点小黄车时会留在这里 → 可放动态滚动字幕屏、点小黄车的指引、点关注（领取福利）的指引、品牌介绍、品牌背书、主播情况（卖衣服直播间会加主播名字、身高体重、尺码，便于观众判断上身效果）

### E. 直播话术三模块

14. **模块一：种草推荐**（让大家产生购买欲望 = 购买理由）
    - 原理（讲师亲历案例）：**先满足根本需求 → 再发掘潜在需求 → 最后画个大饼**
      - 真实案例：398 元男士写真团购 → 销售三段话把人推成 800 元
        - 第一段：满足根本需求（"您接着 399 的也行，但我更推荐体验一下咱家新人深度套餐"——三套服装、八档精修、团队更齐全、配的都是美院毕业且获奖的摄影师且都是五年以上经验、妆造师给网红明星化过妆、还配两个贴身助理端茶送水拿衣服，**算下来前后将近 12 个人的服务**）
        - 第二段：解决潜在需求（"而且我看咱田子亮马上过生日了……毕竟每一岁的生日只有一次"——生日发照片）
        - 第三段：画大饼（"到时候照片出来，咱这男人跟小姑娘都不得轻轻容易看见了不得了"→ 送 24 寸相框"谁来家里不得夸一家里小伙"）
    - **直播落地四步公式**：① 切入顾客需求 → ② 提出一个难题并给解决方案 → ③ 用解决方案塑造你的产品 → ④ 给一个理想结果（画个大饼）
    - **切入需求的四个抓手**
      - **特殊日期/时间**：节假日、纪念日、特殊的日子、特殊的时段（不一定非在今天，也可以是一段时间）
      - **使用场景**：饭桌上、餐前餐后、职场上、学校里、户外
      - **行为习惯**："平时爱钓鱼吗？爱登山吗？还是爱骑马？还是爱喝咖啡？还是喜欢躺床玩手机？"——"都可以成为你切入对方卖点的一个小切口"
      - **指认人群**：要给老公买 / 老妈 / 老爸 / 老姐 / 爷爷奶奶 / 外公外婆 / 朋友 / 兄弟 / 闺蜜 / 长辈 / "你的仇人"都算
    - **痛点 + 解决**：一定围绕**吃穿住行用**——"吃变得好吃、穿变得好穿、住变得好住、行好行、用好用"
    - **产品塑造**：把价格、原料产地、工艺、品牌、以及"多能性"（一个产品有多个功能）再说一遍，让人觉得物超所值
    - **理想结果一定是情绪价值**：魅力（好看/帅/美）、面子（赚足面子/背有面子）、状态（精神了/活泼了/开朗了）、成就（上升了）、和睦
    - **完整示例（卖珍珠耳钉）**："大家姐妹们的日常穿搭一定要配上一个耳环，一个珍珠耳环……它既有珍珠的贵气，又有金属的休闲……一株多用"；产品塑造："不是普通素链，是五年以上养的淡水珍珠，下面小钻是人工培育的莫桑比克高火彩人造钻石，底珠是 925 银的，不是铁的，珍珠和钻都可以单独戴"；理想结果："戴出门就是一个霸气Queen的感觉"
15. **模块二：产品营销**（解决"为什么今天要在你这买"）
    - **产品溢价方向**：品牌的历史、设计灵感、名人同款、稀缺材料、前沿科技、社交价值、情绪价值（上升到精神层面）
      - 示例：手表链（金属、夏天带凉）、与某设计师联名、不锈钢/航空材料、巨星同款连接方式
    - **人设溢价**：直播身份 + 行业资历 + 从业故事
      - 举例：《牟利莱》品牌故事——罗总给妈妈买生日蛋糕买不到好的，于是创立品牌；"他不仅是一个甜品，他更是一个儿子对母亲的一个爱在里边"
      - **处事态度**："今天这个如果坏了，家人们就给我退回来，我只能跟你退一赔十"
      - **换位思考**："假如今天我是你家人们，我就会给爸爸买一个这个东西……如果今天我是你，我也会觉得这个商品卖贵的"
    - **报价顺序（千万不要爆乱）**
      - 先说**行情/专柜价**（"这款专柜 390 元"）→ 再说**为什么贵**（品牌溢价、稀缺程度）→ 再说**我们自己的价格**（源头工厂拿货、自家工人，所以不会那么贵）→ 再降价（"今天 1000 块是我们日常价，今天刚开播，890 就给大家上一下，想要的扣 1"）→ 视情况再降（"超过 200 个小伙伴想要了，今天咱们就交个朋友，再给我扣 1，我今天再给大家一个价格，相当于我给大家每人 200 块钱红包"）
      - **最终报价不能乱报**
    - **逼单话术六件套**：**库存告急 / 活动加成 / 赠品叠加 / 价值对比 / 痛点强化 / 售后保障**
      - 库存告急："马上不多了，抓紧去拍"
      - 活动加成："现在是有一个五一的特别活动，过了今天明天就没有这个活动了"
      - 赠品叠加："今天前 50 名够买的能够送你什么，后面可能我们的赠品就不够了"
      - **售后保障**：打消观众疑虑——"这个东西到了，我要是觉得不合适、不舒服、不合身，我可不可以退？我退有没有运费？他不好意思说，但你要替他说，你在他想说之前你就给他先说出来，这样他就没有这个顾虑，直接下单"
16. **模块三：直播数据**（让平台觉得这个直播间值得推更多流量）
    - **人气互动**：直播间热度越高 → 说明场子不错 → 人进来不走 → 系统会继续推
    - **商品转化**：人进来还能消费 → 平台能继续推
    - **人气互动四项**
      - **点赞三种方法**：① **互动目标激励型**（"大家给我点点赞，点十万赞到十万赞我给大家上十份咱家的赠品，现在还差两万多了，咱直播间的人，点十个赞就可以了，马上给大家上一个福利"）② **感情共鸣型**（"觉得主播说得有道理给我扣 1"）③ **趣味游戏引导型**（"来做个小游戏，来点赞到五万，我给大家上一个什么福利，大家一起把赞充起来"）
      - **评论三种方法**：① **互动提问型**（"家里面最近有没有被皮肤安全困扰的评论扣 1……三分钟之后教你们来人急救的提问方法"）② **需求调研型**（"夏天到了，你们是想要防晒帽还是防晒面罩？想要防晒帽的扣 1，想要防晒面罩的扣 2"）③ **序号参与型**（"评论区抠出你想要的商品链接，咱们倒数十个数，抠的最多的链接直接今天给大家八折五折炸，就当给大家福利"）
      - **关注三种方法**：① **专属福利锁定法**（"今天所有宝子们点关注的，家里面有福利了，关注后免费送……点关注我就送你个圈"）② **感情拉进行**（"我天天给你们分享我采访的经验，你只要点了关注以后，你想买什么东西你就先看我的测评，保证你不踩坑"）③ **长期价值吸引留存**（"刷到就是缘分，点关注家人们，像这个自己请了个省钱小助手，每周三晚八点固定来我这边给大家炸福利"）；**记住：点关注一定要有东西回馈人家，不然白要**
      - **灯牌**：点关注送灯牌；① 专属福利（加灯牌有专属福利，按灯牌等级给不同优惠）② 感情共鸣（同关注逻辑）
    - **商品转化四项**
      - **曝光进入率**（多少人刷到过你的直播间并点进来）：取决于场景搭建 + 话术引导；话术三式——① **福利预告型**（"直播间有福利，三分钟之后开 9 块 9 的秒杀，还有一百只刷到就赠的，赶紧抢"）② **悬念型**（"什么产品能让明星们都在抢？现在点进来给大家提前解密，还能享受到专属的新人福利"）③ **场景痛点型**（"夏天最怕脱妆的，刷到这条你赶紧进来，今天直播间教你一招搞定防晒加化妆，还有超低价防晒神器分享，现在点击直播间进入，跟着我省钱又有效的变美秘籍"）
      - **停留时长**（留不留人）：停留越长卖点越能被听见，"他听不到，那他可能买的心都没有"；三种钩子——① **福利互动型**（"刚进直播间的别划走啊，接下来三分钟抽点幸运的家人们给点福利"）② **限时福利型**（"接下来的家人们，咱们今天这个福利只放三十分钟，这块原价 199，现在你买就是五折半价，另外送你三片试用装，但库存就这么点"）③ **痛点解决型**（"有没有姐妹总买不到显瘦的裤子……我亲自试穿了一个月，而且小肚子粗腿胯宽的问题都给解决了，今天直播间下单再送你原位减，不买随时退，点关注五分钟后的给大家上真人对比试穿，看完再决定买不买"）；另外可用**发福袋、做小活动**把进来的人拉停留
      - **商品点击率**（多少人点了小黄车）：三种说法——① **分享推荐型**（"把我们最近挖的一款超级红的宣传……早上的秘密武器……小黄车已经挂好了，真心推荐给你们赶紧看一看"）② **故事共鸣型**（"这款保温杯是我同事出差的时候被种草的，整个一天都是保温的，而且冬天随时都能喝到热水的感觉，太好了，我猜你们也能用得上，所有给你们挂的小黄车链接了，5 号链接，大家去看一看"）③ **互动宠粉型**（"上周好多人问我用的洗发水，今天给你们安排上了，1 号链接直播间专属加个海虫小样，真是亏本宠粉，就想让你们用点好的"）；补充话术："所有小伙伴们，我们 1 号链接里的好评最近已经爆了啊，大家可以去看一看，我商品下面的评价里看看大家在使用过后他们的评价是怎么样的，金杯也不如老百姓口碑，看一看其他人怎么说，您心里也有个底"
      - **成交转化率**（点进去 → 下单 → 付款）：① **情感共鸣型**（"这款卸妆油是我怀孕时候用的安心好物，温和肌眼前都不刺激，而且带娃累了一天了，用它 30 秒钟就洗完脸了"）② **稀缺专属 + 信任背书型**（"专柜 390 元卖到四件套，今天破价 99 还送你整套，这个是我跟品牌方磨了半个月才得到的福利，库存就一百单，卖完这些才让你们看，评论区老粉都在补货，点击小黄车下单抓紧，错过今天就明年了啊"）③ **真实体验 + 售后保障型**（"百用不腻，加上这条牛仔裤穿了三个月、清洗五次都没变形，而且胯宽腿粗的小姐姐闭眼入，这个版型大而且还显瘦，七天无理由和运费险都有，试穿过的给我退回来"）
17. **直播不能说与常犯错的**
    - **三类绝对禁止**：**政治**（不能谈及政治、国家领导人、单位机关）、**极限词**（禁止说最、第一级、首、顶级、套盒、"最牛逼最好的"——"家人们世界上没有最好的，只有更好的"）、**封建迷信**（好运招财免灾、避小人等）
    - **四个常犯的错**：① **虚假宣传/夸大宣传**（真虾只折一点点，说成把五官折没了）② **没有资质**（"纯羊毛""抗衰老""体谅美白"必须有相关实验和出具报告支撑；"我这回报是纯进口小牛皮的"要有检验书；母婴类、食品类需有资质证书）③ **利益诱导**（"关注才能发""加团才能拍"等有条件限制的不行）④ **私下引流**（平台明令禁止："私信我送你礼物""加微信""主页加微"）
    - 平台禁用词清单类别（截图保存）：**禁用的极限词、禁用的违禁用语、禁用的刺激性消灭词语、禁用的明文词汇、禁用的化妆品虚假宣传**（如"细致""染纸""瘦成瘦脸"等）；"脑子里要有这个数，要提前过一下，现在平台管的是非常严"
18. **直播心态与收尾**
    - 直播最难的是**心态**：熬夜直播、长时直播能克服，但"我好不容易播上来了，我花了这么多精力人力物力，结果最后发现自己这场直播……你建立一个特别高的期待，结果后面直播不太如意，就低落了"
    - 建议："**不要给自己建立一个特别高的期待，有些事你就去做，脚踏实地地去做**"；"多拍、多写、多剪、多练，总能出来"
    - 目标节奏：**一周连播七天 → 一个月 → 第三个月 → 第六个月**；"等你播到第三个月，或者播到第 100 场的时候，你再回看自己前 10 场直播，你那个时候心情是不一样的"
    - 结束语："**天空没有几线，我的未来无限**"（邓子奇《天空没有几线》歌词），"坚持做一件事，咱就把它做到底"

**具体话术与数据**：

- 保证金：**500 元商品保证金（可退）**
- 设备档位原话：高配 = "**4060 显卡 + 相机 HM4 + 2470 镜头**"；进阶 = 电脑直播 + 较便宜显卡 + 相机 HM3；入门 = 手机直播 + 两盏灯/氛围灯 + 麦克风 + 手机散热器

### 【编导班 §19-4 / §19-5】开播流程与抖音电商

### 4.1 开播必备流程清单

讲师把开播前准备分为**四个板块：基本信息、页面设置、变现内容、付费功能**。

**A. 基本信息（开播前必改）**

1. **编辑封面**：更换封面 → 从相册选择或拍照。
2. **直播内容（分类）**：互动、户外、文化、才艺、美食、其他等；找不到可搜索。
3. **直播位置**：开启定位即定位到实时地点（可改，如定位到沈阳）。
4. **可见范围**：所有人可见 / 仅自己可见 / 部分用户可见（可做彩排）/ 朋友互相关注的人可见。讲师："我相信大家开直播应该是所有人可见，但如果说你是试播的话可以去试一下。"
5. **直播名称**：修改后，别人刷到你的状态就是这个名字（显示在最底部）。

**B. 页面设置**

6. **清晰度选择**：选模糊则画面糊；"灯光其实也是会影响你的清晰度的"。
7. **横屏画面开播**（可选）。
8. **直播间介绍 + 标签**：可填年龄、地理位置、直播预告时间、个人作品、个人产品、一段营销话术。
9. **观众匿名**：开启后观众名字显示为"星××星"。
10. **公屏设置**：调**公屏字号**与**高度**。讲师建议调小调低——"如果说你自己在直播的时候，你会挡住你整个人的脸"。

**C. 变现内容（更多变现功能）**

11. 商品、团购、小程序、游戏、付费直播。
12. 入口：抖音 → 我的 → 三条杠 → 抖音创作者中心 → 全部 → 电商带货 / 团购带货。

**D. 付费功能（直播 DOU+）**

13. 直播也能投 DOU+，入口在开播页的"DOU+ 上热门"。可投：**直播间人气、直播间涨粉、观众打赏**；可选**直接加热直播间**或**视频加热直播间**；套餐形式 / 智能推 / 自定义推广。
14. 自定义投放里可选**直播间加热**、**人群包**（"这个人群包是需要你自己去测试出来的"，测过的可直接选）。

**E. 开播后的直播内设置**

15. **粉丝团 / 粉丝群**：开播后点"更多" → 粉丝群 → 右侧设置 → 可改群名称、头像、欢迎语；进群门槛可选"不用关注也能进 / 仅关注 / 加粉丝灯牌 / 进了粉丝群"。
16. **福袋**：互动 → 福袋，分**钻石福袋**和**实物福袋**（直播中才能发）。
17. **红包**：**现金红包**（抢到就是钱）和**钻石红包**（钱换成钻石再分发）。
18. **直播管理**：拉黑、**禁言设置**、**屏蔽词设置**、管理员设置、装饰美化、直播数据。
19. **装饰美化**：贴纸、滤镜、变声器特效等（"新主播、感谢陪伴""新人第一次开播"这类贴纸就在这里找）。
20. **连麦**：更多 → 三个点 → 连线设置 → 跨房对战、**付费连麦**（薛老师直播间用的就是这个，可设付费连麦价格、历史账单）、多人连线/PK 连线、观众连线（聊天室、KTV 等玩法）。
21. **连线权限**：可设"观众可申请连线"（关注即可申请）或"**仅接受粉丝申请连线**"（卡关注）。

### 4.2 电商基础知识（小店、橱窗、带货资质等）

讲师把抖音电商分成**五个板块：企业号蓝 V、团购链接、抖音小店、认领门店、开通橱窗**。

#### ① 企业号蓝 V

- **是什么**：开通企业号 = 抖音认可的商家。"你没开通，你说我自己是商家，抖音不认。"
- **不适合开**：不经常在抖音打硬广的、靠私信引流的、只专注打造个人 IP 的（"这种我建议你就专门做那个达人号就行"）。
- **适合开**：有实体店/有自己店铺、需要给店铺打硬广的、需要挂团购/小店等营销属性偏多链接的。
- **三个用途**：**找客户、做推广、打品牌**。
- **所需材料（4 项）**：
  1. 营业执照
  2. 法人身份证
  3. 运营人身份证及手机号
  4. 行业资质（**金融、食品、教培**三个行业需特殊资质）
- **开通路径**：我的 → 三条杠 → 创作者服务中心 → 企业号 → 立即申请 → 新建企业号 → 立即新建 → 上传企业资质、法人身份证。
- **常见问题（讲师给的标准答案）**：
  - 认证有效期：**1 年**
  - 一个营业执照能认证几个：**只能认证 2 个**企业号
  - 收费吗：**不收费**，只需准备文件
  - 开通后有流量扶持吗：**不等于增加流量**，"只是多了一个运营工具而已"
  - 开通后流量为什么变小：**考核的数据不一样，推流机制也不一样了**

#### ② 认领门店

- **显示位置**：视频**左下角**，带"查看地址"和"联系电话"。
- **适合谁**：本地实体商家、通过线上推广的商家；行业上食品/餐饮较多，金融、房地产也有。
- **收费**：基本入住 **0 元开店**；收费环节在团购交易结算时收**平台服务费（扣点）**；使用投流推广工具另计。
- **认领步骤（方法一）**：
  1. 下载**抖音来客** APP 并入住
  2. 搜索自己的门店，或创建门店
  3. 上传营业执照或法人身份证
- **认领步骤（方法二）**：抖音 → 右上角三条杠 → 全部分类 → 下拉 → 我的线下门店 → 立即认领免费门店 → 上传资质。
- **常见问题**：
  - 搜索门店找不到店铺 → "说明你没有在地图上标注你的店铺位置"
  - 上传营业执照与门店地址不一样 → 补充材料（营业执照 + 门头照片）上传

#### ③ 开通橱窗（小黄车）

- **是什么**：橱窗 ≈ 小黄车。视频里的小黄车在左下角，直播间的小黄车在中间；分别对应**视频带货**和**直播带货**。
- **为什么开**："赚钱，一定要赚钱。"
- **开通四个硬性条件**（讲师原话，"这个是一个硬性要求"）：
  1. 身份证满 **18 岁**
  2. 粉丝数量达到 **1000 以上**
  3. 发布视频数量**必须超过 10 条**（"少一条可能都不太行"）
  4. 缴纳 **500 元以上**的保证金
- **开通路径**：我的 → 创作者服务中心 → 全部 → 电商带货 → 填写个人信息/个体工商户/企业资质 → 提交审核 → 交保证金。
- **选品**：我的 → 我的产品 → **选品广场**（有推荐品；没有就搜索，看历史搜索）。
- **挂车（视频）**：发布视频时 → 添加标签 → 小黄车商品 → 从选品车添加。
- **挂车（直播）**：开播前 → 商品 → 选品车 / 我的橱窗。

#### ④ 抖音小店

- **最大特点**：**零粉丝也可以在抖音上带货**。
- **所需材料**：营业执照（个体或企业）、自己的产品 / 第三方货品 / 官方供应链。
- **开通路径**：百度搜"抖店" → 立即体验 → 填写主体信息、店铺信息 → 提交审核 → 账户验证 → 缴纳保证金（**六步**）。
- 讲师播放的官方教程要点：按营业执照类型选主体（个体工商户 / 企业公司）；营业执照与身份证可自动识别填充，需核对；经营类目须在营业执照经营范围内，**不要选超范围类目**；部分类目需上传许可证，且**许可证主体需与公司名称一致**；审核时效以页面提示为准；个体工商户可人脸识别（抖音扫码）做账户验证；按类目要求缴保证金。

#### ⑤ 团购链接

- **四步流程**：准备材料 → 确定门店经营方式 → 提交资质 → 抖音来客绑定。
- **准备材料（4 项）**：
  1. 下载**抖音来客** APP
  2. 营业执照照片（**四角完整、必须清晰**，"不清晰或者四角不完整很难上传得上去"）
  3. 法人身份证
  4. 相关经营许可证（如食品许可证）
- **关键提醒**：登录抖音来客 APP 尽量用**法人实名认证的手机号**，"避免后续审核的时候容易出问题"。
- **确定经营方式**：单门店（立即开店）/ 连锁店（直接入住），然后认领门店或直接创建。需填门店名称、品类、招牌、所在地区、详细地址。
- **提交资质**：备案、行业资质补充完成后 → 我已阅读 → 提交审核，**预计 1~3 个工作日**，短信通知结果。
- **绑定**：抖音来客 → 店铺经营 → 抖音号绑定 → 绑定官方账号（三步）。

### 【拆片会 2025.03.25】平播四轮万能话术：不会播也能唠 20 分钟（董华）

> 蒸馏来源：25年11月最新allin编导团队拆片会及往期13+16节/05、三大体系成就百万大V薛辉编导团队拆片会【2025.03.25】.mp4（董华，约第 21–23 分钟）

#### 一、他要解决的场景

- 「很多学员会说：老师我不知道怎么直播」「怎么播也太难了」「播啥都不知道说啥」「你要我播一个小时，都不知道说啥」
- 他的做法是「我就去拆了很多……一些主播，我看他们话术」「麦当劳、肯德基那些大厂，看他们怎么播的」，并咨询了「一个朋友也是经常播那些麦当劳、肯德基啥的大厂」
- 产出：「帮大家总结一个比较简单的平播万能话术」

#### 二、四轮结构（按顺序，一轮讲完接下一轮）

| 轮 | 讲什么 | 他的原话 |
|---|---|---|
| ① **痛点** | 圈人群 + 抛痛点 | 「第一轮就是痛点，圈你的人群加一个痛点」「痛点基本上大家都知道」 |
| ② **卖点** | 产品特点 | 「卖点是怎么卖呢？就是你产品的特点」「我觉得你们比我更会介绍你自己的产品」 |
| ③ **对比** | 找优势 + 找一个不如你的作对照 | 「加咱们的第一天的 15 个成交理由」「找到咱们产品的优势，然后再找一个是不如咱们的进行一个对比，把咱们的成交理由体现出来」 |
| ④ **饥饿营销** | 稀缺 + 排期 | 「最后一个就是饥饿营销」 |

他的节奏判断：「基本上就按这么个流程来，你总能唠个一二十分钟」「一轮、二轮、三轮，一个（小时）到二十分钟就过去了，就下播了」。

（整理者注：这套是"平播"（无脚本、无投流、日常开播）的兜底结构，不是大场直播的脚本。它的价值在"不会冷场"，不在"能爆单"。）

#### 三、第④轮的示范话术（他给的两个原话）

- 手艺类（他举例的语境是医美/推拿一类）：「我家只有三个师傅，别的师傅我看不上。如果你不是今天来找我，可能你预约到给下月 1 号。我不能给你提前，因为我不想让我们的（效果）下降」
- 课程类：「我们的小班课，只要剪辑的小班课，一班只招 30 个人，已经满了。如果你想再来的话，肯定（排）到下月 1 号」

（整理者注：这两句的共同结构是"稀缺 + 不为你破例 + 给出理由"。第三句"因为我不想让效果下降"是关键——它把"不给你排期"从"我不想接"翻译成了"我为你好"，这才是饥饿营销和"摆架子"的分界线。）

#### 四、他给的最终判断

- 「其实说到最后，还是得直播」
- 「直播才能变现」「直播变现挺快的」

#### 五、与本册前文"直播话术三模块"的关系

本册前文的"三模块"（种草推荐 / 产品营销 / 直播数据）是**大场/有脚本直播**的完整框架；本节这套"四轮"是**日常平播**的最低可用版本。两者不冲突，可以这样配合：

- 日常平播 → 用四轮兜住，保证不冷场
- 有活动/有大流量时 → 切到三模块，做转化峰值

#### 六、存疑

- 「第一天的 15 个成交理由」指课程第一天讲的 15 个成交理由清单，本场未复述，需回查正课。
- 「一个（小时）到二十分钟」转写含混，按"一二十分钟"理解。
- 麦当劳/肯德基的"大厂主播"具体指品牌自播间，非平台官方。

### 【拆片会 2025.04.22】带货短视频一条龙：从脚本到拍摄到"不像广告"（若鱼）

> 蒸馏来源：allin 编导团队拆片会 2025.04.22（若鱼，63 分钟）。她把"说产品"这件事从文案到剪辑到配乐全串了一遍。本册已有 4.0 主课的 4P 法则，这里补的是**落地层**——顺序、常见错误、拍摄、去广告味。

#### 0. 先定账号配比与起步门槛

- **纯带货账号 3000 粉就可以开干**。理由不是"够了"，而是「我怕大家坚持不下去」：有正反馈才撑得住。「别等着涨三十万、五十万粉再开干，这时候大家坚持不下来。」他的原话是「把抖音当个班上」「电线要趁早」（转写疑为"开线/开店要趁早"，按上下文应为"开干要趁早"）。
- **人设与带货配比 3 : 7**。30% 输出晒过程/教知识/聊观点维持人设，70% 高频发带货。这是"纯带货账号让人看着不舒服"的解法。
- 反证：纯带货账号七八百条到一千多条全是产品，点进去就想划走，但橱窗能卖二三十万件——**说明它靠的是高频与选品，不是内容好看**。

#### 1. 4P 法则的关键修正：顺序不固定

主课的 4P 是 **目标人群 → 场景冲突 → 产品亮点 → 促销活动**。她放的三条爆款，**没有一条按这个顺序**：

| 案例 | 第一条说的什么 | 主打卖点 |
|---|---|---|
| 挡油板 | 直接说功能（挡油防水防烫） | 功能强 |
| 纸巾 | 「赶紧手机拿来我带你薅点羊毛」 | 便宜 |
| 送礼款 | 上来就说"送闺蜜的礼物"，连价格都没说 | 颜值高 / 礼物属性 |

所以她的结论：「4P 法则顺序给大家列在这儿了，但真正写带货文案的时候，并不一定非得按那个顺序写。」**正确做法是先判断主打卖点，把那个卖点提到第一句。**

**判断练习（她现场给的四个产品）**：9 块 9 一百二十个垃圾袋 → 便宜；89 块防脱洗发水 → 效果强；168 块车内小牛挂件 → 颜值高；69 块玻璃烧水壶 → 安全/价格（因为市面上都是 50–100 块、都写 304，没有差异化）→ **没有差异化的常规品，就老老实实按 4P 常规顺序写**。

她补了一条判断标准：打火机 300 多块很漂亮 → 先写颜值和礼物属性；打火机就是两块钱一个的 → 按常规 4P。

#### 2. 带货脚本四种常见错误（附改法）

| 错误 | 反面案例（学员真实脚本） | 改法 |
|---|---|---|
| **信息密度低（说废话）** | 「家人们我要开始念广告了，家人们你们要的老爹鞋终于到货了……现在一双只要 19 块 9」——三句只说了一个"便宜" | 「我从来没有买到过 19 块 9 还这么便宜舒服百搭的老爹鞋」——一句话说完 |
| **反问句式（攻击性强）** | 「你想轻松拥有一尘不染的家吗？这款打折的吸尘器就是答案」 | 换成分享句：「可算让我找着个擦地不费劲又不用手动清理的宝贝了」 |
| **卖点模糊** | 「这款褪黑素一定不能错过，天然成分温和助眠，快速调节生物钟」 | 换成具体体验：「昨晚我睡前嚼了一粒，睡得那叫一个香，一觉睡到大天亮，而且吃完完全没有以前那种头昏脑胀的感觉」 |
| **不说人话（术语）** | 「采用全新生物酶配方，能快速分解油脂分子，PH 值中性不伤手」 | 「拿着钢丝球半小时都蹭不掉的陈年老垢，轻轻喷两下，三秒钟擦干净」 |

她给的两条通用替换原则：
- **说"节省时间"** → 不如说「以前擦地坑哧坑哧擦半小时，现在五分钟家里擦一圈，剩的时间还能看看电视剧」。
- **说"性价比高"** → 不如说「花两杯奶茶钱，承包一整年的地板干净」。

#### 3. 拍摄：让画面动起来的三个技巧

| 技巧 | 做法 | 示例 |
|---|---|---|
| **边走边说** | 在真实动线上讲产品，不坐下来 | 卖酒：跟老公回娘家、往后备箱装酒时讲；卖解酒药：在酒吧门口吃完往里走时讲 |
| **直接拍使用场景** | 功能强的产品，边用边讲 | 吸尘器：直接吸给你看，一边吸一边介绍 |
| **多切特写** | 把细节拆开拍 | 高跟鞋测评：鞋跟五根钢筋、蝴蝶结拉力、鞋面软度、鞋底耐磨，一路特写 |

她给的对照实验：同样卖帽子，一条坐在那儿拿着帽子干讲，一条切了很多画面和特写还拍了使用场景——「我看到这我已经下单了」。

#### 4. 克服"营销感"的四个办法

1. **这个产品你必须真的用过**。「你没用过你肯定拍不好的，你跟它都没有关系咋拍呀。」
2. **刻板重复**：台词读一遍 vs 读五遍 vs 读五十遍，「拍出来的效果真的完全不一样」。
3. **别怕说错**：「只要意思对，就一直往下说就好」，不要因为第三个字说错就重拍。
4. **找个人当搭子 / 给自己加戏**：条件允许就找个人坐对面，真给他分享时状态一定真诚；或者给产品设计一个场景戏——卖清肠片就坐马桶上拍，卖褪黑素就躺被窝里拍，卖解酒药就上酒桌拍。她的原则：**「尽量别坐在那儿拍，坐在那儿拍就太假了。」**

#### 5. 反向带货（小玩法，适合热卖款）

**做法**：上来先骂/先质疑，后面全在夸。原片：「家人们千万不要用这个沐浴露，千万别买——怎么回事？我怕它给你啃坏了。」

**适用条件**：抖音上的**热卖款**（已经卖了几百万单的品），常规打法打不进去了。她给的模板：「网上卖了十万单的这个口香糖，它真这么好使吗？我买回来一个咱看看。」

**同源思路**：没东西可写时，**从自己对产品的质疑出发**——买褪黑素会想"有没有副作用、会不会依赖、会不会吃完头昏"，脚本就反着来，一条条打消。

#### 6. 选品/写稿没时间怎么办（给纯带货博主）

1. 同类型视频多拆，尤其是**同款爆款**。
2. 商家的详情页认真研究。
3. **用户评价一定要看**，「用户评价是最真实的，直接拿过来用就行」。

#### 7. 她给整节课的收尾（最该记住的一句）

> 「真正牛的视频，其实就是不让别人知道你在带货。你拍的这条带货视频，是在跟好闺蜜、好兄弟、好姐妹分享。」

以及一个身份设定：**「一个毒舌的、挑剔的人，来给你分享一个用过的好东西。」**——这个身份比"推荐官"可信得多。

### 【拆片会 2025.11.08】九种购买动机 + 三个必答问题（加利）

> 蒸馏来源：allin 编导团队拆片会 2025.11.08（加利，89–103 分钟，第一次上拆片会）。她是直播运营，讲的角度跟编导不一样：**编导关心"怎么让人看完"，她关心"人为什么掏钱"。**

#### 起点：先算"谁的钱最好赚"

她把消费人群排了四类：**女人、懒人、孩子、老人**。本场只讲女人，理由是「现在消费者的主力军就是女人」。

她用来证明"女人消费力有多猛"的证据是李佳琦 2024 年双十一首场直播（10 月 24 日）：她给的数字是场观 4.56 亿人次、销售额过百亿（具体口径她自己也存疑：「具体 200 多亿也好，肯定是过百亿了，大家可以自己数一下这个零」）。**这属于课堂引用的第三方数据，未核实。**

#### 九种购买动机（她给的清单，原文照录）

求实、求新、求美、求名、求速、求利、从众、癖好、随机。

她现场用一条美妆带货视频做了对照：博主标题写"分享一下半年度爱用"，视频里重复了一遍"把你的美丽交给我""大美女"，**全片没有提价格**。她的拆解：

| 视频里的动作 | 命中的动机 |
|---|---|
| 「大美女」「美丽交给我」「奶雾感妆效」 | 求美（变美变年轻就会立即购买） |
| 「半年度爱用」「分享」 | 从众（口碑分享 = 立即购买） |
| 全片不提价格 → 观众自己去查，发现才八十几块 | 求利（便宜） |

她给的推论：**一条带货视频不用覆盖全部九种，命中两到三种就够。**

#### 三个必答问题（这一段被薛辉当场认定为最有价值的部分）

> 「我为什么要买？为什么找你买？为什么现在买？」

她的原话是「今天所有的购买动机，其实都是第一个问题——为什么要买」，后两个她说"未完待续"。

薛辉的点评补上了后半段，而且补得很准：

> 「我觉得你问的第三个问题很好，就为什么现在买。我觉得咱们卖课不好卖的点，就是**没法给人一个现在买的理由**。大家听我这课都觉得买挺合理，就是挺合理，但是就是没必要现在下。」

他给了一句总结：**「所有的直播带货都是为什么现在买、为什么找你买。」** 并当场给这位讲师派了活：「你好好给我研究研究，研究出来你再给大家分享一场，叫怎么让顾客现在买。」

#### 一个附带的方法论：男性和女性的购物车差别

她用一个现场互动证明"男人是懒人"这个判断：让男生扣 1（购物车是空的）、女生扣 6（购物车满的）。薛辉接了一段自述，值得记：「我到 2018 年的时候跟公司一个产品经理聊天，我们俩都是男的，突然聊到购物车这功能是干嘛用的……我们男人理解不了什么叫购物车。」

> 整理者注：这段看着像闲话，其实是一条选题线索——**"男人不懂购物车"本身就是一条观点型选题**（结构见 `03-脚本体系.md`「观点型脚本」，属于"敌人"或"过错"抽屉，站女性这一边）。

### 【拆片会 2025.08.30】单品带货三段论：一个脚本套到底，拍 134 条（司凯）

> 蒸馏来源：allin 编导团队拆片会 2025.08.30（司凯）。他自己先说明了动机——「我家里是做白酒生意的」，想开一个"什么都不干，只卖产品"的号。**本册最可直接套用的带货模板，不需要创意，只需要填空。**

#### 先说清它要解决的问题

他引了同场紫荆老师的一句话，作为整套方法的前提：

> 「**拍视频不费劲，没流量不心疼。**」（意即：可着一个脚本、一个套路走，海量出，拍了就发，不要流量焦虑）

#### 结构（三段，中间四块）

| 段 | 内容 | 要点 |
|---|---|---|
| **① 框定人群** | 「这个玩意儿，爱玩手机、爱拍短片的朋友、经常外出、爱直播的朋友，我不允许你们不知道」 | **凡事都不如与我相关**。第一句就把人叫住 |
| **② 中段四块** | 卖点 + 使用场景 + 自我评价 + 产品背书 | 见下表 |
| **③ 价格对比 + 引导下单** | 「海外售价 22.9 美金，折合人民币 150 左右；这次我替抖音的朋友跟品牌卡了下价格，99 包邮，相当于七折」+「你手里的手机支架现在还好用吗」 | 抛出原价→现价→一句反问式收口 |

**中段四块怎么写（他给了填空口径）**

| 块 | 写什么 | 原片示例 |
|---|---|---|
| **卖点** | 从**大小、颜色、材质、功能、特色**里挑 1–2 个说清；吃的再加口感 | 「半杯水的重量，最短一瓶水的高度，最长 1 米 3」 |
| **使用场景** | 什么场景下用、能解决用户什么问题，用大白话说 | 「站着直播能用，坐着拍口播能用，躺着看剧还能用」 |
| **自我评价** | 有行业背书的说心得；普通消费者说使用感受 | 「我自己手机支架很多，使用过程当中很多会有逐渐松动的问题」 |
| **产品背书** | 是不是名牌、有没有获奖、明星同款、销量排行、评分 | 「拿过四次红点奖」「斯莫格官方旗舰店发货」 |

#### 他的现场练习（这段最能说明"填空"的含义）

**卖 29.9 的小米电动牙刷**：卖点（防水、续航、可换刷头）→ 使用场景（普通牙刷刷不干净；**逢年过节家里来客人借宿，你拿出一个电动牙刷给他，他会觉得你这个人很讲究**）→ 自我评价（这个价位里算好的）→ 背书（小米大品牌）。

**卖智能马桶**：卖点（加热、材质、清洁）→ 使用场景（**北方冬天没供暖时坐上去不会一机灵；女性特殊时期更卫生**）→ 自我评价（「用了这个智能马桶，你再用普通的根本用不回去」）→ 背书（海尔品牌、销量）。

#### 他给的两个实证（都可核对）

**① 南哥（100 多万粉）**：一条视频卖一个手机支架，**销售额 300 多万**。

**② 集议摄影工作室（10.9 万粉）**：这个案例更关键，因为它证明"不靠表现力也能成"。

| 项 | 数据 |
|---|---|
| 粉丝 | 10.9 万 |
| 总销量 | 6.2 万件 |
| 30 天销量 | 8700 架（单价 178） |
| 单件佣金 | 53.4 元（他在精选联盟查的） |
| 月佣金估算 | 约 40 万 |

他特意点出这个号的条件有多差：「这个视频两分 45 秒，从传统意义上来讲不算太好——时长比较长，表现力也很平，剪辑也没有，甚至连字幕都没加。」

**关键动作：这个号半年发了 134 条作品，全是同一个手机支架、同一套脚本，只是换地方拍。**

> 「你发现它是一直在不停地拍。……他不是有了这些粉丝才开始拍，他一定是拍了之后再有的粉丝。」

#### 他举的同类账号（都在反复拍同一个品）

| 账号 | 品类 | 作品数 |
|---|---|---|
| 除仙岛海鲜零食 | 鱿鱼丝、龙虾尾、生蚝 | 1500–2500 条 |
| 乾坤兄弟 | 一个辣椒酱 | 800 多条 |
| 汕衔黄鹏（山东老家） | 西瓜酱 | 2000 多条 |

> 整理者注：这套方法的真正门槛不是文案，是**重复**。对婚礼微电影这类"一单一个样"的生意，直接照抄"134 条同一个品"不成立，但可以平移成"**同一个服务、换 134 个客户场景讲**"——脚本不变，素材变。这恰好也是 `06-剪辑.md`「插入素材声同画」能接上的地方。

## 带货的三种姿势：站着、跪着、坐着（9-6 拆片会）

这一节针对的痛点说得很准：

> 「如果你的带货视频没有流量，或者是你绞尽脑汁地往你的带货文案里插广告，插得又特别硬，观众看着就想划走，怎么办？」

他把市面上的带货账号分成三种，只有第三种适合普通人。

### 一、站着挣钱：纯视觉锤，不计 ROI

**样本**：一条条全是广告、但你"一不留神就看完了"的特效短片（他放了两条，一条卖粉底/散粉刷，一条是 M&M's 类）。

> 「他是非常轻影响感的，就你如果不仔细看，只是觉得它是一个很酷炫的动画，但是他在**评论区会 @ 品牌方**。」
>
> 「我把它称之为'站着把钱赚了'——我就砸钱，我管他卖不卖出去，我就是砸最好的特效。」
>
> 「这类的账号就是纯是**视觉锤**，所有的特效都非常好。」

他自己也承认转化不明：「有购买欲吗？没有吧，其实看个热闹。」

**门槛**：钱 + 特效团队。普通人做不了。

### 二、跪着挣钱：乞讨式

> 「好多直播间也都是些病人啊、或者是比较落魄的人，然后在有种乞讨式地拍抖音。」
>
> 「我不觉得这个有什么不好的。如果人一旦放下尊严、放下脸面，我就要靠抖音赚钱，人家也是能赚得到的。」

**门槛**：脸。多数人放不下。

### 三、坐着挣钱：关系冲突 + 海量道具（推荐）

他连放三条，都是同一个内核：**一个人理直气壮地买，另一个人不理解**。

**样本 A：老婆乱买东西系列**（满柜子玻璃杯、一整面墙的杯子）

> 「它的最好的地方就是，它每条视频都可以夹带私货地去带货，但是你看的过程它又不烦，就没有被广告恶心到，你也不知道它哪是广告。」
>
> 「这类主题 IP 第二个好处就是**不用写文案，而且能持续更 100 条也不费劲**，他只要把道具都准备好就 OK 了。」

关键的一条：
> 「老婆一定要**理直气壮**——我就应该买这个，我理直气壮地去带货。我这个杯子就是好，然后讲每一个杯子的品类，就会特别有意思，而且它就隐性地被种草了。」

**样本 B：受气包老公吐槽系列**

> 「它的差异化呢，一定是要非常直男，他对老婆买的每一样东西不理解。比如说口红色号，十个口红他都觉得是一个颜色，这样他的戏剧张力就出来了。」

**两个通用要点**：

> 「① 所有视频里，老婆买的**量非常大**，都是满柜子的玻璃杯、一整面墙的杯子——**产品的量大才有视觉的张力**。」
>
> 「② **人物要有冲突**。老婆理直气壮地买，老公觉得他们就不应该买，有这种冲突之后，你所有的吐槽就有意思了。」

### 关系替换公式：关系 × 附加元素

没有老婆老公怎么办？他给了三种替换，并各配一个"加元素"的升级法：

| 基础关系 | 附加元素 | 升级后的标题 |
|---|---|---|
| 婆婆 × 媳妇 | **地域/文化** | 「我的日本婆婆买的奇葩东西」 |
| 老板 × 员工 | **年龄** | 「我的 00 后老板买的奇葩东西」 |
| 姐姐 × 弟弟 | **性格** | 「我的暴躁姐姐买的奇葩东西」（配一个受气包弟弟） |

> 「地域、年龄、性格这三个元素也是可以混搭的。我们只要找到一个自己能真实存在、或者能虚拟演绎出来的关系就可以了。」
>
> 老板 × 员工那条他专门解释了为什么写"00 后老板"：「为啥没有写员工？就可能 00 后就当上老板了，**他的戏剧张力会更有趣，它是一个双重的冲突**。」

**收尾金句**：
> 「站着挣钱门槛太高，跪着挣钱弯不下腰，怎么办？我们最适合普通人的其实是舒舒服服地坐着挣钱。」
>
> 「不要找客观原因：我没有钱怎么拍视频、买不起设备怎么拍视频、我拉不下脸拍不了视频怎么办——都可以。你找到一个适合自己的，有一个手机、有一个摄像头，**我们先拍了再说**。」

（整理者注：这一节和 8-30 的"单品带货三段论"（一个脚本套到底、拍 134 条同一个手机支架）是同一条路的两个变体：那条靠"同一个产品反复拍"，这条靠"同一种关系反复拍"。共同点是**都不需要新选题**，只需要新道具/新商品。这是"能持续更新"的真正原因。）

## 不露脸带货：第一视角 + 碎嘴子旁白（9-6 拆片会，"售后"专场）

讲者开场就说明了为什么讲这个——上一期他讲的是露脸带货，结果很多人反馈：

> 「很多小伙伴说：老师我不想露脸，我表现力不行，我对镜头紧张，或者我现在就是不想露脸。」

样本账号：**潘潘今天喝什么**（110 万粉，219 条作品，8 个月日更，短视频带货 10 万+，当月带了一万多件）。

### 四维拆片法（他要求观众带着这四个维度看片，这个方法本身可复用）

> 「大家先来看我这上面标的四个东西，叫**画面呈现、文案、声音、剪辑**。就分析这四个维度。」

**① 画面呈现（他量过）**

| 要素 | 具体做法 |
|---|---|
| 场景 | 窗台 / 飘窗 / 榻榻米上放个小桌——**「这个有吧」** |
| 光 | **自然光**。时间段：「早晨九点到十一点半，到下午两点半到五点。这个时间的阳光不会太硬，也不至于说阳光太强，而且又有阳光，这个时候画面拍出来比较通透干净」 |
| 机位 | **固定机位，从头到尾没动过**（「可能是不小心移动了一下，但绝对我觉得应该不是故意设计的」） |
| 角度 | **低视角**，「这种代入感很强」；「我给他定住了是 75 度角，无意俯视拍摄」 |
| 容器 | **不普通**：「他那个容器是非常有热点的——《蜜雪冰城》它本身自带流量」 |
| 背景 | 有只猫在背后。「在自己家的阳台上，有阳光，在午后做一杯饮料，又有宠物在背后，他营造的是一种氛围」 |

**② 文案：不是教学，是碎嘴子**

> 「他有可能是在想教我们怎么做，但其实他在陈述的时候他有点碎嘴——**有点叨叨叨地在跟我说这个事儿，他没有在教我**，但是我可以跟他去学。」
>
> 「他就是在叨叨叨地跟我聊天儿说：你看我怎么做了。而且我故意漏勺，我会故意倒出来一个自我调侃。」
>
> 「**他不是教学，就让我看着很爽。**」

**③ 声音：AI 配音，故意用错音色**

> 「他用的是 AI 的智能语音，是在剪映里边的 AI，男声音色，门类底下的叫**'知识讲解'**。」
>
> 「这种声音就**颠覆感很强**——本来这是一个知识讲解的，但是我用在这个上面自我调侃，本身就有颠覆性。这个就是一种火的流量密码：**颠覆**。」

原声也要清楚：「原声首先要很清楚，就是他倒冰啊、把冰块放进去啊。」

**④ 剪辑：40 秒 / 20 个镜头 / 2 秒一个**

> 「他平均时长在 40 秒左右，平均一个视频的镜头在 20 个左右，两秒左右一个镜头，镜头切的节奏非常快，不知不觉我就看完了。」

### 他编的顺口溜（原文照录，好记）

> 视频色彩要鲜明，软广直入才致命，
> 过程声音要能听清，成品颜值必须行，
> 美女美甲好心情，切一小滋成一景。

逐句解释：
- **色彩鲜明**：「我们拍这个视频要清晰、颜色要好看」
- **软广直入**：「他这里面的杯子跟他用的一些材料，其实都是软广的植入」
- **声音能听清**：「更加的治愈」
- **成品颜值必须行**
- **美女美甲好心情**：「他的视频里面的美甲更换得特别频繁，评论区里也有这个点」
- **切一小滋成一景**：「就是他拍的这种氛围」

### 文字钉（他专门解释了什么叫"钉"）

> 「文字钉其实就是一个自己固定的一个设置，就是固定的这个文案。**但是它得能让人记得住。**」
>
> 「很多同学说我有个文字钉，然后我一听他那个，我根本没感觉、没感觉。**他就很魔性**——你像薛老师问的那句话：'愿无岁月可回头'。」

原片的钉子：**「OKK」「盘子真棒」「让我来浅尝一小滴」「哇哇」**。评论区的反应他也念了：「一天不听这个声音我就难受。」

### 落地：教程去哪找

> 「我给在小红书上素材库给你找好了，关键词叫**'夏日饮品自制'**，简单。如果到秋天到冬天了，把'夏日'换成'秋日''冬日'就可以了。」

### 迁移清单（他念的，一个句式换一个行业）

> 「今天喝什么……大家首先想到的就是：**今天穿什么、今天吃什么、今天开什么（车）、今天去哪玩、今天去哪约会、今天住哪儿**。」
>
> 「美食可以做吧，测评开箱也可以做——'今天买了什么'，然后用这种第一人称视角。你想露脸就露，不想露脸就不露。」
>
> 「手工 DIY 可以吧，就是做个手工活、做个美甲……装修的，我甚至也可以露镜，我在那忙，然后去解说，用 AI 的配音。」

**真实案例（徐老师补的，可核对）**：
> 「有一个学生做了一个号叫'挤木朵朵'，两个月不到，一个月能卖 20 万，他只卖杯子，也是做饮品。」
>
> 「我（跟）他说，你做饮品这东西就两点：**一个点是找好玩的杯子，第二个点是做的东西本身好玩。**要不然就是杯子好玩，要不然就是制作过程好玩、做出来的东西好玩，其实就这两个点。」
>
> 「他本身是个程序员，兼职做抖音……昨天我看了看他佣金，**一个月能挣个五万块钱**，他兼职可能比本职工作收入还差不多。他就是每天下班回家拍一条。」

（整理者注：这一节最值得抄的不是"做饮品"，而是**"不露脸也能做"这件事本身被证伪了**——只要你的手在动、过程有画面、旁白有性格，脸根本不是必需品。婚礼行业里最适合这条的是：化妆师（第一视角化妆过程）、花艺（第一视角扎花）、布场（第一视角搭架子）、修图（第一视角调色）。这些都是"过程本身好看"的工种，且完全不需要出镜。）

## 堆人头：一个人表现力不够，就多上几个人（11-1 拆片会，允泽）

这一节拆的是一个服装带货账号，数据很硬，讲者自己都说"给大家看一个恐怖的数据"。

### 账号数据（讲者现场查的，未独立核实）

| 项 | 数值 |
|---|---|
| 30 天累计销售额 | **1000 万–2500 万**（讲者说"两星期前我看才 1000 万"） |
| 粉丝性别 | **88% 女性**——「很值钱的精准粉」 |
| 日更量 | **一天 9 条甚至更多** |

### 核心玩法：堆人头

> 「我觉得她的视频，我给她起了一个名，叫做**堆人头**。可能一个人你的表现力不够，那我就多上几个人。」

**机制（他讲得很准）**：
> 「你像刚才这个视频，他的其他视频——大家想看这个视频上哪个人？'我看穿裙子那男的。'」
>
> 「如果我第一个先上是这个人，你是不是还是想继续看下去，想看到直到他出场，我才会把这个视频看完、滑走？」
>
> 「所以说很可能就是：**如果你的表现力不够，那我们再多上几个人，找一些小梗点，让你的播放量翻倍。**」

**内容构成**：全是"我身高多少、体重多少、穿的是哪个码"——「他不需要写文案，他就用这种呈现方式。」

**这种视频的作用不是卖货，是引流**：
> 「他的视频内容是展示衣服的、说尺码、展现给大家看的，**引流的**。然后他的直播间直接就是去购买这个衣服。对他直播间引流非常重要，非常有用处。」

### 三个"差"是梗的来源

> 「她经典就是在**年龄差**比较大一些，然后还有一些**性别差**——男人穿女装、女人穿男装，或是老太太去展现一下这些衣服的穿搭。」

### 徐老师补的关键一层：陪衬者逻辑

弹幕里有人问"为什么这样的衣服都会有人买"，徐老师的回答是全场最锋利的一句：

> 「买的人心理是什么？**买的是'我怎么穿都比他们好看'。**」
>
> 「就是**陪衬者逻辑**，陪衬者逻辑就能把东西卖出去。」
>
> 「像这些其实就是陪衬者人设，尤其她妈每次摆那个 pose。」

他还把这个账号和另一个做了对照：
> 「前面那个抠图，那个是**搞笑者**的逻辑；这个就是**陪衬者**。」
>
> 「我前两天录视频的时候我说过一句话：我说我们普通人都能做到短视频——虽然我们普通人不能给别人提供真知灼见，**但我们可以在屏幕前丢人现眼**。但是我觉得他这个叫什么呢？他这个叫**既通过短视频提供真知灼见，又同时通过短视频丢人现眼**。」

### 迁移（他现场给的三组）

| 产品 | 玩法 |
|---|---|
| 眼睫毛 | 「我爸妈贴眼睫毛……妈妈贴、爸爸贴」 |
| 汽车 | 「我爸妈看车」——「在我眼里那种跑车是特别牛逼的」，妈妈说"你那跑车不行，还是奔驰比较牛逼"，爸爸说"我觉得路虎比较帅" |
| 服装 | 他想的升级版：「能不能把这个形式跟前面那个（空中跳跃）视频结合一下，多个人一起跳是什么样的感觉」 |

### 一句总结性的话（徐老师）

> 「太阳底下没有新鲜事，所有东西都是重新的排列组合。」
>
> 「不能说咱们完全没见过，只是说当时看到的时候**没有被激发这个灵感**，说拿它用来做我们的呈现方式。」
>
> 「抖音发展到现在，大家拼新的呈现方式，让我们看有新的感官……只要有一个新的呈现方式，基本上就没有什么问题了。」

（整理者注：这条给"没表现力、没文案能力、也没钱"的人提供了一个极低门槛的路径——**找几个人，站成一排，各说一句自己的尺码**。它的商业逻辑是"陪衬"而非"种草"，所以对婚礼行业并不直接适用（婚礼不能靠陪衬卖货）。但它的**结构**可以借：一场婚礼里，"伴娘团/兄弟团/双方父母/小花童"各自说一句话，就是天然的"堆人头"——不是为了卖货，是为了让观众在 30 秒里看到足够多的面孔，撑住完播。）

## 4P 法则的四个补充：这一步在干什么、坑挖多大、价格取中、加 1 元的心理（3.0 §20，少宝）

**先说明关系**：本册开头已有 4.0 主课的 4P 法则（目标人群 → 场景冲突 → 产品亮点 → 促销活动），后面还有若鱼那节的重要修正「**真正写带货文案时，并不一定非得按那个顺序写，要先把主打卖点提到第一句**」。这一节是 3.0 课另一位讲师（少宝，转写亦作"社报/少保"，开场自报「校舍的直播运营、线下讲师，我叫少宝」）讲的**同一个 4P**，两处框架一致、无冲突。**这里只记本册此前没有的四个增量**，不重复结构本身。

### 增量①：四个 P 各自"在观众脑子里干了什么"（他复习时给的）

| P | 作用（原话） |
|---|---|
| 目标群体 | 「**引起受众注意**」——「你就像刚才那个 12 星座图似的，我在那一放，第一时间是不是看到自己的星座」 |
| 场景冲突 | 「**引发用户的情绪**。你有了情绪，他才会在你这下单」「你以后不管是拍视频还是直播也好，一定要圈定好人群」 |
| 产品亮点 | 「**引出解决的办法**」「我的产品要解决我的问题，大家才会去买你的产品；**如果你解决不了我的问题我就走了**」 |
| 促销活动 | 「差一点点的时候，我们就来一个小的促销活动，这叫**引导行动的理由**」 |

**关于"圈定人群"他给了一组开场句式样本**（都带明确的身份标签）：
> 「30 岁的你，是不是感觉到上楼都费劲」「喝多的你打电话给前任」「身为东北人的你，是不是容易出现这样的误解」「作为普通人的我们，如何做好抖音」「产后抑郁走出来的三个感受」。
> 「一二三四五，他都确定了一个人群前面……**这叫目标群体**。因为他确定了这个群体之后，我们再去研究怎么把货卖给这个群体。」

他用 12 星座图解释得最透：
> 「其实大家看到这张图的时候，本能的反应是什么？**是先找自己**……看完了自己的星座，看后面，'他好像说的对'……我赶紧看一看自己伴侣的……然后就开始看自己亲人、朋友的了。为什么？因为他统一都圈定了一个目标群体……**这里面一定会有你**。」

### 增量②："只有场景才能唤醒强烈的情绪"＋挖坑的尺度

这是本节最值得记的一段。他讲了自己做运营时连续两个真实场景（周五下班前 180 页 PPT 被领导两分钟全否、一个人加班到 22:47；以及 26 岁程序员同学熬夜秃顶），然后引出电梯里那两句广告：

> 「**又一天过去了，我离我的梦想远了一点——只有加班的人能看见。**」
> 「**即使加班到明天，也不一定有明天。**」（他那位程序员同学看到后一周就辞职了，薪资从 3 万降到 1.5 万，但"不累了"）

**他接着主动给这个结论划了边界，这一步比结论本身重要**：
> 「我们换一种思维想——我刚毕业，我刚想留在沈阳，我的梦想我的未来都在这个城市里……**你还告诉我离梦想远了一点？我恨不得天天加班**，好好表现提升自己的工作能力。」
> 「所以说**目标群体不一样，看到每个场景的感觉也不一样**。」

> 「你今天说了'扎心了老铁'……都是因为**场景**。**场景能唤起我们强烈的情绪。如果没有这个场景、不是当下发生的事，我们一定是没有情绪的，很难有情绪。**」
> 「只有场景才能唤醒我们强烈的情绪，大家一定要记住这句话。」
> 「你今天很开心……中了 10 万块钱，别人过来跟你说什么负面的东西'没事铁子都能过去'，但是事实并不是这样。」

**挖坑的尺度（他反复强调的一条硬规矩）**：
> 「**这个场景冲突你不要挖坑挖得太大**，你挖得太大，这用户一看'那我也不填了，太难了'；**但是你这个坑你要是挖得特别小的话**，用户'我不在意、无所谓、无关紧要'。」
> 他给的正反例：减肥场景说"坐公交车一人坐两个位置"→「又怎么样呢」（坑太小）；说"跟一个美女去见面，你一人坐两个位置""出行大汗淋漓、衣服前后全湿了，影响你的形象"→ 这个才成立。

（整理者注：这条补上了本册 4P 里最含糊的一环。**冲突不是越痛越好，也不是随便一个不便就行，判据是"目标群体真的在意、且自认为能解决"**。这与 11-1「贩卖幻觉」里"实现他人压抑生活中的幻想"、"选的事件必须是大多数人都真实咽过气的"是同一条判据的两种说法。）

### 增量③：需求 vs 核心承受成本——价格带要"取中"

他举了一个 19459 元的扫地机器人，问「如果说让你买一个，你会买吗？我估计 95% 的人应该都不会买」，然后给两个核心点：

> 「第一个核心点是**需求**，第二个点叫**核心承受成本**。」
> 「即使我需要一个扫地机器人，但是我也要考虑到我的承受成本……我可能综合一下就买个 3000 到 5000 的，就是我的上限了。」
> 「可能你感觉他很 OK、很不错、性价比很高，**但是它的价格很高，我们尽量不是我们的首选**。」
> 「你可以选择由中高低档，**所以说我们尽量去选中、取中**。就像我们吃鱼一样，我们基本都是不吃鱼头、不吃鱼尾，**我们吃的是鱼身**，因为这块肉比较多……尽量不去卖特别高的，也不要去卖特别低的，我们选一个中等的产品价值就可以。」

### 增量④：促销的"加 1 元"比"白送"更好卖

经典案例（他现场让学员选 A/B）：
- A：买 999 元的不粘锅，**送**价值 299 元的马勺
- B：买 999 元的不粘锅，**加 1 元**赠送 299 元的马勺

> 「大家会选 A 方案还是 B 方案？……是不是大家会选择 B？为什么？」
> 「**加 1 元，但是重心是 999 元的锅**——会让消费者产生一种什么心理呢？'我花了 999 元，真的是买了一个 999 元的锅，我这个 299 元的马勺可能就值 1 块钱'。」
> 「但上边不一样了：'我买价值 999 元的锅，送我一个价值 299 元的马勺'——**我就会想，那我这是不是我这个花了 1000 块钱，他俩半成品了？马勺 300 块钱，买了我这个锅 700 块钱，让消费者产生余地了**。」
> 「而且还有一点是什么，**加 1 元他会感觉他占便宜了**，他虽然多花了 1 块钱，但是我感觉我占便宜了。」
> 「**用户思维你得让他占到便宜，他才会从你这买到产品。**」

（整理者注：这里的"让消费者产生余地"应读作**产生"锅被折价了"的疑虑**——白送会让顾客把赠品价值从主商品里倒扣，加 1 元则把赠品锁成"我另外买的便宜货"，主商品价格感不受损。这是价格锚定，不是话术欺诈；但**"价值 299 元"必须是真实可查的标价**，否则构成价格欺诈，见文末风险。）

### 四个现场填空练习（他把 4P 套了四遍，可直接当模板）

| 品类 | 目标群体 | 场景冲突 | 产品亮点 | 促销活动 |
|---|---|---|---|---|
| 减肥 | 想减肥的人 | 「相亲困难、买衣服困难……那衣服都很好看，穿什么什么丑，赶紧就不逛街了」 | 「喝完左旋会让我们的运动状态翻倍，会让我们减脂状态也翻倍」 | 「**每天只需要一两块钱**，降低成本」 |
| 美妆 | 想变美的姐妹们 | 面部有闭口、有小痘 | 「我可以完美地去解决你的闭口问题」 | 「这一瓶是**三个月的量**，我只需要买一瓶，三个月都不用担心」 |
| 母婴 | 宝妈 | 「宝宝的屁屁总是出疹子」 | 「尿不湿四层吸水面，透水性好，**能吸一升水**」「小宝宝再怎么它也产出不了一升水」 | 「这款是**对标某大牌价格的一半**」 |
| 美食 | 喜欢做饭、爱好美食的人 | 「又菜又爱做……我做的不甜不咸、味道还不好、颜色还不好」「感觉差不多差不多，做了还是不好吃」 | 调料包：「你什么都不用放，把菜放在油里一炝锅，把这个调料包放里面，一道菜就出来」「做出来跟饭店一个味」 | 「**买一发 10**，10 道菜，19 块 9，十包，一道菜一块九毛钱」 |

### 顺带三条本册此前没有的判断

**流量与"人带货/货带人"的先后**：
> 「**流量小的时候我们是货带人，流量大的时候我们是人带货。**」
> 「我们最初开始做抖音……流量没有那么大，我们对自己的要求不用那么高，只需要先研究流量……先做货带人；等慢慢的人物属性和个人 IP 强的时候，我们就可以做人带货。」
> 他把学员的实际卡点归纳成三句：「**好人难找、好货难选、好场难搭**」；对第一条他的建议是「**咱先不找人，咱先自己研究明白**」。

**视频电商 vs 直播电商**（他的区分与选择）：
> 视频电商是「刷视频刷到了，左下角有一个视频链接，点下去就可以直接购物」；直播电商是「小黄车 + 主播 + 直播运营 + 投手 + 场控/中控」的团队配置。
> 问学员"A 做视频电商 / B 做直播电商"选哪个，他的回答是：「**小孩子才做选择，成年人我全都要**……我两个兼做，可以，没有问题。」

**无产品 / 有产品两条路**（本册已有选品五步，此处补的是"从哪来"）：
> 「我们在做抖音的时候就变成**有产品和无产品**。」他用一个真实撮合举例：盘锦同学家有几百年亩稻田蟹（有产品、有物流），另一个同学做中间商、有社区与实体超市渠道（无产品，只负责销售，「发货什么都不用管」），他把两人介绍到一桌达成合作。
> 「无产品」的三个典型困惑：「我不知道卖什么」「我不知道如何选爆款」「我不知道选品应该注意什么（收货太麻烦、全是客诉、评论区都炸了）」。
> 「**你卖的产品不能是说你认为我喜欢、我可以，而是说你卖的这个产品要迎合大众。**」
> 不知道卖什么时的三条动作：「**看做得好的同行他们都在做什么**——你们切记**同行是验证了这个市场的**」「去精选联盟里看一看爆品榜，**榜是大数据分析出来的**」「**千万别等**，你等着他永远没有结果」。

**看榜的时间纪律**（本册此前没有）：
> 「大家在看这三个榜（爆款热卖榜 / 搜索热度榜 / 搜索趋势榜）的时候，**尽量是早晨 8 点看一次、中午 12 点看一次、晚上 6 点看一次**，三个不同的时间段你去刷这个榜，它如果上下有浮动的话，到时候大家再去斟酌去选哪个品。」
> 「因为它可能是有的时候数据——就这一条视频爆了，大家买得特别多，他可能就短时间内上榜，跑一跑他就下来了。**所以说我们尽量去卖这种可持续性一段时间的产品**，会更有性价比。」

### ⚠️ 风险说明（整理者注，必须写清）

1. **本节大量功效宣称，一律不能照抄**：「喝左旋让运动状态翻倍、减脂状态翻倍」「掉秤特别快」「一贴一撕让牙齿变亮变美」「喝××可以变美变白」「完美解决闭口」「三个月都不用担心闭口」。这些是讲师现场举例的话术，**涉及保健品/化妆品/医疗器械功效，须有法定依据与备案，且不得使用"完美解决""翻倍""保证"等绝对化用语**。这是本 skill 第四次遇到课程里的功效/编造主张，前三次（力寅、允泽、程佑、李鑫）已分别标注。
2. **「能吸一升水」「对标某大牌价格的一半」属可验证的性能/比较宣称**，须有检测依据；比较广告不得贬损特定竞品，「某大牌」的模糊指代在广告法下同样有风险。
3. **「价值 299 元的马勺」「买一发 10」**：赠品标价、划线价、促销力度须真实可查，否则"加 1 元"这套心理机制就直接滑向价格欺诈。
4. **「7 天无理由退货后重新从自己橱窗下单以赚回佣金」**（他在开场自述里说自己把之前下的单全退了、再从自己橱窗买）——这是**平台规则灰区**，各平台对自买自卖、退货套利有明确限制，可能导致佣金追回或账号处罚。**本 skill 不推荐此操作**，仅按原话记录讲师的自述经历。
5. 500 元保证金、橱窗开通路径、三榜名称、佣金比例等均为**课程录制时的平台状态**，会变，执行前须核实。
6. **婚礼行业适配**：4P 可用于"婚礼服务/周边产品"的带货，但**不要把新人的真实困境当"场景冲突"去挖坑**——"婆婆不满意""婚礼当天出糗"这类痛点一旦指向真实当事人，就不是促销而是消费他人隐私。可用的是通用痛点（备婚信息过载、预算失控、流程记不住），且坑要挖到"能解决"的尺度。

## 【第 20 轮增补 · 红人星球第7节课 + 营销答疑课 1-17】

> 蒸馏来源：① 红人星球第7节课（95.9min，2020.03 推），`[63:38]`–`[64:16]`、`[79:57]`–`[91:08]`；② 营销答疑课 1-17（104.3min，2022.01.17），`[73:41]`–`[77:30]`、`[92:55]`–`[97:00]`。
> 本册已有 4P 的结构与两处修正（若鱼"顺序不固定"、少宝"坑的尺度"）。本批**只补三处此前没有的东西**：① 第四步的成本分层（显性／隐性）；② 四条可直接套的 4P 完整文案；③ 两条极窄但极好用的带货脚本——"清仓低价"与"反向操作"。

### 【红人星球 第7节课｜2020.03】4P 第四步要打两种成本：显性成本与隐性成本（薛辉）

> 蒸馏来源：红人星球第7节课，`[79:57]`–`[91:08]`。

**核心结论**：促销不是只有降价。**钱是显性成本，时间、试错、丢脸是隐性成本**；很多品类（教育、医美、服务）客户卡的不是钱，是"怕白花钱"，这时给"试听/体验/无效退"比打折有效。

> 「这块不太好理解 大家注意」「这块不是说只有钱」「只有钱是成本」「钱叫做显性成本」「还有一个东西叫隐性成本」

> 「我不在乎我给我们家宝宝报英语班花多少钱」「我在乎的是 我们家宝宝找你学了之后 学了半年会不会学得不好」「你教得太差」「那你就可以试听」「这个试听是时间成本」「时间成本不是显性成本 时间成本是隐性成本」

> 「所以你的促销活动可以给显性成本 就是钱降价」「你还可以给什么 给隐性成本」

**四步的功能定义（比"四步名称"更好用的是"四步各在解决什么"）**：

| 步 | 英文 | 他给的功能 |
|---|---|---|
| 一 | People | 「引起用户的注意」 |
| 二 | Problem | 「引发他的情绪」「情绪到了才能买东西」 |
| 三 | Project | 「给他解决这个场景冲突的办法」 |
| 四 | Promotion | 「要解决我要付出什么呀」「让你付出东西其实很少」 |

（整理者注：这条补上了 4P 最容易做错的一步——绝大多数人把第四步理解成"限时特价"，结果只对价格敏感型客户有效。**判据是：客户犹豫的是"贵"还是"怕没用"**。前者给降价，后者给试错保障。可与若鱼"顺序不固定"并读：她讲的是**顺序**可调，本节讲的是**第四步的内容**要分层，两者不冲突。）

### 【红人星球 第7节课｜2020.03】四条 4P 完整文案（可直接当模板改写）

> 蒸馏来源：红人星球第7节课，`[85:18]`–`[91:08]`。以下均为他现场口述的广告文案，逐句对应 4P。

**① 金融小额贷（价格低 + 无抵押）**

> 「刚参加工作不久的小伙伴看过来」（People）
> 「还在找朋友借钱吗」（Problem）
> 「凭芝麻信用分多少多少分就可以贷多少多少元」（Project）
> 「目前日息只需几元」（Promotion，显性成本）

他补的目标群体画像：「小额贷目标群体一般都是刚毕业大学生」「他们租房子很贵」「但是他们已经参加工作了 他又不好意思管父母要钱了」。

**② 在线少儿英语（服务型，卖隐性成本）**

> 「想要培养宝贝学英语 却又没有时间接送」（Problem）
> 「外教老师线上教学」（Project）
> 「我怕这个老师教得不好 怎么办呀」「点击领取免费试听」（Promotion，隐性成本＝试错）

**③ 婚礼纪 App（决策成本高、信息分散）**

> 「下半年准备结婚的宝宝们」（People）
> 「酒店婚纱钻戒该怎么选」「比价 比质量 比口碑」（Problem）
> 「一个 App 全搞定」（Project）
> 「目前旅拍团购中 下载 App 还送 1980 元婚礼大礼包」（Promotion）

**④ 女性向游戏 App（情绪型）**

> 「小姐姐们看过来」（People）
> 「生活中男人都是大猪蹄子」（Problem，情绪）
> 「游戏中与不同的小哥哥 发生不同的故事」（Project）
> 「苹果端限时免费下载 戳这个链接」（Promotion）

（整理者注：四条的共同点是**第二步都不是"痛"，是"此刻的处境"**——借钱不好意思、没时间接送、信息太散、现实里的男人不行。这与同批 03 册"场景冲突不是喊痛"是同一条判据的带货版。四条文案均为 2020 年前后的行业样本，具体价格/赠品已失效，只用结构。）

### 【营销答疑课 1-17｜2022.01.17】"清仓低价"脚本：先给低价找一个大家都认的理由（薛辉）

> 蒸馏来源：营销答疑课 1-17，`[92:55]`–`[96:00]`。

**核心结论**：低价不是卖点，**低价的理由才是**。他拆的这条爆款结构是：**我们被大主播坑了 → 货砸在手里 → 工人等着发工资 → 只能清仓**。四段走完，价格低得合理，还带一点道德正当性。

> 「这个结构我觉得如果你要卖货的 你可以拆一下这个片」「这个结构是 我们被谁谁谁欺负够了」「或者我们的东西被谁谁谁带货 骗怕了」「然后呢 接下来我们就想清仓卖掉它」

> 「其实是给自己的低价找一个理由」「找一个大家都认可的理由」

> 「大主播带货 清仓…」「说能带 800 件 实际就卖了 150 件」「还退回 100 件」「大过年的这 800 多件 兄弟们也不知道该怎么办了」

> 「这些工人还等着这 800 多件的…衣服发工资呢」「所以不能让工人兄弟们难做」「这个过年得带着钱回家」「我们现在就是这个东西就得清仓卖掉」

**场景选择（这条脚本成立的关键）**：

> 「你看他选的场景选得也很对」「选的是库房」「要不然就是选车间」「这些地都是好地」「原生嘛」

> 「如果你有厂家有流水线 肯定是在那说话是最有说服力的」

**适用边界（他自己划的）**：

> 「但是这个结构试用面有点窄」「得试用低价货」「还得是有厂家的人才能用这个模板」「但是如果你正好试 用这个模板会非常棒」

> 「这也没法放正价课里」「因为这个试用的领域太窄了」「必须得是清仓的货」

（整理者注：这条把"低价"从**价格事实**变成了**叙事结果**——不是因为货差所以便宜，是因为被坑了所以只能便宜。这条边界必须写清：**它要求"低价"是真的（清仓、尾货、断码）**，否则就是编故事骗人，属虚假宣传（见 07 册）。他本人也明确说"试用面窄、不能进正价课"，不宜当通用模板推。）

### 【营销答疑课 1-17｜2022.01.17】好物推荐的第一条件是"能被看见"（薛辉）

> 蒸馏来源：营销答疑课 1-17，`[73:41]`–`[77:30]`。

**核心结论**：好物推荐不火，多半不是表现力问题，是**这个商品本身拍不出画面**。数据线、纸巾、垃圾袋这类"没有可视差异"的品，怎么讲都平；玩具、奇葩小物、能出效果的品，随手拍就有人看。

他放一条点赞 179000 的玩具视频（**课堂个案陈述**）：

> 「当时我就买了一个」「点赞多少 179000 的点赞对吧」「当时我就买了一个 200 多块钱」「这就叫好物推荐」

> 「你那个好物推荐是什么玩意」「你那好物推荐都没法可视化」「我都看不到他的东西」

> 「这就叫好物推荐」「新奇特 奇葩的好玩的」「奇葩的好玩的就是爆款元素」

**反例（数据线）**：

> 「你数据线怎么能够说出他好」「你给我一个把数据线说成好的方法」

> 「大哥你数据线他怎么可能能火呢」「你要能出一个奇葩的数据线」「这边插 USB 那边分出 16 个头」「那数据线还带投影仪功能」「那你能火」

> 「因为正常数据线你告诉我 我都好物推荐」「好物推荐能火吗」

> 「你选的东西都是商品本身没法可视化的」「商品本身没法有画面的」「这肯定就不火呀」

（整理者注：这条是选品的第一道筛子，比"佣金高不高""好不好卖"更前置——**先问"这个品的差异能不能用一个镜头说清"**。能，就拍；不能，就换品或换角度（把"产品"换成"使用后的效果"）。179000 点赞／200 多元为**课堂个案陈述**，不作规律。）

### 【营销答疑课 1-17｜2022.01.17】"反向操作"：把最差的一面直接摆出来（薛辉）

> 蒸馏来源：营销答疑课 1-17，`[91:19]`–`[92:45]`。

他放一条 39 元洗浴的片子，全程只有一个"12 号技师野玫瑰"的自我介绍，评论区全在玩梗：

> 「这个就是我说的叫反向操作」「或者叫难看的和难吃的难用的」「这个特别好」

> 「啊你好我是 12 号技师野玫瑰 很高兴为你服务」「安心…就找野玫瑰」「结束了 结束了 就是这条视频点赞不少 流量也不少」

> 「然后呢那个评论里就是 哎妈呀 39 块钱就这水平了」「那 139 那不得起飞了呀」「这就叫反向操作的」

（整理者注：这条与册内"难吃难用"是同一元素，但他给了一个更清楚的机制——**反向操作的成本极低（不用拍好），收益来自评论区**。所以它的成立条件是"能引发调侃"，不是"真的很差"。若产品真的差，反向操作会变成差评聚合，不可混用。）

## 【第 23 轮增补 · 营销答疑课 2-21】

> 蒸馏来源：营销答疑课 2-21（121.8min，2022.02.21），`[49:19]`–`[51:45]`、`[95:43]`–`[100:50]`。
> 本批 09 册增量一条核心判据：**"可视化"——能被看见的效果，决定一个品类好不好拍**；外加一个可复制的晒过程模板（发货拦车随机拆箱）。

### 【营销答疑课 2-21｜2022.02.21】"可视化"：能被看见的效果，决定这个品类好不好拍（薛辉）
> 蒸馏来源：营销答疑课 2-21，`[49:19]`–`[51:45]`。

学员问"视频可视化是什么意思"，他先把定义压成一句：

> 「你的东西它得是能看出来的」「你的东西它得是我拿眼睛能看出来的东西，这个就叫可视化」
> 「视频拍的那个东西得是我能看到的东西，这就叫可视化」

然后他用四个品类做了正反对照：

| 品类 | 判断 | 他的原话 |
|---|---|---|
| 数据线 | 不可视化 | 「我今天卖一个数据线，它就不太可视化」「你说它怎么可视化，它就很难拍」 |
| 强力拖布 | 可视化 | 「你的地很脏，你一擦过去就没了，我能看到它真的没了，它就可视化」 |
| 零食 | 不可视化 | 「你说零食它怎么可视化，你就说它真好吃，我又尝不到」 |
| 袜子 | 可视化 | 「卖袜子你看就可视化，袜子好看」 |
| 挖耳勺 | 不可视化 | 「你要卖挖耳勺就很难，挖耳勺不容易被看见」 |

（整理者注：这条给的是**选品阶段的一道筛子**，不是拍摄技巧——"能不能被看见"在选品时就已经决定了一半。注意它的判断标准是"效果能否在画面上呈现"，不是"产品是否好看"：袜子好看所以可视化（视觉结果），零食好吃所以不可视化（味觉结果）。这条也能解释为什么"清洁类/改造类/测评类"在抖音特别好卖：它们的效果全部落在画面上。反过来说，不可视化的品类不是不能做，而是必须换呈现方式（把效果外化：数据线测弯折寿命、零食做吃相/声音）。这一句是整理者推论，讲师本场未展开。）

### 【营销答疑课 2-21｜2022.02.21】发货拦车随机拆箱：一个生产商可以直接借用的晒过程模板（薛辉）
> 蒸馏来源：营销答疑课 2-21，`[95:43]`–`[100:50]`。

他拆的那条草莓视频，结构是"随机拦下自己发出的快递车 → 现场抽一箱拆开"：

> 原片：「大哥先别走，那个我们给粉丝验一些货，稍微等一会」「这是我们今天发的第二车快递了，给大家随机的抽选一下，看看咱们品质咋样」
> 「就这家了，北京的贾先生，对不住了，一表歉意，一会再给你送一盒冰冻草莓」
> 「这是我们的如虎添翼礼盒，专门为虎年所设计的礼盒」
> 「都说全国草莓看丹东，丹东草莓看舅舅」「顶线农场家的九九草莓是什么样子的」「里面是金灿灿，满满的两大托盘」「都是精选的特大果，单果是在 35 克以上，每十斤才能选出来一斤」

他给的判断分三层：

> 流量层：「这条视频点赞会高吗，点赞不会高」「但这条视频完播率还可以」「所以它的流量也还行」
> 细节层：「然后有一个细节特别好，叫'贾先生对不住了'，这个细节特别好」
> 生意层：「这条视频和销售营销是不是强相关的」「强相关的」「就这条视频挂车看播放量和购买量」

他还把这个模板抽象成一句可迁移的话：

> 「如果我们是生产商，这个选题是可以借鉴的」
> 「借鉴哪个选题：发货这一刻给拦下来，随机拆一个」
> 「我不管你是卖草莓还是卖什么，总得发货，发货的时候拦下来，随机拆一个，挺好的」

（整理者注：这个模板之所以成立，是因为它同时解决了三件事——**随机性**（不是摆拍，观众信）、**公开性**（拆的是已经发出去的货，不是样品）、**歉意**（"贾先生对不住了"这一句把"我拆了你的货"变成了人情，而不是表演）。第三条是最容易被抄漏的：没有这句道歉，整个动作就变成"我在展示我的货"，而不是"我在替你验货"。这个模板对所有"有发货环节"的生意都成立，是 09 册里少数可以直接照抄的结构。）

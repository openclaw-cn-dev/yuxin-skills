# 11 · 自检清单

> 用法：不要通读。**每次只查你正在做的那一步。**
> 六道关，按顺序过；任何一关不过，不要往下走。

---

## 第 0 关 · 定位关（做号之前只做一次）

- [ ] 能一句话说清"我是谁、给谁看、看完能从我这儿得到什么"
- [ ] 变现方式已经确定（卖货 / 卖服务 / 卖课 / 接广告），不是"先涨粉再说"
- [ ] 内容定位落在四类里的一类为主（聊观点 / 晒过程 / 教知识 / 讲故事），不是四类混着发
- [ ] 有 3 个可以对标的同行账号，且已拆过至少 10 条
- [ ] 知道自己的"成交理由"是什么（别人为什么找你而不是找别人）

> 详细方法见 `01-定位与变现.md`

---

## 第 1 关 · 选题关（每条视频发之前）

- [ ] 这条选题至少命中 1 个爆款元素（成本 / 人群 / 奇葩 / 最差 / 反差 / 怀旧 / 荷尔蒙 / 头牌）
- [ ] 命中 2 个以上更好，但要能说清是哪两个
- [ ] 选题能用一句话讲完，且这句话本身让人想点开
- [ ] 不是"我想讲的"，是"他想看的"——受众明确
- [ ] 素材库里已有对应的真实素材（照片 / 视频 / 聊天记录），不是纯口播空谈

> 8 大元素的完整定义与套用法见 `02-选题与素材库.md`

---

## 第 2 关 · 脚本关（写完稿、开拍前）

- [ ] 已确定这条属于哪一层脚本（形态 / 情绪原型 / 具体写法）
- [ ] 前 3 秒有钩子，且钩子不是"大家好我是……"
- [ ] 全片只有一个转折，没有第二个
- [ ] 每一段都能回答"这段删掉会不会影响理解"——会，才留
- [ ] 结尾有明确的动作指令（关注 / 评论 / 私信 / 下单），不是"就这样吧"
- [ ] 通读一遍，没有一句是"正确的废话"

> 三层分类与 13 种写法见 `03-脚本体系.md`；句式见 `10-话术速查.md`

---

## 第 3 关 · 拍摄关（开机前）

- [ ] 景别已经定了（远 / 全 / 中 / 近 / 特），不是全程一个机位
- [ ] 场景有"生活痕迹"，不是白墙或纯色背景
- [ ] 光够，脸不黑，没有顶光造成的眼窝阴影
- [ ] 收音单独确认过（环境噪音 / 回声 / 麦克风电量）
- [ ] 手机/相机参数：1080P 30 帧起，快门约 1/80，不用美颜滤镜
- [ ] 自己先对着镜头说 30 秒，确认不尬——尬就重来，别指望剪辑救

> 训练法与指导话术见 `05-表现力与拍摄.md`

---

## 第 4 关 · 剪辑关（导出前）

- [ ] 气口（停顿、口水音、"那个""就是"）已清
- [ ] 信息密度处理过：相同的词删、意思相近的合并、重复的只留一段
- [ ] 爆点已前置到开篇
- [ ] 字幕已核对，没有错别字（自动识别必错）
- [ ] 音量统一，BGM 不压人声
- [ ] 封面单独做过，不是随手截一帧

> 信息密度 11 条手法、爆点前置 6 条、剪映 46 节速查见 `06-剪辑.md`

---

## 第 5 关 · 发布关（点发布之前）

- [ ] 标题/文案里没有违禁词、没有绝对化用语
- [ ] 没有搬运、没有未授权的影视素材、没有蹭名人肖像
- [ ] 挂车/挂链接的，转化路径自己走过一遍
- [ ] 发布时间符合目标人群的活跃时段
- [ ] 发布后 1 小时内会盯数据（完播率、前 3 秒流失）

> 平台机制、审核节点、限流原因见 `07-平台规则与运营.md`

## 第 6 关 · 投放关（决定花钱之前）

- [ ] 自然流量已经跑过一轮，知道这条的基准数据
- [ ] 投的目标明确（点赞 / 涨粉 / 主页浏览 / 转化），不是"随便投投"
- [ ] 算过单粉成本，知道自己的上限
- [ ] 只投已经验证过内容质量的那条，不投"我觉得好但数据差"的

> 投放流程、判断标准、限流申诉见 `08-投放.md`

# 附录 A · 编导班讲师反复强调的自查项

## 附二：本册的自查清单（讲师反复强调的）

**教知识四型通用四错（§8-3）**：用词专业 / 反馈过长 / 排列不好 / 对象模糊。

**晒过程三件事（§9-1）**：完播时长＞点赞量；每个节点必须有情绪曲线；起因必须挂钩子。

**故事三型通用（§11-1～§11-3）**：困境与转机是骨干、经典桥段是灵魂；二轮困境要深于一轮、二轮转机要大于一轮；苦难不能哭、重走成功路要苦中作乐。

**观点（§10-3）**：归纳论证只能选三个且必须不同；正反论证一反一正；最后一定有明确观点。

# 附录 B · 表现力自检清单

## 附：表现力自检清单

> 用法：拍完一条，逐项打勾。任一项为"否"，按对应章节回改。

### A. 内容层（§14-1）

- [ ] 这段话有明确的**交流对象**——我能说出"我是在跟谁说"（父母/同事/闺蜜/老公/客户）
- [ ] 这段话有明确的**内心视像**——我说的时候脑子里有具体画面（欠钱的原因、还钱的情节、那 2000 公里）
- [ ] 我把"借两千块钱"这类台词，分别对 3 个不同对象说过一遍，选了情绪最对的那版
- [ ] 入戏前我问过自己：认识多久？男的女的？他了解我家情况吗？我们一起抽过烟吗？
- [ ] 我没有为了"显得高端"而端着（通病一：追求高大上）
- [ ] 我没有在讲大道理（通病二：爱讲大道理）
- [ ] 我卡壳了没有停、没有重来，继续往下说了（通病三：爱背稿）
- [ ] 文案可以差，但视像和对象必须在（流水账也能看下去，没视像再好的文案也没人听）

### B. 现场层（§14-2 / §14-3）

- [ ] 拍摄前破冰了：聊过**热点事件／回忆往事／（视身份可用的）八卦**
- [ ] 我**没有**提前把问题给 IP（一有准备就像念稿）
- [ ] 我提过这五类问题：为什么／能给点建议吗／能举个例子吗／还有其他的吗／真的假的
- [ ] 我用过"找对抗"：疑问语气 + 负面话题 + 眼神疑惑加皱眉 + "这样对吗？"
- [ ] 我给过情绪回应：幽默处带笑意、悲伤处皱眉、及时语言回馈
- [ ] 我**没有**做这五件事：批评情绪／要求背稿／打断说话／说"刚才没录上"／拍摄时说悄悄话
- [ ] 我**没有**犯四大禁忌：见面开大／人形读稿器／杠精讨厌鬼／想起来就问
- [ ] 现场**没有**四周全是灯，场景让 IP 放松（咖啡店/饭店/自己的店）
- [ ] 拍完我给了具体赞美，不是"挺好的"（不放过任何一个可夸的细节）
- [ ] 我的姿态既不低（否则 IP 说教）也不高（否则 IP 没自信）

### C. 画面层（§4-1 / §5-1）

- [ ] 景别选对了：动作→中景，表情→近景，情绪最大化/细节→特写，交代环境→远景（少用）
- [ ] 没有相邻景别硬切、没有跳两级切
- [ ] 没有卡关节（手腕、肩膀、脖子、脚踝）
- [ ] 主体在画面里"谁主角谁在中间"，或人在三分线交叉点且**脸朝景物方向、反向留白**
- [ ] 前景有遮挡时是糊的，没有抢主体
- [ ] 没有顶天立地、没有面壁思过、没有喧宾夺主、没有镜头歪
- [ ] 运镜有目的：开头推、结尾拉、关系用横移、记录感用跟随、张力用环绕
- [ ] 手机：1080P / 30 帧；网格、水平已开；长按锁定了曝光
- [ ] 没有打硬光直怼脸；没有一面亮一面暗的阴阳脸

### D. 场景层（§4-2）

- [ ] **不是素背景**（不是大白墙／假书架／纯色窗帘／一扇门／纯色壁纸）
- [ ] 场景类型选对了：要专业感→包装型；要人设/信任→生活化
- [ ] 场景和选题匹配：私密话题没在大庭广众说
- [ ] 越专业的内容，场景越生活化
- [ ] 这个景能让人**信服我说的话**（原生感定义）
- [ ] 对得上五句口诀：科普当闲聊／揭秘要悄悄／对镜头是爆料／高端优雅舍掉／生活原生见效

### E. 原生感层（§4-3）

- [ ] 是**第一人称**，不是第三人称旁观（"我在干"而不是"我在看"）
- [ ] 手机放在脸前，**脸—眼睛—手机三点固定**，眼睛动镜头才动
- [ ] 是"指哪打哪、看一眼就收回"，不是"慢慢展示"
- [ ] 没有镜头调度/视角切换（一镜到底或连续视角）
- [ ] 是"说拍就拍"，没有喊"等一下打光""等一下准备"
- [ ] 没有用云台
- [ ] 没有刻意找景、没有刻意摆构图（打破景别/构图/运镜）
- [ ] 允许带点糊（"带点糊才更真实"）
- [ ] 角度够怪/够新（包里、桌下、肩后、偷拍位）
- [ ] 看完这条，观众会觉得"这个男的就是我"

### F. 表达层（§5-3，进阶自检）

- [ ] 光线上有没有"阵营/内心/希望"的暗示，而不是平均照亮
- [ ] 有没有用高低、面积、背景整洁度、框架、遮挡交代人物关系
- [ ] 该迷茫/抗拒的地方，有没有用虚焦而不是台词硬说
- [ ] 该失衡的地方（醉酒、混乱、反派），画面有没有倾斜
- [ ] 每句话都问过：这句是**写实**（说什么拍什么）还是**写意**（脑中的那个画面）？写意的句子有没有配落叶/烟头/飞机这类镜头

# 附录 C · 剪辑常见错误（讲师点名批评的做法）

### 八、剪辑的常见错误

> 全部为讲师在课上点名批评的做法，按出现位置归并。

**A. 素材阶段（§1-3、§15-1）**

1. **不浏览素材就开剪**——"你不能说你剪一半之后，发现视频不对，那你之前白剪了"。
2. **不擦镜头**——画面糊，"你们拍摄之前一定一定一定要擦镜头"。
3. **不试麦**——"麦这个东西它有时候抽风，这个时候它可能就会录不上"，整段素材作废。
4. **环境噪音太大还不补录**——降噪无效就必须补录。
5. **构图整体偏歪**。

**B. 剪辑阶段（§1-3、§3-2）**

6. **气口没剪干净就先加音效/特效**——"但凡中间哪一个气口没剪好、挪一下，你这个音效它就串了"，"只能重剪"。
7. **素材放太靠下被字幕挡**——"图片位置放的这个地方，压根就没想让我们看，会被文案挡"。
8. **贴纸没有功能**——既不框选也不指向，"一点用处也没有"，还抢注意力。
9. **音效跟内容不相关**——"那个恐怖音效都上来了，跟你说的这个内容不相关"。
10. **每句字幕都加动画**——"所有的都是重点了，不就没有重点了吗"。
11. **字幕太小、位置贴边**——"都快放那个车的门缝里面了"。
12. **两三秒一个硬切景别、没有目的地乱动**——"你这个视频太乱了，没到重点的时候就开始在画面上一顿动弹，人家看着都会闹眼睛的"；正确做法是"有重点的时候可以硬切景别，但是别两三秒一个"。
13. **一秒加三四个音效**——"已经不知道"（在听什么了）。
14. **字体颜色太花**——"不要超过很花花"。
15. **剪辑过度**——"学会了各种各样的技能之后，我什么都想往这个视频里加，不是这样的，我们一定要注意这个剪辑的度"。
16. **人物特效滥用**——"尤其是人物特效那些什么激光眼、分头行动，如果你跟你的老板在拍摄的时候，尽量少用"。

**C. 封面阶段（§3-3）**

17. **封面用 9:16**——字被裁掉看不见，应为 3:4。
18. **封面不露脸**——无法完成"识别内容信息"。
19. **封面跟内容无关**——标题和画面两回事。
20. **封面文案太长**——"一眼我就看不清他到底写了什么"。
21. **字体颜色靠色**——缩到主页九宫格里就糊成一片。

### 【拆片会 2025.03.18 / 2025.03.25】开拍前 10 问（笑笑 / 大龙 / 小西 / 董华 / 小峰 / 志鑫 六人汇总）

> 蒸馏来源：25年11月最新allin编导团队拆片会及往期13+16节/04、【2025.03.18】.mp4；05、【2025.03.25】.mp4

**A. 定位与变现（先问这 3 个，答不上就别拍）**

1. **观众看完知道我是干什么的吗？**（三场拆片会最高频的差评是"不知道他干啥"——小峰、董华各说过一次）
2. **这条片的流量和咨询是一回事吗？**（董华：180 万播放零咨询，39 万播放每天 20–30 咨询）
3. **有没有留 10% 的身份露出？**（董华：「内容 90% 要用这个热点去输，最后那个 10% 只需要让他知道你是做什么就够了」）

**B. 脚本（问这 3 个）**

4. **有没有一个"反差"？**（志鑫：「一个视频可以没有头没有尾，但是必须要有情绪」；反差是情绪的开关，如"上钟了"）
5. **开头第一句是自夸还是自嘲？**（大龙：「你上来说牛逼别人不看」——必须走自嘲或"劣势转优势"）
6. **结尾的情绪是上扬还是下坠？**（志鑫：「如果最后你的结尾还是松垮下去……我就没有一个想给你点赞的冲动了」）

**C. 呈现（问这 2 个）**

7. **制景 / 服装 / 道具，能不能让人一眼看出行业？**（小西：草地 + 道袍 + 草药；反例："你一个干装修的去草地里拍，那不合理"）
8. **有没有一个"低成本具象化"的道具？**（小峰：折纸模拟皱纹、橡皮筋模拟弹弓发力、小车模拟重心转移）

**D. 交付（问这 2 个）**

9. **写分镜了吗？**（小西：「没有写分镜……临时现拍的」「剪的时候也很费劲」）
10. **AI 出来的文案改过了吗？**（三人共同警告：「它出来的这个观点你不能直接用」「你直接用它太弱了」）

（整理者注：这 10 问里，1、2、3 是"能不能变现"，4、5、6 是"能不能爆"，7、8 是"像不像内行"，9、10 是"能不能交付"。四组各自独立，任何一组挂了都会拖垮整条片。）

### 【拆片会 2025.04.01】开拍前的五问：这一条踩中了哪一个（上香 / 辉辉）

> 蒸馏来源：25年11月最新allin编导团队拆片会及往期13+16节/06、三大体系成就百万大V薛辉编导团队拆片会【2025.04.01】.mp4（上香约第 0–25 分钟，辉辉约第 25–47 分钟）

上香在结尾把五个招数复述了一遍，可以直接当拍摄前的自检表用：

1. **是不是"人生第一次"？** ——「第一次买什么东西，或第一次干什么事，选 A 还是选 B」「第一次干什么不丢人有面子」「第一次干什么怎么避坑」「第一次干什么怎么省钱」「人生第一个什么什么东西怎么选」
   - 追问：我问的这个问题，是不是客户掏钱前最纠结的那一步？
2. **是不是揭秘了行业内幕？** ——用什么视角？「偷拍视角，对，全程记录」
   - 追问：我有没有把行业的环节捋完？有没有替客户先问一遍？
3. **是不是"扮猪吃老虎"？** ——「其实也是一个内行人，我应该怎么做，也是偷拍视角」
   - 追问：我提的要求够不够专业？我有没有拒绝对方给的方案？我有没有给对方留回话空间？
4. **是不是"最容易花冤枉钱的地方"？** ——「你们行业最容易花冤枉钱的地方在哪儿，给他说出来」
5. **是不是"我最讨厌的城市"？** ——「打一下你们的同城流量」

辉辉那条线补一个自检项：

6. **这条有没有反差？** ——人、事、物三格，至少一格是"奇怪"的；如果有，落位到六类型（形象/场景/身份/行为/年龄/道具）中的哪一类？
   - 追问：反差之后有没有接"晒过程"？没有接，就只是流量片，挂不上货。

（整理者注：第 1–5 项是选题层自检，第 6 项是元素层自检。两层的区别是——选题决定"有没有人关心"，元素决定"划到会不会停"。两条都过，才值得开拍。）

### 【拆片会 2025.04.29】脚本自检三张表（小畅 / 马宁 / 司祺）

> 蒸馏来源：25年11月最新allin编导团队拆片会及往期13+16节/10、三大体系成就百万大V薛辉编导团队拆片会【2025.04.29】

#### A. 找借口 / 观点类脚本（小畅）

1. **开篇是不是一个具体的小缺陷？** 不是"你要努力"，是「为什么你因为一点小事就发脾气」。
2. **过错方有没有落地到三个方向之一？** 原生家庭 / 社会环境 / 亲密关系——三选一，不要含糊成"这个社会"。
3. **有没有"困扰"这一段？** 只有归因没有困扰，观众不会疼；困扰要具体到行为（「你就恐惧、你就焦虑不安」「像小孩一样去哭闹、去摔东西」）。
4. **结尾给的是情绪价值还是方法？** 这类脚本以情绪价值为主（「这跟你没有关系」），方法最多一句。
5. **开篇观点是不是自己硬想的？** 若是，改用「现象 + 找人背锅」从对标里拆（见 02 册）。

#### B. 暴露脆弱类脚本（马宁）

1. **暴露的是"用户也有的毛病"，还是"用户羡慕的成就"？** 只能是前者。
2. **第一段有没有细节？** 禁写"我很焦虑"，要写「不爱说话、不爱出门、没有胃口、没有精神」。
3. **感官用了几种？** 只能是两种。五种全上＝观众疲劳。
4. **第二段有没有"放纵逃避 → 积极面对"的对比？** 没有对比＝没有情绪曲线＝完播崩。
5. **是不是"一下就解决了"？** 是就重写——「你别我一下子就解决了、释怀了，那没有人爱看」。
6. **第三段是不是正向？** 释怀/和解/打败都行，停在躺平不行（平台偏好见 07 册）。
7. **有没有靠演技硬哭？** 有就换素材——「需要非常好的演技」且「也没有什么人设」。

#### C. 实体店 / 本地生活类脚本（司祺）

1. **开篇是不是两个悬念？** 人物一个、店铺一个，缺一个都弱一半。
2. **人物悬念有没有和行业绑定？** 「最想碰到的花艺师 / 学长 / 营养师」——绑不上就是空悬念。
3. **店铺悬念有没有套"15 个经典理由"？** 选择多 / 效果好 / 好评多 / 生意好，四选一。
4. **身份反差写了吗？** 离职、放弃百万年薪、放弃体制内、离开大城市、放弃十年专业技能——五选一。
5. **开店原因里有没有行业乱象？** 有乱象才有立场；只写"我喜欢"＝没有对立面。
6. **卖点是不是具体数字？** 「月卡 200 到 600」「不会健身 700 一个月，随时来」。
7. **结尾有没有升华到"意义"？** 「任何时间都不晚」这类，是把价格问题转成价值问题。


### 【拆片会 2025.09.06】信息密度自检：发布前过一遍这七问（达文西）

> 蒸馏来源：25年11月最新allin编导团队拆片会及往期13+16节/11、三大体系成就百万大V薛辉编导团队拆片会【2025.09.06】（达文西，约第 95–118 分钟）

1. **每 2–3 秒有没有换东西？** 参照卖伞片：15 秒 6 个卖点，平均 2–3 秒一个信息点。
2. **有没有做到"三秒吸睛、五秒转场、八秒反转"？** 注意是"每隔"三/五/八秒，不是"第"三/五/八秒。
3. **开篇头两秒有没有一个"不经意的小动作"？** 关键帧缩放、甩镜头、水滴音——「至少让你们的两秒跳出率降低10%」。
4. **文案里还有没有废话和语气词？** 要删的具体词：「嗯、啊、唉、呦、呵」。知识类脚本要"短平快"。
5. **背景是不是大白墙 + 白 T 恤？** 是就重拍——「信息密度没有」。
6. **人动不动、画面动不动？** 至少有一个要动，「一定不要做的是人不动、画面也不动」。
7. **十秒一轮回做了吗？** 开篇那套技巧（画面/行为/视角/运镜/音效）每 10 秒循环一次，直到片尾。

补充一条时长判断：**不要问"该拍多长"，要问"信息够不够密"**——「爆款短视频、爆款长视频，等于的是信息浓缩的密度」。

### 【拆片会 2025.09.06】实体店 / 老板号脚本自检（小西 / 大龙）

> 蒸馏来源：25年11月最新allin编导团队拆片会及往期13+16节/11、三大体系成就百万大V薛辉编导团队拆片会【2025.09.06】

#### A. 营销员工类（小西）

1. **主角是员工还是老板？** 老板出镜讲自己＝跑偏，这条脚本的核心是"营销别人"。
2. **第一段用的是"大家都知道……那你见过……吗"吗？** 常见职业 + 反常事实，缺一个都不成立。
3. **有没有外在形象 + 一个具体动作？** 「起球的黑秋衣」「炒完菜往角落里一蹲」「看他那个成年老动漫」。
4. **有没有行为矛盾？** 「身边的人早就自己出去做买卖了，他还是十年如一日地跟着我」——这句可以反复用。
5. **关键节点写的是细节还是辛苦？** "从沈阳飞到湖南"没用，要写"试了多少遍、找了多少材料"。
6. **结果能不能是坏的？** 可以，而且坏结果更好——留得下一条"我转型成功了"。
7. **有没有老员工？** 没有就改拍"上班体验"版（身份+场景+冲突点 → 核心任务 → 分项拆解 → 夸运营 → 升华）。

#### B. 客户至上类（大龙）

1. **三段齐了吗？** 反面事件 → 正确做法 → 升华。
2. **反面事件是不是"自己人做错了"？** 服务员说"差不多"、新人切得稀碎、空调没开——错在自己人才有反转空间。
3. **正确做法有没有给"标准"？** 「精确到毫米」「理论+实操都过才能上岗」「10 倍赔付」——标准越硬越可信。
4. **事件是从 90 个里挑的吗？** 员工 / 产品 / 日常三个方向各 30 个，挑不出来说明经营动作本身缺。
5. **升华是不是一句能被截图的话？** 「我们做生意最害怕的就是抱着差不多的态度」。


### 【拆片会 2025.10.03】交片前自检：先按口诀自剪，再找人要点睛（司祺，ASR 记作"死因老师"）

> 蒸馏来源：allin 编导团队拆片会 2025.10.03（开场段）。他的规则是"学员先过一遍，老师只提一层"。

**三条剪前自问**（来自他对"买单哥"那条视频的拆解）：

1. 该谁说话，我有没有**放大谁**？
2. 该慢的地方，我有没有**真的慢下来**？
3. 整条片子的情绪，是我用剪辑**控**出来的，还是让它自然流过去的？

**他的验收口径**：「如果你的视频里都做到了，我给你提升；如果没做到，请你自己改。」他说这套口诀「节省了我 80% 的回复时间」。

**顺序不能反**：先自剪到"基本成型"，再去找人提亮点。「如果这个视频剪得就巴拉杂几，我给你亮点就用不上。」

**补充：口播有没有呼吸点。** 看有没有留一两个情绪分镜（笑场、叹气、语气词）——「当你加了这种情绪分镜，观众有一个呼吸缓和点」。

> 整理者注：`11` 册原有的"开拍前五问/十问"管**拍之前**，这一条管**交之前**，两条一起用才闭环。

### 【拆片会 2025.10.03】故事型视频交片前三查：给钱了吗、素材真吗、困境对得上吗（大卫老师）

> 蒸馏来源：allin 编导团队拆片会 2025.10.03（末段）。

| 查什么 | 不合格的样子 | 他为什么说不行 |
|---|---|---|
| 结局有没有给钱 | 主角塞钱、对方收下 | 「如果你写给钱了，那么这个脚本就垮了，这个脚本直接就垮了」 |
| 有没有实拍素材 | 纯口播讲一个被帮助的故事 | 「他会显得假，会觉得你的故事是编的」 |
| 困境与帮助对不对得上 | 没钱吃饭却收到一箱油 | 「你们要一一对应」 |

**再查一条：恶意有没有写**。「当你们面对陌生人帮助的时候，一定要第一时间往人性最卑鄙的那一面去想……然后这一刻说完了之后，一定是马上被打脸。」没有这段揣测，后面的"人性光辉"就没有落点。

> 整理者注：这条检查表的本质是**防止故事太完美**。三个不合格项的共同点都是"太顺"——给钱太顺、口播太顺、帮助太顺。故事要成立，必须有一处不顺。

### 【先导课｜日期未标注】交片前问一句：观众有没有"任务线"（薛辉）

> 蒸馏来源：薛辉进阶课「敢为人先」先导课（转写 119 分钟）。他给学员改脚本时最常说的一句话就是"你的故事，观众没有任务线"。

**三问（按他讲人物关系的顺序）**：

1. **这条内容里，谁是弱者、谁是强者？** 没有强弱就没有站队。「因为公公和儿媳妇人物关系也天然有强弱，我们的任务线和价值主张都出来了：我们要保护弱者。」
2. **观众看完会希望谁赢？** 「我在这个视频里，我开始希望着这个主角能赢——你希望这个主角能赢，这个任务就行。」
3. **观众会不会替某一方说话？** 「你这个公公怎么能欺负儿媳妇呢」——这句吐槽就是价值主张成立的证据。

**如果是"教"类内容，再加一问**：有没有给"教的人"一个身份？「奶奶教你怎么做凉拌蒜茄子，他就加一句话叫'奶奶教你'……你感受到的不是学菜，你感受到的是温馨。」

**如果是"秀"类内容，再加一问**：有没有一个反派/参照物？「你的傲慢不要给观众看，你的傲慢你得（挂）一个反派，加一层什么关系，让观众看热闹。」

**一个低成本自测法**：把文案全部遮住，只看画面里的人物，能不能看出"该帮谁"。看不出，就不是文案问题。

> 整理者注：这条与 `11` 册"开拍前五问/十问"不重复——那些问的是"这条能不能拍"，这条问的是"这条有没有人看下去"。建议放在最后一道关。

### 【往期拆片会 8-09｜2025.08.09】三张表：开拍前 / 剪辑后 / 拆片时（编导团队）

> 蒸馏来源：往期拆片会 8-09《三大体系成就百万大V》薛辉编导团队拆片会（转写 109.8 分钟）。本场五位讲师各自给的方法，都能落成勾选项。

**表一 · 开拍前（表现力）**

- [ ] 这个人现在是不是"端起来"了？（判断依据：第一句话录了几遍）
- [ ] 有没有办法让他忘记镜头？（用家乡话/用偷拍机位/让他边走边说）
- [ ] 这条片子的素材里，有没有"当时没打算拍"的花絮？如果没有，机器先别关。
- [ ] 如果拍的是"不剪辑/不规划"类，花絮段和正片段的**区分手段**定了吗？（滤镜 + 音乐，二选一不够，要两个一起）

**表二 · 剪辑后（呼吸感）**

- [ ] 每一处放大，是否对应一个正向情绪点？（重点/冲突/递进/高潮）
- [ ] 每一处缩小，是否对应一个负向情绪点？（逃避/难过/崩溃）
- [ ] 有没有"一会放大一会缩小"却没有情绪依据的地方？删掉。
- [ ] 慢放是否只出现在情绪最顶峰？没有共鸣的地方慢放会尴尬。
- [ ] 定格是否只用于搞怪/无厘头？尴尬有没有"细节化放大"（同一个动作切三次）？
- [ ] 换角色/回忆处，有没有用滤镜做区分？
- [ ] 全片自问一句：这些切点是为观众情绪服务的，还是我自己想切？

**表三 · 拆片时（七问 + 一问）**

- [ ] 内容类型是什么？
- [ ] 细分叫什么？
- [ ] 主题IP怎么命名？
- [ ] 差异化在哪？
- [ ] 写作对象门槛高不高（要不要网感）？
- [ ] 脚本结构分几步？
- [ ] 有哪几个点能直接拿走？
- [ ] **风格与题材分开了吗？**（这一问是薛辉补的，最容易漏）

（整理者注：表三的第八问是这套表的关键。前七问填完，很容易得出"要慢、要黑白、要用四三拍"这种结论——那是风格，抄了不成立。第八问逼你把"题材"单独拎出来，才是能迁移的部分。详见 `04` 册「风格与题材必须分开」。）

### 【往期拆片会 8-16｜2025.08.16】三张新表：毛边 / 期待点 / 说教感（编导团队）

> 蒸馏来源：往期拆片会 8-16《三大体系成就百万大V》薛辉编导团队拆片会（转写 115.9 分钟，七位讲师）。本场主线是"期待感"和"毛边"，两件事都能落成勾选项。

**表一 · 毛边（剪辑时逐段过）**

- [ ] 这段我原本想删的理由是什么？如果只是"不够好看/不够专业"，把它列为候选毛边。
- [ ] 全片有没有留一处**尴尬的微表情**（笑场、绷不住）？
- [ ] 有没有留一处**停顿/咂嘴/找词**的空档？
- [ ] 有没有留一处**紧张的小动作**（摸鼻子、手不知道往哪放）？
- [ ] 留的这几处，是不是都**打断了节奏**？（只画质差、内容空的，不算毛边，删。）
- [ ] 全片自问：这条片子里的我，是不是比本人"更优秀"？如果是，加一处毛边。

**表二 · 期待点（数得出来才算）**

- [ ] 开头那一句，观众是不是"知道有事、但不知道是什么事"？（卖关子的定义）
- [ ] 全片数得出几个"观众想知道结果"的点？**1 个是及格，3–4 个是头部。**
- [ ] 第一个结果出现的时间点在第几秒？如果 30 秒内就兑付完了，后面靠什么撑完播？
- [ ] 兑付前的那几段，每一段还在给新信息吗？（只等不给，叫拖，不叫拉完播）
- [ ] 有没有"策划了但没兑现"的点？如果有，它有没有被剪成一条副线（而不是硬塞进主线）？

**表三 · 说教感（知识类专用）**

- [ ] 场景是"讲台"还是"副驾驶"？（私密空间 = 陪伴者位置）
- [ ] 每隔两三句有没有一个问号？
- [ ] 每一个知识点后面，有没有跟一个**大范围人群都经历过**的具体场景？
- [ ] 有没有先用反问代替直接回答？
- [ ] 有没有先给一个"不明觉厉"的短句，再解释？
- [ ] 有没有**先点出错误做法，再给正确做法**？（只讲对的，观众没有参照系）

（整理者注：表二的第 3 条是这场最实用的一个检查项。多数人做不出完播，不是节奏慢，是**兑付太早**——30 秒就把结果给了，后面全是废话。反过来，兑付太晚又没有中途信息，就变成拖。中间那几十秒必须一直在给"过程信息"（形态、刀工、别人的反应），这是皮佑那条四分钟片子成立的原因。）

### 【往期拆片会 9-27｜2025.09.27】商家脚本的三张自检表（则希／渣男／金句讲师）

> 蒸馏来源：往期拆片会 9-27，三位讲师各自给了一页"可截图"的检查表，此处合并成三张。

**表一：教吃法／教程类脚本（则希给的硬指标）**

| 检查项 | 合格线 |
|---|---|
| 工具 | 「工具要谁家都有」 |
| 原料 | 「原料要三种左右」 |
| 步骤 | 「步骤要五步以内」 |
| 成品 | 有没有放在开头（「你放在开头，大家没见过呀，你是不是就完成了黄金三秒了」） |

**表二：质检／验货类脚本（则希给的四个"别"）**

| 检查项 | 不合格的表现 |
|---|---|

**表三：结尾金句（金句讲师给的五个特点）**

| 检查项 | 不合格的样子 |
|---|---|
| 短小精悍 | 超过两句话 |
| 朗朗上口 | 念出来拗口、要停顿换气 |
| 一针见血 | 只是陈述，没有观点 |
| 打破预期 | 说的是大家都知道的那半句（"念念不忘，必有回响"） |
| 引人深思 | 听完没有任何"对啊"的反应 |

她的用法说明：「当你们（找）的金句不符合上面这五种技巧的时候，放弃掉，那个不是金句，或者说那个金句不适合你。」

（整理者注：三张表里最容易糊弄的是表二——因为它检查的是"有没有作弊"，而作弊的收益在短期是正的。但这条脚本的全部价值就建立在"没作弊"上，一旦切镜，前面所有铺垫归零。所以表二应该放在发布前最后一道，而不是拍摄时想到才做。）

| 环境音 | 让视频更真实 | 画面像在棚里 |
| 背景音乐 | 定情绪 | 观众不知道该用什么情绪看 |

**他给的判断句**：「你要去看一下环境（音）为你起到的是（正向）作用还是反向作用。」——反向的定义是「我说话都听不清」。

（整理者注：这张表的价值在最后一列——它把"要不要加"变成了"不加会缺什么"。剪辑时如果某一层答不出"缺了会怎样"，那一层就是多余的，删掉反而更干净。）

### 【营销答疑课 2022.01.03】上镜三查与开篇两查（薛辉）

> 蒸馏来源：`往期所有课程/【薛辉：三大体系成就百万大V-营销答疑课】11节/《三大体系成就百万大V》营销答疑课1-03.mp4`，98.2 分钟，薛辉讲授。本节是把他在拆片段用的判据抽成可勾选的表，判据原话见 05 册与 03 册同批次章节。

#### 一、上镜三查（发之前，关掉声音看一遍）

| # | 查什么 | 不合格长什么样 | 判据出处 |
|---|---|---|---|
| 1 | **眼神有没有聚焦** | 眼睛发飘、没有神气 | 「你看一个人他两个眼睛中都没有聚焦 这个人没有精气神」 |
| 2 | **脸和内容对不对得上** | 讲委屈的事在微笑、讲震惊的事面无表情 | 「你说这件事的情绪是不对的 你怎么能微笑呢」 |
| 3 | **画面还有没有颜色** | 整片发白、红不是红、黄不是黄 | 「右边这个视频他整个全是白的 所以你就会觉得他不好看 因为他不真诚」 |

三查全过，再开声音听第四项：**有没有"想说"的欲望**（「台词写好了我把台词背下来 但这件事跟我没关系」＝不合格）。

#### 二、开篇两查（只看前两句）

1. **这两句和主题有关吗？** 无关即废话——「就是跟这个主题完全不相关的 就叫废话」。典型废废话：「今天去我一个朋友家吃饭」「然后吃饭的时候呢」「我是你们朋友老齐」。
2. **删掉这两句，第一句还成句吗？** 成句就删。他给的示范是直接从冲突句进：「为什么有些男生各方面条件都一般 却能找到一个很优秀的女生?」

（整理者注：第 2 条是整理者把他的话操作化的判法，他原话是「它分明可以从第三句话直接开始进」。）

#### 三、文案两查（写完，读一遍出声）

1. **这句话我能不能"说出来"？** 说不出口就是模板感——「你别拿笔写,一拿笔写就容易出现模板化」。测法：不看稿，把这段讲给一个人听，讲出来的版本才是能用的版本。
2. **开头给的是"他早就知道的"还是"他不知道的"？** 前者零获得感、必划走——「上来先说态度真诚会被划走的」「因为没有获得感」「大家都知道态度真诚」。

#### 四、定位卡住时的一查

问自己两个数字：**想过几个定位？做了几个？** 他的原话是「他分明有五个定位 他就是不做 他就要想第六个定位」「我说你想了九个定位 你做一个 你去把钱赚了」。

（整理者注：想过 ≥3 个而做了 0 个，问题不在定位，在执行；此时不该再讨论赛道，应该按 01 册"日百三层填空"直接填死三层开工。）

## 【第 20 轮增补 · 红人星球第7节课 + 营销答疑课 1-17】

> 蒸馏来源：营销答疑课 1-17（104.3min，2022.01.17）。以下七查全部来自他当场逐条判片的口径，按"从最外层到最里层"排序，与册内已有的"上镜三查／开篇两查／文案两查／定位一查"互补，不替代。

### 【营销答疑课 1-17｜2022.01.17】发布前七查（薛辉）

> 蒸馏来源：营销答疑课 1-17，`[41:37]`–`[73:33]`。

**第一查：开篇和选题是同一件事吗？**

他把"开篇跑偏"叫「驴唇不对马嘴」。病例：选题「如何在 60 秒内快速入睡」，第二句却是「我是子龙 一个 92 年的北漂男生 在北京工作四年多」。

> 「我当时我看到这个选题 我觉得这个选题特别好」「我觉得这是一个爆款选题」「结果第二句话直接给我干懵了」「驴唇不得马嘴」「就是怎么能想到往这个方向贴的呢」

（整理者注：这是七查里最容易漏的一条——**选题对、开篇错，等于没选题**。检查动作：把开篇第一句和选题并排写，问"这两句在说同一件事吗"。）

**第二查：开篇有没有报时间？**

> 「我特别不喜欢你们写故事的时候 出现这种东西 叫时间」「98 年的时候啊」「只要这个时间线一出来 你们是不是就觉得 我操这姐妹要开始长篇大论了」

**第三查：有没有"二次开篇"？**

病例：幼儿园行业秘密，开头已经把话说完，第二段又重新起了一遍。

> 「开片这都交代完了」「为什么回来还要再来一遍开片呢」「就像他第二个开片 又开片一次」

**第四查：一句话有没有录成两段？**

> 「一句话说不通顺 就多录几遍」「别一句话都录两段」「你看刚才你有一个句话是 一句话录成两段」「那就太挑了」

**第五查：画面比例对不对？**

> 「不要拍这种比例奇怪的视频」「你要不然就拍竖版 你要不然就拍横版」「老有人拍这种上下带个黑边的版本」

**第六查：滤镜关了吗？颜色还在吗？**

> 「白不等于美」「蓝是蓝 黄是黄 黑是黑 白是白 这才叫美」「你那个一片白胡的 那不叫美」
> 「它只是磨皮 但它不加滤镜」「所以你会看到它的绿色 你会看到它的蓝色 它是本身的颜色」

**第七查：音乐是配角还是主角？**

> 「为什么要用这个背景音乐」「有点硬核」「音乐不合适」
> 「音乐赢了」「儿童用这个音乐」
> 「音乐的音量有点大」「音乐的音量再小一点」

（整理者注：七查可压成一句口诀：**同一件事、不报年份、不重开、不断句、竖或横、不压色、乐让位**。前四条管"信息能不能被听懂"，后三条管"画面像不像真的"。与册内"开拍前十问"的区别是：那十条在**开拍前**问，这七条在**导出前**问，是同一流程的两个闸口。）

### 【营销答疑课 1-17｜2022.01.17】"磨叽"的判定：第一件事没讲完就进第二件（薛辉）

> 蒸馏来源：营销答疑课 1-17，`[62:02]`–`[66:20]`。

他批一条中老年向的"人生感悟"，全程只有一个判词——磨叽。具体位置：

> 「第一件事还没讲完呢对吧」「跟你第二件事就连个踪影都没有」「怎么那么磨叽啊」

> 「太肤浅了 会滑走的」「因为知道你的事情太多了 所以就害你很深」

（整理者注：这条给了"磨叽"一个**结构定义**，不是"语速慢"，是**一件事没闭合就开下一件**。所以解法不是加速，是**数一下这条片子里有几件事、每件事有没有结论**。同批 05 册"一加速就不真诚"正是这条的反面：加速治不了磨叽，只会让它更假。）

### 【营销答疑课 1-10｜2022.01.10】发布前的"五秒判死"七条（薛辉）
> 蒸馏来源：`往期所有课程/【薛辉：三大体系成就百万大V-营销答疑课】11节/《三大体系成就百万大V》营销答疑课1-10.mp4`（109.4min，薛辉主讲；`[38:39]`–`[107:00]`，从约 30 条拆片的判词里归纳）

这不是他列出的清单，而是他全场**反复用来一句话否掉一条片子**的七个点。按他判词的出场频率排序：

| # | 判死点 | 他的原话 | 判定阈值 |
|---|---|---|---|
| 1 | 死盯镜头 + 面部无情绪 | 「眼睛一直盯着人，就会给人感觉这个人很呆板」 | 全程视线不偏移即判 |
| 2 | 板着站 / 手没处放 | 「你这么板着站，你又这么盯着我，真的很难受的」 | 站姿对称、双手垂放即判 |
| 3 | 礼貌性微笑 | 「礼貌性微笑看出来了吗……太假了」 | 全程同一种微笑即判 |
| 4 | 模板感台词 | 「三个小妙招预防红屁屁，他的模板感特别重，特别套路」 | 出现"三招/以下三点/记得点赞收藏"即判 |
| 5 | 滤镜过白（颜色不正） | 「白不代表美，美的前提是真」 | 画面里找不到正红/正蓝/正黄即判 |
| 6 | 加速超过 1.2 倍 | 「只要你的视频加速超过 1.2 倍，你的视频就一定会假」 | 1.1 倍为上限 |
| 7 | BGM 盖住人声 | 「背景音乐太大了，太噪了，听不见也不想听」 | 听不清人声即判 |

（整理者注：这七条的共同点是**都能在 5 秒内判完，且不需要听内容**。所以用法是"关掉声音看前 5 秒"查 1/2/3/5，再"只听声音"查 4/6/7。与册内已有的「上镜三查」「发布前七查」不重复：那两份是**内容层**检查（说什么），这份是**信号层**检查（看起来/听起来像不像真人）。）

> 蒸馏来源：`往期所有课程/【薛辉：三大体系成就百万大V-营销答疑课】11节/《三大体系成就百万大V》营销答疑课1-10.mp4`（`[36:05]`–`[37:06]`、`[38:07]`–`[38:14]`）

> 「做完视频之后可以自检一下，拿情绪曲线图」
> 「它是每三秒给自己的视频画一个情绪曲线」
> 「你说这三秒别人看了没情绪，那就划走了」
> 「如果是真人口述，就会三秒一个情绪点；如果是视频加配音，可以五秒一个情绪点」

（整理者注：整理成可执行的三步——①按口播 3 秒 / 视频加配音 5 秒把时间轴切格；②每格写一个词（惊讶/心疼/爽/好奇/愤怒）；③**连续两格写不出来就回去改脚本**，不要靠剪辑救。第三格之后的空格最危险，因为那是观众已经准备划走的区段。）

> 「教知识要能让老太太都能听懂，所以你不能出现专业词汇」

（整理者注：他给的反例是"全国 40 个限购城市"——这类内容"只有房产行业的公务员需要学"。所以这一查放在**选题阶段**做，不是写完再改：写下选题后问一句"我妈会问这个吗"，答不上来就换题。与 02 册同批条目互见。）

## 【第 22 轮增补 · 营销答疑课 12-20 / 12-06】

### 【营销答疑课 12-20｜2022.01.20】自嗨的三步自查：换位、打分、扔群里（薛辉）
> 蒸馏来源：`transcripts_all/往期所有课程__薛辉_三大体系成就百万大V-营销答疑课_11节__三大体系成就百万大V_营销答疑课12-20.mp4.txt`（`[29:35]`–`[30:00]`）

学员问"自嗨怎么自查"，他答得很短：

> 「自嗨自查就别自嗨呗」
> 「站在别人角度想想问题」
> 「画那个情绪曲线图吗——画个情绪曲线图，自己给自己打个分」
> 「扔群里让大家拍拍转」（按上下文应为"拍砖"）

（整理者注：三步对应三种失效模式，顺序不要颠倒。①换位解决"我以为有意思"；②打分解决"我觉得还行"（把感觉变成数字才有比较）；③扔群里解决"我和我朋友都觉得好"（熟人会给面子，陌生人不会）。第三步的关键是"群"要选对——同学群/同行群才有效，家人群无效。）

### 【营销答疑课 12-06｜2022.01.06】情绪曲线自检的升级版：每 3 秒标"情绪类型"，不只标"有没有"（薛辉）
> 蒸馏来源：`transcripts_all/往期所有课程__薛辉_三大体系成就百万大V-营销答疑课_11节__三大体系成就百万大V_营销答疑课12-06.mp4.txt`（`[91:09]`–`[92:26]`）

> 「我给你们做一个情绪曲线图，然后你把你的视频放在这个情绪曲线图里面」
> 「每三秒，给自己打一次分」
> 「假如说每一个是十分，然后你可以每三秒打一个」
> 「这三秒我会有好奇的情绪，这三秒我会有实用的情绪，这三秒还是实用的情绪，这三秒还是实用的情绪，最后是共鸣的情绪」
> 「然后去抓这个情绪曲线」

（整理者注：与 1-10 那场的「三秒一个点」相比，这条多了**类型标注**——不只是"这 3 秒有没有情绪"，而是"这 3 秒是什么情绪"。差别很实际：全是"实用"的片子会闷（信息密度够但没有起伏），全是"好奇"的片子会散（钩子多但没落点）。可执行的表格：时间｜情绪类型｜分数（1–10）｜这一格靠什么撑（一句话/一个画面）。连续两格同类型且分数不升，就是该插一个反转的位置。）

## 【第 23 轮增补 · 红人星球第10节课 / 营销答疑课 2-21】

> 蒸馏来源：① 红人星球第10节课（115.4min，课程无标注日期），`[89:24]`–`[95:15]`、`[112:05]`–`[113:20]`；② 营销答疑课 2-21（121.8min，2022.02.21），`[66:17]`–`[82:00]`、`[118:30]`–`[119:05]`。
> 本批 11 册增量三张表：**呈现形式十几种变体清单**（用来判"是不是真的不适合真人出镜"）、**开篇与文案的四条硬查**、以及**"自己看自己"的局限**这一条元提醒。

### 【红人星球第10节课｜日期未标注】"我不适合真人出镜"这句话，要测完十几种变体才有资格说（薛辉）
> 蒸馏来源：红人星球第10节课，`[89:24]`–`[92:20]`。

学员问"怎样的呈现形式合适"，他先否定这个问法：

> 「呈现方式是要测的」「咱们今天讲课不是一直在讲吗，说你要去测试」「你到底适不适合真人出镜」

然后他列了一份"真人出镜的变体清单"，并明确说这是一组而不是一种：

> 「你也不能出镜一次，你就给自己否定了，说不适合真人出镜」
> 「我可以这样真人出镜，可以走在路上真人出镜，可以走在夜路上真人出镜」
> 「我可以换一件衣服真人出镜，我可以用悄悄话真人出镜，我可以用报道派真人出镜」
> 「我可以用采访视角去说，采访视角对着手机去说，采访视角对着人去说」
> 「这十几种的呈现方式，都是真人出镜」「你需要把这十几种测完，才知道说我适合什么样的」
> 「如果我真的还是不适合，那我可以尝试着去做视频加配音」

（整理者注：这份清单可以直接当自检表用。它的逻辑是——"真人出镜"不是一个开关，而是一个**参数组合**（位置 × 时段 × 服装 × 语态 × 机位 × 对象）。所以"我不适合出镜"这个结论，在只测过一种组合时是不成立的。这条与本轮 05 册"呈现变量清单"是同一份材料的两个用法：那边讲怎么测，这边讲测到什么程度才有资格下结论。）

### 【红人星球第10节课｜日期未标注】开篇与文案的四条硬查（薛辉，来自 2-21 现场拆片）
> 蒸馏来源：营销答疑课 2-21，`[75:25]`–`[80:10]`。

他现场拆出的四条，全部是可逐条打勾的：

| # | 检查项 | 不合格的样子（原片） | 他的判词 |
|---|---|---|---|
| 1 | 第一句能不能"被看见" | 「远嫁 12 年，我只见过我爸妈三次」——前面还有"后悔真的后悔"七个字 | 「我们刷视频的时候根本看不到七个字」「上来就是后悔，真的后悔，远嫁 12 年」「我们根本就不知道他在说什么」 |
| 2 | 第一句是不是这段素材里最好的那句 | 用了"远嫁 12 年"当切点 | 「这 12 年我只和我爸妈见过三回，你不觉得这句话当第一句话更好吗」 |
| 3 | 开篇有没有重复 | 「一分钟做出治疗红屁屁哦 / 花椒炸香油可以治红屁屁 / 包括红屁屁口水疹反反复复」 | 「开篇重复了三次」「你发现了吗，语无伦次，一个视频开篇开了三遍」 |
| 4 | 知识点是不是常识 | 「水开放汤圆，煮到汤圆浮起，一碗甜甜糯糯的汤圆就煮好了」 | 「你学会了吗」「我学了个啥」 |

（整理者注：这四条的顺序有讲究——1 和 2 管"第一秒能不能抓住"，3 管"有没有浪费开头"，4 管"内容值不值得看"。前三条是技术问题（改一下就好），第 4 条是根子问题（改不了，要换选题）。实操上建议按 4→1→2→3 的顺序查：先确认知识点不是常识，再修开头。）

### 【营销答疑课 2-21｜2022.02.21】"我看自己只能看出 30 个毛病"——自检的天然局限（薛辉）
> 蒸馏来源：营销答疑课 2-21，`[118:30]`–`[119:05]`。

学员问"给别人挑毛病容易，看自己视频就懵逼了咋办"，他的回答很实在：

> 「多看」「就是多挑毛病多看，都这样」
> 「就是我给别人看视频能看出 100 个毛病，我自己我给我自己只能看出 30 个毛病，这就可以了」
> 「都这样」「自嗨，谁都看自己家（的）好」「这很正常」
> 「看别人能看出 100 个，看自己能看出 30 个，就这样呗」

（整理者注：这条是对"自检清单"这个工具本身的限定——清单能提高自检的分辨率，但消不掉"看自己"的偏差。他的解法只有"多看"和"接受 30/100 的差距"。实务上的推论（整理者注）：既然自检天然打折，那么**外部反馈（学员群拍砖、导师批改）就不是可选项而是必需项**；这也解释了他为什么把"学员群拍砖"当成群的第一个用途。）

### 【红人星球第10节课｜日期未标注】合格线的三段位：5 分作品测不出东西，60 分才算合格（薛辉）
> 蒸馏来源：红人星球第10节课，`[112:05]`–`[113:20]`。

> 「每一个视频做出来都是 5 分的水平，总共 100 分满分」「来回去测，5 分和 6 分的作品测出来，6 分的也没有用」
> 「咱们得做到 60 分才算合格」
> 「你差不多每一个作品就能达到 50 分的水平，那结果有一个选题很好，结果那个作品一下成了 80 分，你就爆了」
> 「然后 50 分慢慢再提升，每一个作品能到 60 分的水平，那你每一个视频都能有个几万播放量，这就很好」

（整理者注：这张分段位表可以直接当"要不要发/要不要测"的判据：50 分以下先别测（测了也没有信息量），50–60 分是日常水平，60 分是合格线，80 分靠选题撞。配合 07 册"下限从 1% 互动率抬到 3%"一起用，就构成了一套完整的"作品分级 + 目标设定"。）

## 这个 skill 解决什么问题

写短视频内容时真正难的往往不是文笔，而是「定位怎么定、选题从哪来、脚本用哪套结构、为什么这条不涨粉」。这套笔记把散落在十几门课、几百个视频里的方法论抽出来，按**问题**而不是按**课程**重新组织：同一个主题在不同课里的说法会并到一册，互相矛盾的地方单列索引，而不是抹平。

配合 `SKILL.md` 作为入口，Agent 会先判断问题类型，再跳到对应册取用具体方法，不必通读 5 MB 全文。

## 蒸馏纪律（也是阅读时的理解前提）

- **只写转写里真实出现的内容**，不替讲师补写、不推测「他大概会这么说」。
- **讲师原话用「」**；整理者自己的推论一律标成 `（整理者注：…）`，两者不混。
- **口径冲突并列保留**，不抹平、不选边，集中登记在 `00-冲突索引.md`。例如「三有原则 25% 还是 30%」「声音加速 1.2 还是口播加速 1.1」，都是不同批次课程里的不同说法。
- ASR 同音错字按上下文修正；数字、收益、平台规则原样保留并附风险说明，不做「看起来更合理」的改写。
- 极短片段、纯画面演示、PPT 图表无法靠音频还原，均已逐条登记，不计为遗漏。
- v3.4 溯源修复：第 33 轮把 177 条「同上（讲师，时码）」的继承式来源标注补成可唯一解析的真实文件名，每条引文都能单独回溯到具体视频；口径冲突仍并列保留，不因溯源而抹平。

## 已知限制

- 纯音频转写，**PPT 内容、画面示范、剪辑操作的视觉效果无法还原**，只保留讲师口述部分。
- 语音识别对专名、行业黑话可能失真，已按上下文校正但不保证 100%。
- 讲师口述的平台规则、参数、收益案例属于**单方说法**，不是平台官方文档，可能已过时。
- 不同课程批次之间的结论存在冲突，已在 `00-冲突索引.md` 并列，请按自己账号的实际情况判断。

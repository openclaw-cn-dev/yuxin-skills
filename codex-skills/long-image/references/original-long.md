# 原文长图：一字不改的长图

把**完整文章**（原文、译文或 `rewrite.md`）排成一张（或几张）可连续阅读的长图。规则和校验与所有原文排版相同，见 `../../article2media/references/verbatim.md`：每一句按原顺序只出现一次，生成图 0 张，逐块读回比对。

```bash
node ${CLAUDE_SKILL_DIR}/scripts/long.mjs <目录>/article.md                  # 白底阅读面 → <目录>/full/full.png
node ${CLAUDE_SKILL_DIR}/scripts/long.mjs <目录>/article.md --theme quiet    # 用某个主题的颜色与字体 → <目录>/quiet-full/
```

## 阅读面（1080 px 成品）

- 正文 40 px / 1.9 行高，约 896 px 行宽；标题 80 / 54 / 44 px；表格 34、代码 32、图注 30。手机上约等于 14 px 的舒适字号。长图变高是放大文字的正常代价，不为压高度缩字。
- 默认白底 `#FFFFFF`、深中性黑 `#171717`，暗朱红只用于少量分隔与强调；标题和正文用京华老宋体（缺字时回退宋体）。
- 传 `--theme` 时换成主题的底色、文字色、主色和字体，字号下限不变。
- 超过约 14 800 px 时在**块与块之间**切成 `full-01.png`、`full-02.png`……，绝不切断段落；交付时说明分成了几张。

## 审片与交付

- 看 `full/review/slice-*.jpg`：重叠切片覆盖全部高度，逐段检查截断、遮挡、孤行、表格越界、配图是否完整。
- 交付报告：PNG 路径和尺寸、原文来源、原文块数量与全文校验结果（"45 / 45 块逐字一致"）、实际字体、生成图 0 张。

# UGC 视频

> 中文阅读版。给 AI 执行的指令见同目录 `SKILL.md`，各部分详细内容见 `references/`。
## UGC 视频脚本


### 目标

写出像原生内容的短视频广告脚本，以及一份清楚到达人第一次就能交付可用素材的拍摄简报。

### 脚本结构

| 部分 | 时间 | 作用 |
|---|---|---|
| 钩子 | 0–3 秒 | 让人停止滑动：画面 + 口播 + 屏幕字幕 |
| 问题 | 3–8 秒 | 让观众觉得「说的就是我」 |
| 产品时刻 | 8–20 秒 | 真实使用、特写、真人上手 |
| 证明 | 20–30 秒 | 效果、评论、数据、对比 |
| 行动号召 | 最后 3–5 秒 | 一个明确的下一步 + 报价 |

### 前 3 秒冲突原则（必须遵守）

前 3 秒必须有剧情冲突：观众预期与实际发生之间、人与人之间、人与问题之间的张力。没有冲突的钩子留不住人。冲突示例：

- 人与问题：旧方法当场失败（「这周第三次，手机 20% 电就关机」）
- 人与人：伴侣、室友或顾客质疑（「你花了多少钱买这个？」）
- 预期与现实：看起来不对劲，结果反转
- 时间压力：「客人 10 分钟后到，水槽堵了」

检查每个钩子：去掉冲突后什么都没少，就重写。要从现有视频反推脚本，用 `references/ugc-video-teardown.md`。

### 钩子类型

- 大胆陈述：「我在找到这个之前白花了 200 美元」
- 围绕问题的提问（聚焦产品，不涉及观众个人特征）
- 视觉打断：第一帧出现意外动作
- 「POV：」场景
- 「买 XX 之前我希望早知道的事」
- 回应评论或差评

每个脚本至少写 5 个钩子，同一主体可以分别测试。

### 形式

真人口播、开箱、「三个理由」、并排对比、生活一天、绿幕回应、教程、问题解决小短剧。健康美容类避免夸张的前后对比。

### 达人简报模板

- 产品，以及最想传达的一点
- 要点（不是逐字稿，让达人自然表达）
- 必须拍到：产品特写、使用过程、必要时拍包装
- 禁止：违规宣称、竞品名、未授权音乐
- 交付物：视频数量、时长、原始素材、钩子变体、9:16 竖屏、无字幕版本便于剪辑
- 使用权：付费投放期限、Spark Ads / 合作广告授权、白名单
- 披露：达人须按 FTC 规定和平台工具标注付费合作
- 截止时间和付款方式

### 经验法则

- 在 TikTok 和 Reels 上，真实场景的真人胜过棚拍精致感
- 一定加字幕，很多人静音观看
- 一条视频只讲一个信息，三个卖点就拍三条
- 绝不编写虚假证言，效果表述必须来自真实用户体验

### 输出格式

3–5 个脚本（时间、画面、口播、字幕）、每个脚本 5 个备选钩子、一份填好的达人简报。

## 视频逐帧拆解 → 生成新脚本


### 目标

把一条视频变成：（1）逐秒拆解，说清它为什么有效或无效；（2）几条复用结构、但内容全新的原创脚本。

### 第一步：抽帧和音频

有命令行和 ffmpeg 时运行：

```bash
bash scripts/extract_frames.sh <视频文件> <输出目录>
```

会得到：前 3 秒每 0.25 秒一帧、之后每秒一帧、转场处的帧和时间点、音频文件。按顺序看帧，用可用的工具转写音频；没有转写工具就请用户提供脚本或字幕。

### 第二步：钩子分析（0–3 秒），最重要

逐帧检查：

- **冲突**：前 3 秒有没有剧情冲突（人与问题、人与人、预期与现实、时间压力）？没有冲突就不吸睛、没留存，这是第一个要报告的结论
- 第一帧：有声音之前观众看到什么？有没有动作、人脸、意外物体？
- 第一句口播和第一行字幕
- 产品第一次出现在第几秒

### 第三步：完整拆解

时间线表格，每个节拍或镜头一行：

| 时间 | 画面 | 机位（特写、第一视角、全景） | 口播 | 字幕 | 声音 / 音乐 | 作用（钩子、冲突、问题、演示、证明、行动号召） |

再总结：结构模式、节奏（镜头数、平均时长）、留存手法（悬念、提问、打断、揭晓时机）、证明与行动号召、弱点及修改建议。

### 第四步：生成新脚本

为用户的产品写 3 条新脚本，保留有效的结构和节奏，但场景、台词、画面全部换新：

- 每条前 3 秒都有明确冲突
- 每条附 3 个备选冲突钩子
- 用时间线表格格式，拿来就能拍
- 达人简报参考 `references/ugc-video-scripts.md`，宣称合规参考 `paid-ads` (`references/ad-policy-compliance.md`)

### 规则

- 只复用模式，不复用内容：不抄别人的台词、画面、角色、音乐、品牌名
- 不逐镜头翻拍竞品视频，要换场景、换冲突
- 新脚本里的宣称必须基于用户产品的真实信息

### 输出格式

钩子结论（有无冲突、1–5 分、原因）、时间线拆解表、模式总结与弱点、3 条新脚本各带 3 个冲突钩子、建议测试顺序。

## 海外达人合作


### 目标

建立可重复的达人合作体系：找对人、报价清楚、简报顺畅、内容可二次用于广告、合规披露。

### 达人分层

| 层级 | 粉丝量 | 适合 |
|---|---|---|
| 素人 | 约 1k–10k | 低成本 UGC、高信任、寄样铺量 |
| 小达人 | 约 1 万–10 万 | 覆盖、成本、互动的最佳平衡 |
| 中达人 | 约 10 万–50 万 | 有公信力的覆盖 |
| 大达人 | 50 万以上 | 大型上新、品牌曝光，昂贵 |

小品牌一般从大量素人和小达人开始，而不是押一个大号。

### 去哪找

- 平台达人市场和联盟计划（如 TikTok 达人工具、TikTok Shop 联盟）
- 按产品解决的问题搜索话题和关键词
- 已经在发竞品或品类内容的达人
- 主动发帖的现有顾客

### 筛选清单

- 粉丝地区：目标国家占比高
- 互动真实（有内容的评论，不只是表情），警惕粉丝暴涨
- 内容质量和出镜状态
- 品牌安全：过往内容和争议
- 过往商单：效果如何、有没有规范披露

### 合作方式

- **寄样**：送产品，不保证发帖（适合素人）
- **一口价**：保证交付内容
- **佣金 / 联盟**：按销售分成，适合长期合作
- **混合**：小额费用 + 佣金
- **付费使用权**：额外付费把内容用于广告（Spark Ads 授权码、合作广告、白名单）

### 外联消息

简短、个性化、具体：为什么找这个达人（提到一条真实作品）、产品做什么、你提供什么、一个明确问题。通过平台工具、私信或商务邮箱发送，跟进一两次没回复就换人。

### 协议要点

交付内容和截止时间、审核流程、使用权（平台、期限、付费投放）、是否独家、付款条件、披露要求。

### 披露

美国 FTC 要求清楚披露利益关系（付费、送样、佣金）。达人应使用平台的品牌合作 / 付费合作标签，并用 #ad 等明确字样。绝不要求达人隐藏合作关系。

### 追踪

给每位达人专属折扣码和 / 或 UTM 链接，追踪单条成本、播放、点击、销售，以及内容用于广告后的表现。

### 输出格式

达人标准与分层预算、搜索计划、筛选清单、外联模板（首条与跟进）、合作结构与协议清单、追踪表字段。

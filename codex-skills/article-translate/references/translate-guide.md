# 翻译指南：忠实、通顺、像中文

目标：中文读者读起来像一篇本来就用中文写的好文章，同时每一句都能在原文里找到对应。

## 1. 忠实

- **不删不加**：每一句都要译出来，包括作者的自我介绍、推广和"订阅我"。不想要这些内容时，应该改走改写（article-rewrite），而不是在翻译里删。
- **不改强度**：原文说"可能""我觉得""大多数"，译文不能变成"一定""事实是""所有"。
- **数字、金额、日期**照原文：`$13.9B` 保留原币种与写法，或写成「139 亿美元」，二选一，全文统一。年份、百分比用阿拉伯数字。
- **引语**：原文引用别人的话，译文也用引号标出。
- 原文明显笔误（如重复的词）可以顺手更正；事实性错误不改，交付时提一句。

## 2. 通顺

- 按中文语序重组句子，不要逐词对译。英文长句拆成两三句中文短句很正常——但拆完仍在同一段里。
- 少用"被""的的的""进行""一个"堆叠；代词 he/it/this 能省就省，指代不清时换成名词。
- 口语化原文（推文、播客逐字稿）译成口语化中文，书面原文译成书面中文。
- 网络用语、梗：有通行中文说法的用通行说法，没有的直译并在第一次出现时括注原文。

## 3. 格式

- 中文与英文、数字之间加空格："2027 年""YouTube 植入""Claude Code 的用法"。
- 标点用全角：，。！？：；「」或“”（全文统一一种引号）。省略号用「……」，破折号用「——」。
- 专有名词（人名、公司、产品、平台）保留原文：Naval、Substack、Reels、Eden。约定俗成有中文名的用中文（马斯克、苹果），第一次出现时可以括注原文。
- 标题意译成有力的中文标题，不必逐字："The most lucrative AI business to start in 2027" → "2027 年最值得做的 AI 生意"。

## 4. 结构（检查脚本会核对）

| 原文 | 译文 |
|---|---|
| 一段 | 一段（不合并、不拆开） |
| `#` / `##` / `###` 标题 | 同级标题 |
| 整段粗体的小标题（`**…**`） | 整段粗体 |
| 列表项、编号 | 同样多的列表项，编号不变 |
| 引用 `>` | 引用 |
| 表格 | 行列不变，逐格翻译 |
| 图片 `![…](地址)` 和紧跟的斜体图注 | 图片原样，图注翻译 |
| 代码块 | 一字不改 |
| 分隔线 `---` | 原样 |

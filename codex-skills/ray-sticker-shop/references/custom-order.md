# 定制接单

## 卖什么

卖「你家的猫、你本人、你店里的吉祥物」做成的专属表情，不是卖现成的通用表情。买家付钱是因为这套表情只有他有。

常见的三类单：宠物、本人或情侣的卡通形象、小店或公司的吉祥物。

## 一单怎么走

1. **收素材。** 要 1–3 张清晰正面照，问 8 句想要的话，问用途（自用还是要上架）。
2. **确认权利。** 素材是客户自己的；真人要本人同意；不接明星、动漫角色和孩子的上架单。
3. **定角色。** 用 `character` 出角色图发给客户确认。这一步先确认，能省掉大部分返工。
4. **出整套。** `gen` + `build` + `check`。
5. **交付。** 把 `预览.png` 发给客户确认，再发 `交付给客户.zip`。要上架的客户，多给 `submit/` 和 `上架文案.md`。

## 提前说清

- 约定修改次数，比如含 2 次重抽。
- 说明这是 AI 生成的。
- 确认前只发预览图，不发原文件。
- 客户照片用完就删，不拿来做案例，除非对方同意。

## 商品页

- 放同一个角色「原图 → 表情包」的对比，这是最有效的图。
- 写清张数、交付时间、修改次数。
- 公开平台上不要导流到站外，容易被限流，看各平台规则。

## 教训

1. **视觉体系要先问用户认哪一版**：一开始按旧工具（xhs-web-layout）出图直接被否，用户心里认的是内容分发仪表盘里那套 azhen-ppt 视觉。先对齐样板再动手
2. **头像圆框裁切必须实测**：不同抠图的构图差异大，margin 值不能想当然，返工了 3 轮
3. **反馈当场固化**：这个实例的每条规则都是用户指出后立刻写回 SKILL.md 的，第二次跑就不再犯
4. **提示词类内容一开始就问全文还是节选**：默认全文，版面跟着内容长度调，不要反过来

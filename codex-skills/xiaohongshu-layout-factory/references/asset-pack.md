# 素材图集闸门（本工厂自带，不依赖其它 Skill）

没有同 IP 多动作图集时**不要再问"要不要生成"**。先确认 IP 定位卡，再延展动作包。用户明确拒绝才允许降级，并在 `quality-checklist.md` 标注。

## ① 定位卡（先于动作清单）

```
【IP 定位卡】请确认或修正，确认后才出动作清单：
- 身份：讲师 / 品牌吉祥物 / 店长 / 虚拟员工 / …
- 行业：美食 / 科技 / 教育 / 金融 / 美妆 / …
- 使用场景：小红书图集主要讲什么
- 调性：软萌 / 专业 / 潮酷 / 治愈 / 严肃 / …
```

结论写进 design-tokens.md 顶部。

## ② 规模二选一

- **A · 精简包 20 张**：8 张通用动作 + 8 张场景定制 + 4 张纯表情补位
- **B · 完整包 45 张**：4 个场景大类 × 10 + 4 张纯表情 + 1 张主场景图

底色三档：透明底（浅色图集默认）/ 白底 / 指定底色。深色底慎用模型自带透明 PNG（边缘残影），优先白底再二次抠。

## ③ 角色一致性（prompt 开头）

```
以参考图作为角色锚点。必须 100% 保留：五官 / 发型 / 配饰 / 服装 / 鞋袜 / 头身比 / 画风 / 色调。
允许变化：动作、姿态、表情幅度、道具、手势、视线、构图。其它一律保持。
服饰小件逐条写死：耳环结构、扣子数量位置、鞋袜。电子设备背对观众时背面必须干净纯色外壳。
道具完整入画，不被裁切。
```

## ④ 通用 8 张（每个 IP 都生成）

| # | 动作 | 适用页 |
|---|---|---|
| 01 | 正面站立默认 | host 头像 / 封面 |
| 02 | 托腮思考 | 观点 / 对比 |
| 03 | 举灯泡灵感 | 金句 / 洞察 |
| 04 | 举绿对勾 | 清单 / 正确做法 |
| 05 | 举红叉号 | 避坑 / 警示 |
| 06 | 工作姿态 | 流程 / 执行 |
| 07 | 跳起欢呼 | 收尾庆祝 |
| 08 | 挥手打招呼 | 收尾 / host |

定制动作按定位卡反推，生成前给用户过目。页面类型 → 动作映射见 `workflow.md` Step 1.5 表。

## ⑤ 生图通道（先探测，有默认就用）

探测顺序：本机已装生图 Skill / MCP / CLI。探测到直接用，只告知不追问。探测不到才问：A 指定模型 API，B 只出 `prompts.md` 用户自己跑完回传文件夹。

分辨率硬规则：入库 PNG **短边 ≥ 1000px**，不够就重跑或放大，不许将就。

输出目录默认：`~/Downloads/<主题名>-emoji-pack/`

## ⑥ 单张生图 prompt 模板

```
[贴角色锚点段落]
【本张要表现】动作：… 构图：全身立绘居中，留约 8% 边距，相机平视
【输出要求】底色按用户选择；比例 1:1；PNG 短边不少于 1000px；不裁头顶和脚；边缘干净
```

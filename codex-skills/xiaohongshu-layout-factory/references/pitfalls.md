# 避坑指南（xhs 图集版）

前 8 条来自阿真「小红书排版」实例的真实翻盘，后面是版面通用坑。复刻时直接跳过。

## 1. 视觉体系先对齐样板再动手

阿真实例第一版按旧工具风格出图直接被否——用户心里认的是另一套视觉（azhen-ppt 系）。**Step 2 之前先问用户有没有"就要这种感觉"的样板图 / 旧成品**，有就以它为准反推，没有才从 IP 图反推。

## 2. 零投影是全页禁令，不是只管角色

一开始只禁了角色着地阴影，保留了"金色柔光 drop-shadow"和头像框 box-shadow，后来用户升级为**全元素零投影**。直接按最严执行：任何元素不写 box-shadow / drop-shadow；光晕用 `.ip-glow` 渐变 div，金圈用 border。验收跑一遍 `rg "box-shadow:|drop-shadow\(" *.html`，注释外零命中。

## 3. 文案第一版就写笔记体

提炼内容时最容易写成"官方 AI 腔"：抽象名词、看不懂的比喻、汇报式标题。用户的原话是"内容非常 AI，让人没有想看的欲望"。规则：口语短句、直接给判断标准和例子、生造术语翻成人话、标题像真人会说的话。**demo 第一版就按这个写**，别等用户翻盘。

## 4. 标题和正文的空格规则不同

标题（h1 / h2 / 金句大字）里数字和英文**前后不加空格**（「刷完24部」「15秒」）；正文小字维持标准间距（中英文数字边界留一个空格）。两条规则同时写进 tone-guide，渲染后抽查标题页。

## 5. 提示词类内容默认放全文

案例页出现提示词时全文照放不节选；双语只放英文，仅中文放中文。放不下的处理顺序：调小字号（16px/1.6 起步）→ 压插图框高度（470px 起步可降）→ 拆页。**禁止截断**，末尾参数（--ar / --sref 这类）掉了等于白放。

## 6. host 头像圆框裁切必须实测

不同抠图构图差异大，margin 想当然必返工（阿真实例调了 3 轮：上移、右移、再左移）。固定 SOP 见 workflow.md Step 2.5：渲染 → 裁剪放大右上角 → 目检 → 微调。实测值写进模板注释，**换头像图就重新校准，不照抄旧值**。

## 7. 画质坑在渲染分辨率，不在素材

素材原图 `cp` 没有压缩，但 1x 渲染（1080 宽）会把 2K 插图压掉一半细节。**渲染一律 `--force-device-scale-factor=2` 输出 2160×2880**；素材侧保持零处理（不压缩不缩放不转格式）。验收 `sips` 抽检尺寸。

## 8. 无头渲染必须等字体加载完

真实翻车：重渲时漏了 `--virtual-time-budget`，中文字体按 unicode-range 分块异步加载，前几页字体到位、后几页截图时还没加载完，整套图前楷体后黑体。双保险：模板用 `font-loader.html`（国内源优先）+ 就绪门；渲染命令必带 `--virtual-time-budget=15000`。禁止只挂 Google Fonts。

验收时把全部页标题区各裁一条拼成对照表看一眼，字体不一致立刻重渲。

## 版面通用坑

## 9. 不要急着选字体

中文主字体 + 英文衬线 + 手写体先选 2-3 组合做 demo 看实际效果再定。单档字重字体撑不住标题时**换字体，不要合成加粗**（发虚）。加载走 `references/fonts.md`（国内优先）。选型失败就换可商用开源字体，不要卡在某一个 CDN。

## 10. 抠图首选 macOS Vision

别装 rembg（170MB 模型）。本工厂自带 `assets/cutout.swift`，20 行调系统 API，零依赖。

## 11. 浅色底 + 白底卡 = 层级糊掉

线框容器统一 `background:transparent` + 1.5px 细线。图集里唯一白底例外是案例页插图框 `.frame`（承载照片需要底）。

## 12. 60px 安全边距写死并 grep 自检

不写死下次就会出 `bottom:-30` 这种 bleed（装饰 glow 除外）。quality-checklist 里加一条负值 grep。

## 13. 装饰永远低于内容

z-index：装饰 1 / 线框 2 / IP 3 / 文字 4 / host stamp 5。IP 和文字视觉重叠就缩 IP / 错位 / 换图，**禁止用 z-index 让文字穿透 IP**。星点落负空间，贴字就挪。

## 14. 方法论可学，实现必须原创

总-分-总、骨架库、自检清单是通识可复用；**色板 / 字体 / 装饰 / 命名 / 文案口吻必须从用户 IP 反推**，照搬阿真的就是衍生品。

## 15. 每次反复都要固化进 references

用户翻盘什么，当场写回新 Skill 对应文件（映射表见 workflow.md Step 4.6）。阿真实例 7 条规则全部来自"当场固化"，第二次跑零重犯。

## 16. 新 PNG 替换后重算视觉体量

换素材不能沿用旧宽度：封面大图是否过大、小立绘是否压卡片、和文字至少留 20px。先看截图再改尺寸。

## 17. 局部反馈不扩大成全局重做

用户说"这个往左一点"就只动这个（及明确同类），不顺手重排整套。说"所有这种都改"才全局动，并同步写进规则。

## 18. 🚫 素材没齐严禁开做正式图集

单图凑合出一版、事后补图回填 = 所有页面 IP 尺寸位置重算 + 全部重渲，整轮视觉调试报废。Step 3 闸门三项强制过，唯一例外是用户签收降级。**前置素材永远比后期回填便宜 10 倍。**

# 跨 IP 通用硬规则（每个实例化出的小红书排版 Skill 都必须写死）

以下规则与具体 IP 无关，来自阿真「小红书排版」实例的全部踩坑记录。实例化新 Skill 时原样抄进新 Skill 的 SKILL.md，只把示例文字换成新 IP 的。

## 画布与渲染

- **比例 3:4**：CSS 画布 1080×1440，`html,body` 和 `.page` 写死这个尺寸
- **渲染一律 2x 输出 2160×2880（保画质）**：截图命令加 `--force-device-scale-factor=2 --window-size=1080,1440`
- **素材零压缩**：IP 抠图、插图原样 `cp` 进任务目录 `assets/`，全程禁止压缩、缩放、转格式；HTML 用相对路径引用原图
- 整套同尺寸，逐张独立 PNG；不出现页码、水印、logo、日期
- fonts 走国内优先加载（`font-loader.html`：font.im → loli.net → Google Fonts 兜底）；**禁止只挂 Google Fonts CDN**。模板 `<head>` 必带字体就绪门 + 渲染命令必带 `--virtual-time-budget=15000`
- 渲染后用 `sips -g pixelWidth -g pixelHeight` 抽检全部为 2160×2880

## 零投影禁令（最高优先）

**全页所有元素一律禁止投影**：任何地方不写 box-shadow、不写 drop-shadow（头像框、卡片、立绘、插图框、文字全部包括）。

- 角色身后光晕：只用径向渐变 div（`.ip-glow`）实现
- 头像金圈：用 `border` 实现，不用 box-shadow 描环
- 立绘 `.ip` 不加任何 filter

## 版面

- **60px 安全边距**：所有内容元素 `top/right/bottom/left ≥ 60px`，禁止负坐标 bleed（装饰 glow 除外）
- 容器全透明背景 + 1.5px 细线描边；chip 用 999px 圆角 dashed；禁止白底卡（案例页插图 `.frame` 白底例外）
- 星点只用 ✦ ✧ ★，每页 4-5 颗（案例页可减到 2 颗），opacity .20-.28，落在负空间，远离文字和卡片边框
- 结构走总-分-总：封面钩子（hero）→ 内容页（带 host stamp）→ 行动收尾（hero）
- 默认 5-8 页按内容定（含案例页可到 12-15 页），不为凑页数注水
- 内容页一页只讲一件事；中部不许出现大段空白，空了就补手写注记或一行补充说明
- host stamp：`top:74` 与左侧标题块对齐（不要 top:48），头像背景纯白，不加章节虚线
- footer 固定：左「品牌署名」+ 金色小圆点，右「向左滑动」，最后一页右侧改「@账号名」
- z-index 心智：装饰星点最底 → 线框 → IP 立绘 → 文字最上；文字永远不被 IP 压住

## 头像居中基准（Step 2 必做）

每个新 IP 的 host 头像图都要实测校准：`.host .av img` 用 `width:130%` + `object-position:top center` 起步，微调 `margin-top` / `margin-left` 直到**脸落在圆框正中、头顶不被切**。阿真挥手图实测值是 `margin-top:-4px;margin-left:-12%`，换图必须重新目检（放大右上角截图确认），不能照抄。

## 文案

- **笔记体，不官方**：写成给自己看的干货笔记，口语短句、直接给判断标准和具体例子。少用比喻，不造抽象名词（生造术语必须翻成人话）。标题像真人会说的话，读者一眼知道这页对自己有什么用
- **标题里数字和英文前后不加空格**：h1、h2、金句大字里写「刷完24部」「15秒小测试」；正文小字维持标准间距（中英文和数字边界留一个空格）
- **提示词必须放完整全文**：案例页出现提示词时全文照放、不节选不改写；中英双语只放英文版，仅有中文时放中文版。放不下就调小字号（16px/1.6 起步）、压插图框高度（470px 起步可降），必要时拆页，不许截断
- 不用破折号；禁用「不是X，而是Y」句式；不过度用引号
- 封面只有 chip + 大标题（整套最大字）+ 一行英文 italic + 三行以内钩子
- 行长：正文每行 ≤22 字，金句每行 10-16 字
- 收尾页给行动清单 + 轻柔收藏/评论引导，不写硬广

## IP 选图

- 每页按该页核心动作/情绪选最贴的一张，整套弱偏好不重复用图（最贴合时可重复，不硬选错位图）
- 封面和收尾用大立绘（470-540px，右下，配 `.ip-glow` 光晕）
- 内容页用小立绘（280-320px）做情绪点缀，放正文让出的负空间
- 案例页（有插图 + 全文提示词）不放立绘，版面留给内容

## 出片自检（逐页过，全勾才交付）

1. 尺寸 2160×2880，比例 3:4
2. 全页无任何投影（box-shadow / drop-shadow 检索为 0，注释提及不算）
3. **整套字体统一**：中文全是选定主字体，出现回退黑体/宋体 = 字体没加载完，重渲（快捷验法：全部页标题区各裁一条拼对照表看一眼）
4. 文字不溢出、不被 IP 或插图压住
5. 标题内数字英文无空格；正文间距正常
6. 案例页提示词是全文，末尾参数（--ar 等）完整没截断
7. 星点没贴文字、没压卡片边框
8. host stamp 与标题块顶对齐，头像脸居中、头顶完整
9. footer 署名正确，末页右侧是 @账号名
10. 中部无大段空白
11. IP 图无重复（或重复有理由）
12. 60px 安全边距无越界
13. 逐页语义扣题：标题、卡片、配图讲同一件事

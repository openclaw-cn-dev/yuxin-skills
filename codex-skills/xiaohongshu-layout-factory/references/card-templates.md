# 页面骨架库（4 类骨架 + 内容页 4 变体 + 用量预算）

骨架的可运行 CSS/HTML 在 `assets/template.html`（token 化，换 :root 即换 IP）。本文档讲每类骨架的槽位、字数控制和选用逻辑。

## 骨架 A · 封面 hero（首页，必用 1 张）

| 槽位 | 规格 | 字数 |
|---|---|---|
| chip | 金色 dashed 圆角，栏目名 · 主题标签 | ≤12 字 |
| h1 大标题 | 104px，整套最大字，可两行，第二行带强调色词 | 每行 5-9 字 |
| 英文副题 | italic 一行 | ≤40 字符 |
| 钩子 | 30px，≤3 行，可带一个高亮词 | 每行 ≤14 字 |
| 大立绘 | 520px 右下 + `.ip-glow` 光晕 | 选最有代表性的动作 |

标题写「结果 + 反差」：说读者能得到什么，不写课程名。

## 骨架 B · 内容页（中间页，带 host stamp）

固定件：左上 sec-label（英文 italic）+ 58px 标题、右上 host stamp、左下 footer。
主体区四选一（同一套图集里混用，但相邻页尽量不同变体）：

1. **编号卡 numcard**：2-4 张，圆号 + 要点标题 + 一句话 + 例子行。适合步骤/清单
2. **双栏对比**：左右两个细线容器，顶部各一个短标签。适合 A/B、之前之后、误区正解
3. **时间轴行**：竖向节点 + 每行一句。适合流程、发展史
4. **清单行**：无编号短行 + 行首金点。适合特征列举、避坑清单

收尾件二选一：金色 quote 金句（左条 + ≤2 行），或底部一行补充说明。
小立绘 280-320px 放右下负空间；卡片多时可不放立绘。

## 骨架 C · 案例页（插图 + 完整提示词）

| 槽位 | 规格 |
|---|---|
| sec-label | SHOWCASE 01/02/… |
| 标题 | 案例名，≤8 字 |
| `.frame` 插图框 | 960px 宽，高 470px 起步（提示词长就压低），白底细线圆角，img cover 裁切 |
| `.prompt` 提示词块 | 金色左条 + FULL PROMPT · ENGLISH 小标 + 全文 |

硬规则：提示词全文照放不节选；双语只放英文；放不下依次「调小字号（16px/1.6 起步）→ 压 frame 高度 → 拆页」，不许截断。星点减到 2 颗。不放立绘。

## 骨架 D · 收尾 hero（末页，必用 1 张）

chip 写 YOUR TURN 类行动标签；96px 行动号召标题；3 行行动要点；一行英文手写体；轻柔收藏/评论引导两行；大立绘 470px 右下。footer 右侧改「@账号名」。

## 用量预算

- 封面 A 和收尾 D 各恰好 1 张
- 内容页 B：占中间页的主力；同一变体连用 ≤2 页
- 案例页 C：有实际案例/提示词才用，可连排（SHOWCASE 01-0N）
- 总页数 5-8 页（纯观点内容）或 12-15 页（含案例集），由内容定，不注水

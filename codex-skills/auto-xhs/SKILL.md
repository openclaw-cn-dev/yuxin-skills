# Auto-XHS 小红书自动化运营系统（中文）

> 入口文件。原仓 `core/CONSTITUTION.zh-CN.md` 是**宪法页**（总规矩），本仓所有规则只以它为准，不另写第二份。

## 系统干什么

每天给小红书账号出一条短视频笔记，**全流程**：选题 → 写稿 → 做片 → 发布 → 发后跟进 → 结果汇报。
全程免费工具，不接付费服务。

自动化三档（`config.yaml` 的 `automation.mode`）：

| 档 | 行为 | 适用 |
|---|---|---|
| `full` | 全自动发（含发布） | 成熟账号，平台对全自动发布查得紧，新号别从这档起 |
| `semi` | 到发布前停，备好待发包，老大点发布 | **推荐从这档起**，稳了一两周再升 |
| `manual` | 只做到写稿 | 先试脚本质量 |

换档不用重装，改配置即可。

## 四条核心标准（写每条稿先过）

1. **有吸引力** — 平淡没钩子的题直接换。选题先过「一句话说清这事跟看的人有什么关系」，说不清就换题
2. **说人话** — 大白话短句，绕不开的术语同句里解释一遍
3. **有细节** — 看完不能跟没看一样。讲产品答四问：适合谁 / 谁有这需求 / 需求是什么 / 至少一个落到生活里的场景，再补一句不适合谁
4. **不重复** — 选题、角度、素材都不跟已发的重

## 五阶段手册（`core/stages/`）

| 阶段 | 文件 | 干什么 |
|---|---|---|
| 1 选题 | `01-sourcing.zh-CN.md` | 找题 + 防重复三查 + 敏感词筛查 |
| 2 写稿 | `02-script.zh-CN.md` | 标题/正文/口播稿，按爆款公式选型 |
| 3 做片 | `03-video.zh-CN.md` | 网页做片（1080×1920 竖屏），逐帧渲染 |
| 4 发布 | `04-publish.zh-CN.md` | 发布清单 + 主站登录确认 + 话题/声明检查 |
| 5 发后跟进 | `05-followup.zh-CN.md` | 评论回复 + 数据回收 |
| 周复盘 | `core/lessons.template.zh-CN.md` | 经验沉淀 |

**读法**：`core/CONSTITUTION.zh-CN.md` 先读这一份，总管只读它开工；到哪个阶段再读对应那份，别一次全读。

## 爆款公式库（`core/viral-playbook.zh-CN.md`）

标题公式 F1–F15+（数字清单式 / 数字横测对比 / 痛点场景解法 / 警告式 …），每个都标了证据强弱（强 / 中 / 中强）。
硬约束：

- **取舍总序：共鸣第一，资产第二，搜索词第三**
- 标题总长有硬上限（中文和全角标点 1 字，英文数字半角 0.5 字，emoji 1 字），超限淘汰
- 每版标题必须有钩子（五种形态任一：反问 / 拟人 / 情绪词 / 预期违背 / 强承诺）
- **情绪外壳 + 资产内核**：外壳抓点击，内核保收藏
- 不用绝对化词、不贬损竞品、不引战、零导流、不抽奖换互动

## 机器验收（`core/validate.py`）

只读，不改文件。查：口播字数、post.md 结构、成片规格（方向是否匹配）、全片静音、封面、期号；
警告级：最低码率、空白帧、冻结帧、标题加权长度、正文字数、字幕长度、标题情绪与锚点。

```bash
python core/validate.py <当天素材目录>     # exit 0 = 全 PASS/WARN，exit 1 = 有 FAIL
```

阈值来自仓库根 `config.yaml`（无则用内置推荐值）。**核心数字只在「数字总表」定一份**，手册只引用不改写，两边对不上以总表为准。

## 编排（`orchestration/`）

- `orchestrator.zh-CN.md` — 总管只做派发、检查、汇报；阶段工作交给子 agent，**一次一个**，上一阶段过了才派下一个
- `dispatch-templates.zh-CN.md` — 派发话术模板
- `scheduling/` — 排期模板（Muse）
- `publish-checklist.template.zh-CN.md` — 发布清单模板

## 防重复三查（开工第一件事）

查三处：当天运行日志 / 选题台账（`paths.ledger_file`）/ 当天素材夹 + 账号作品列表。今天已发就停手汇报。

## 四级异常闸口

| 级 | 情形 | 动作 |
|---|---|---|
| 1 可降级 | 单个信源挂 / 素材缺 / 一段配音坏 | 按手册替代顺序办，记四要素，继续走 |
| 2 质量合规 | 事实核不上 / 敏感命中 / 验收不过 | 停在当前阶段，换题换素材重做 |
| 3 发布闸口 | 话题没全变蓝 / AI 声明没选 / 主站没登录 | 不点发布，存待发包再汇报 |
| 4 运行会话 | 没打点 / 浏览器断了 / 页面空白 | 查真实状态，从没做完的阶段续跑，**不重跑已完成的阶段** |

## 敏感词（`core/sensitive-words.template.zh-CN.md`）

模板，用之前复制一份改成正式名字。**两个都冲突时从严**。

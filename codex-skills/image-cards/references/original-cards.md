# 原文卡片：把整篇文章分页成卡片，一字不改

`cards.mjs <article.md> --ratio <比例>` 把完整文章（原文、译文、逐字稿或 `rewrite.md`）排进一组固定比例的卡片。规则和校验与所有原文排版相同，见 `../../article2media/references/verbatim.md`。

```bash
node ${CLAUDE_SKILL_DIR}/scripts/cards.mjs <目录>/article.md                      # 3:4，白底阅读面 → <目录>/full-3x4/
node ${CLAUDE_SKILL_DIR}/scripts/cards.mjs <目录>/article.md --ratio 1:1 --theme quiet   # → <目录>/quiet-full-1x1/
```

## 卡片怎么排

| 卡 | 内容 |
|---|---|
| 封面 | 文章标题（原文的 `# 标题`）+ 作者、平台、日期 + "全文 N 张"；长标题自动缩小字号 |
| 正文卡 | 原文按顺序往下流；页眉是标题和页码（2 / 12），页脚是来源和品牌 |

- 字号与原文长图相同（正文 40 px / 1.9，在 1080 宽的成品上），不为塞进更少的卡而缩字。
- 一段放不下时**在行与行之间**断开，下一张接着排；断开处上一张的末行排满。列表在项与项之间断开（项太长时在行间断开），表格在行与行之间断开、下一张重复表头。
- 小标题不会孤零零落在卡底：放不下它后面的内容时，连同小标题一起移到下一张。
- 原文配图单独一张也放不下时自动缩小；分隔线正好落在卡与卡之间时省掉（换卡本身就是分隔）。
- 每张卡大约放 300–350 个汉字（3:4）；1:1 约 200 字，9:16 约 450 字。

## 张数

小红书一篇最多 18 张（其他比例 20 张）。超出时会提示：
- 分成两篇发（例如上篇、下篇各一组，可以用 `--out` 分别输出两段文章）；
- 或改用原文长图（`long-image`）；
- 或改走改写路径，出总结卡片。

不要为了压张数删原文。

## 检查与交付

- 先看 `overview.jpg`，再打开有问题的单张：断开的位置读起来是否顺、有没有卡只剩一两行、配图是否完整。
- `caption.md` 是发帖文案的起点：标题（小红书最多 20 字，原标题太长时你来缩短）、开头摘录、来源。**补上 3–6 个话题标签**，贴在交付回复里。
- 交付报告：卡片路径和张数、原文块数与全文校验结果（"45 / 45 块逐字一致"）、来源、生成图 0 张。

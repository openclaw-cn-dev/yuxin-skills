# 风控规则手册

> 玉芬/宽博士维护 · 最后更新 2026-09-01

## 全局风控阈值

| 维度 | 阈值 | 触发动作 |
|---|---|---|
| 单策略最大回撤 | -15% | 自动暂停 + 通知玉芬 |
| 组合整体回撤 | -10% | 玉芬告警华哥 |
| 组合最大回撤 | -20% | 立即清仓 + 暂停所有 cron |
| 单标的单日亏损 | -7% | 次日开盘前减半仓 |
| 北向资金连续 3 日净流出 > 200 亿 | — | 暂停所有 A 股买入 |

## 报告与监控

- **每日 09:35 + 14:55**: 风险敞口快照
- **每周五 17:00**: 周度风控报告(含 VaR / 行业暴露 / 流动性)
- **每月第一个交易日 09:00**: 月度策略回顾(Sharpe / MDD / IC 衰减)

## 数据脱敏

任何报告 commit 进仓库前:
- 持仓金额 / 总市值 / 现金余额 → 转换为 % 或脱敏为 "Top1/Top5/Top10"
- 个股代码可保留(研究需要)
- 个股名称在 reports/ 中**保留**(研究需要),在 `data/` 中**保留**(原始数据)

## 2. 目录结构

```
quant-research/
├── README.md          ← 本文件
├── data/              ← 原始/清洗数据快照（仅本地缓存,不入仓大数据）
├── research/          ← 专题研究（指数、行业、宏观、产业链）
├── strategies/        ← 策略骨架 + 参数 + 回测结果
├── risk/              ← 风控规则、回撤阈值、止损参数

```

- **公开研究部分**:`research/` 内的专题可保留完整数据（研究是公开知识）
- **跨仓同步**: 本目录受 yuxin-skills 仓库保护（Private GitHub）,**不会**被 Codex/CC/Hermes 三方自动外发

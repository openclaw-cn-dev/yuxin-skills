# yuxin-compliance-checker

渔芯内容合规审核器。**任何内容发布前必调**，避免违规被限流/封号/法律风险。

## 适用场景

- 所有 `yuxin-promoter-*` skill 输出后必调
- 飞书审核前自动跑一遍
- 周报：合规问题统计

## 工作流（5 维度）

### 1. 广告法（《广告法》第 9 条）
**禁用绝对化用语**：
- 「最」「第一」「顶级」「唯一」「独家」「冠军」「国家级」「最高级」
- 「100% 」「绝对」「完全」「永久」
- 行业变体：「首款」「首发」「销量冠军」

**渔芯特定**：
- 「唯一」「首家」在 RAS 行业需小心（避免无证据）
- 「全网最低价」「性价比最高」必删

### 2. 敏感词（按平台）
```
通用：
- 政治/宗教/色情/暴力
- 涉政人物/红线事件

行业：
- RAS 补贴 → 必须有政策文件号
- 数据来源 → 必须可追溯
- 客户案例 → 必须客户授权

平台：
- 小红书/抖音 → 「最」「第一」限流
- 微信 → 医疗/保健/金融类需资质
- B站 → 二次创作需标注来源
```

### 3. 数据真实性
- 所有数字必须可追溯（RKR / 政策文件 / 公开报告）
- 增长率/规模/补贴金额必须注明来源 + 时间
- 不可"听说""大概""差不多"

### 4. 渔芯产品植入规范
- 产品名出现次数 ≤ 3（公众号）/ ≤ 2（抖音）/ ≤ 1（知乎）
- 不可"我们最好"式自夸
- 案例引用需有客户授权

### 5. 平台规则
| 平台 | 必检项 |
|------|--------|
| 微信公众号 | 不放未授权二维码 / 不诱导分享 |
| 抖音 | 视频无版权 / 不诱导站外引流 |
| 知乎 | 不放外链微信号 / 不硬广 |
| B站 | 视频挂"合作"标签 |
| 小红书 | 不放微信号 / 标题无绝对化 |

## 输出格式

```python
{
  "passed": True | False,
  "issues": [
    {
      "type": "广告法" | "敏感词" | "数据" | "植入" | "平台规则",
      "level": "error" | "warning" | "info",
      "message": "...",
      "suggestion": "..."
    }
  ],
  "score": 0-100,  # 合规分数
  "recommendation": "pass" | "modify" | "reject"
}
```

## 处理流程

```
合规分 ≥ 90 → pass（推送飞书审核）
合规分 70-89 → modify（自动给出修改建议，飞书附注）
合规分 < 70 → reject（不推送，直接打回生成端）
```

## 失败模式

| 现象 | 解决 |
|------|------|
| 误报太多 | 调整阈值（V2 引入白名单） |
| 漏报敏感词 | 持续更新 `references/sensitive_words.md` |
| 平台规则变化 | 月度更新平台规则表 |

# yuxin-promoter-douyin

渔芯科技抖音短视频脚本生成器。30-60 秒倒计时结构 + 9:16 竖屏配图 + 强钩子开头。

## 适用场景

- 同主题公众号发布后，立刻出抖音版本形成流量互导
- 热点话题蹭流（V2 接入热搜 API）
- 抖音矩阵号内容填充

## 与公众号的差异

| 维度 | 公众号 | 抖音 |
|------|--------|------|
| 时长 | 5 分钟阅读 | 30-60 秒 |
| 字数 | 2000 | 100-150 |
| 配图 | 静态大图 | 9:16 竖屏（封面+3 帧） |
| CTA | 长按关注/扫码 | 评论扣 1 / 主页跳转 |
| 流量 | 私域沉淀 | 公域爆发 |
| 开头 | 故事钩子 | 3 秒钩子（决定完播率） |

## 工作流（5 步）

### Step 1: 共用选题
从 `yuxin-promoter-wechat` 的 `drafts/today_pick.json` 读取（**两平台必须同一天发**），或独立接收新选题。

### Step 2: 倒计时脚本（5 段式）

```
[0-3s] 钩子（决定完播率）
  模板 A：「90% 的老板都以为 X，其实 Y」
  模板 B：「这事儿如果不做，3 年后你会后悔」
  模板 C：「华哥说：X 不是你想的那样」

[3-10s] 痛点
  一句话点出观众的真实痛点

[10-30s] 核心（最快讲清楚）
  数据/案例/反常识 × 1-2 个

[30-45s] 渔芯方案
  一句话讲渔芯怎么解决（≤ 30 字，避免硬广）

[45-60s] 行动召唤
  「评论区扣 1，私你完整方案」
  「主页置顶有免费模板」
```

### Step 3: 配图 prompt（4 张）
- 封面：9:16 强视觉冲击（核心数据大字 + 背景色块）
- 钩子帧：开头 3 秒画面
- 核心帧：数据/案例展示
- 结尾帧：CTA + 渔芯 logo

### Step 4: 输出
保存到 `output/douyin_YYYY-MM-DD_<topic>.md`：

```markdown
# 抖音脚本 · <topic>

**时长**：45s
**发布平台**：抖音
**配图**：output/douyin_<topic>_*.png

---

## 0-3s 钩子
> 「XX 老板都搞错了，X 其实是 Y」

## 3-10s 痛点
> 真实场景

## 10-30s 核心
> 1. 数据
> 2. 反常识

## 30-45s 渔芯方案
> 一句话

## 45-60s CTA
> 「评论区扣 1」

---

## 拍摄备注
- 镜头：竖屏 9:16
- BGM：行业/科技类（推荐 BGM 库）
- 字幕：抖音自带字幕
- 演员：华哥本人（首选）
```

### Step 5: 推送飞书
调用 `feishu_content_bridge.send_draft(platform="抖音")`。

## 关键参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 时长 | 45s | 软下限 30s，上限 60s |
| 字数 | 100-150 | 含标点 |
| 钩子时长 | 3s | 决定完播率 |
| 配图 | 4 张 | 封面+3 帧 |
| CTA 形式 | 评论扣 1 | 互动引流 |

## 验收清单

- [ ] 钩子 3 秒内能引发兴趣
- [ ] 痛点准确（渔芯目标客户）
- [ ] 渔芯产品名出现次数 ≤ 2
- [ ] CTA 清晰
- [ ] 配图 9:16 比例正确
- [ ] 脚本可拍摄（不是 AI 自嗨）

## 失败模式

| 现象 | 解决 |
|------|------|
| 钩子太弱 | 用 3 个模板 A/B/C 选最强 |
| 超过 60s | 砍掉次要案例 |
| 渔芯植入太多 | 删到 1-2 处 |
| 没有 CTA | 必须有（评论扣 1 起步） |

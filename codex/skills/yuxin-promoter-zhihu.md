# yuxin-promoter-zhihu

渔芯科技知乎深度回答生成器。利用知乎长尾搜索 + 专业人设属性，沉淀行业话语权。

## 适用场景

- 知乎有相关问题，渔芯专业领域可回答
- 行业 KOL 提问，渔芯用专业答案刷存在感
- 知乎专栏/文章发布（V2 接入）

## 工作流（5 步）

### Step 1: 找到目标问题
- 输入：行业关键词（如"循环水养殖""AI Agent 落地"）
- 在知乎搜索相关高关注问题（V2 接入知乎 API）
- V1 手工输入：`question_url` + `question_title`

### Step 2: 拆解问题
- 拆出问题的核心矛盾（如"成本 vs 产量"）
- 列出 3-5 个被忽略的变量
- 引用 RKR 中的行业数据/案例（≥ 2 个）

### Step 3: 撰写回答（3 段式 + 1 总结）

```
[开头 100 字]
  亮明身份（渔芯科技 / 行业 X 年）
  一句话核心观点

[第一段 300 字 — 直接回答]
  不绕弯，正面回答问题

[第二段 500 字 — 拆解维度]
  维度 1：X 维度的解释
  维度 2：Y 维度的解释
  维度 3：Z 维度的解释
  引用 RKR 素材（每维度 1 数据）

[第三段 300 字 — 渔芯实践]
  我们怎么做的（具体数据/案例）
  提炼方法论

[总结 100 字]
  金句收尾
  引导关注/咨询
```

### Step 4: 配图（2-3 张）
- 核心数据图（柱状/饼图/流程）
- 渔芯项目实拍/截图
- 思维导图（可选）

### Step 5: 输出 + 推送
- 保存 `output/zhihu_YYYY-MM-DD_<question>.md`
- 调用 `feishu_content_bridge.send_draft(platform="知乎")`
- 人工审核通过后，手工复制到知乎（V2 接入 API 自动发）

## 关键参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 字数 | 1500 | 知乎深度回答 800-2000 字最佳 |
| 引用素材 | 2-3 条 | RKR 来源 |
| 数据来源 | 必须 | 不可"我觉得" |
| 渔芯植入 | 1 处 | 第三段自然带入 |
| 配图 | 2-3 张 | 知乎支持富文本 |

## 验收清单

- [ ] 开头亮明身份/专业
- [ ] 核心观点 1 句话清晰
- [ ] 拆解 ≥ 2 个维度
- [ ] 数据来源可追溯
- [ ] 渔芯产品名出现 ≤ 1 次
- [ ] 总结金句
- [ ] 引导关注/咨询

## 失败模式

| 现象 | 解决 |
|------|------|
| 回答太长没人看 | 砍到 1000-1500 字 |
| 引用数据不准 | 退回 RKR 调研 |
| 像广告 | 删到只剩 1 处植入 |
| 没法引发互动 | 加 1 个争议性观点 |

## 知乎生态铁律

⚠️ **知乎对外链/营销/硬广极度敏感**
- 不放微信号/二维码（用「主页有联系方式」替代）
- 不放渔芯产品链接（用「我们项目实拍在主页」替代）
- 触发审核机制 = 答案限流甚至封号

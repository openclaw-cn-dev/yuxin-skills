# yuxin-promoter-xiaohongshu

渔芯科技小红书图文笔记生成器。**官方无 API**，靠浏览器自动化 + 人工兜底发布。V1 仅生成内容，不直接发布。

## 适用场景

- 渔芯产品/案例在小红书有认知价值（工业风/科技感/创业故事）
- 同行已经在小红书种草，渔芯跟进
- **警告**：小红书对硬广/外链/营销号风控极严，建议先养号再发

## 工作流（6 步 — 最复杂）

### Step 1: 选题
- 输入：行业话题 + 笔记类型（"教程"/"测评"/"vlog"/"避雷"）
- 小红书热门关键词：参考 `references/xhs_hot_tags.md`

### Step 2: 标题党优化（小红书标题公式）

**核心：数字 + 痛点 + 解决方案 + emoji**
- 「💡 3 步搞定 RAS 循环水养殖成本计算」
- 「🚨 90% 老板都踩过的坑：设备选型」
- 「🌟 在东莞做 AI Agent 是种什么体验」

### Step 3: 正文（200-500 字）

```
[开头 50 字 — 抓人]
  反问/痛点/场景描述

[主体 300 字]
  干货（教程步骤/避雷点/测评）

[结尾 100 字]
  互动 + 引流
  「主页有完整方案」/「评论区扣 1 私你」
```

### Step 4: 9 图配图（小红书核心是图片）

**9 张图分配标准**：
- 图 1：封面（标题大字 + 主视觉）
- 图 2-3：痛点/场景图
- 图 4-6：核心干货/步骤/数据
- 图 7-8：渔芯产品/案例（轻度植入）
- 图 9：CTA + 主页指引

**风格要求**：
- 1:1 或 3:4 竖屏
- 暖色/小清新/ins 风（不冰冷）
- 字体大、信息密度高
- 视觉风格统一（参考 `references/xhs_visual_guide.md`）

### Step 5: 标签（10-15 个）

```
#渔芯科技 #循环水养殖 #AI Agent #创业日常
#东莞创业 #工厂实拍 #干货分享 #避雷指南
#智能养殖 #水产养殖 #科技改变生活
```

### Step 6: 输出 + 推送（V1 不自动发）

- 保存 `output/xiaohongshu_YYYY-MM-DD_<topic>.md` 含完整 9 图 prompt
- 推飞书审核
- **人工养号后手工发**（V2 接浏览器自动化）

## 关键参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 标题 | 数字+痛点+emoji | 28 字内 |
| 字数 | 300 | 软 200-500 |
| 配图 | 9 张 | 小红书黄金数 |
| 标签 | 12 个 | 10-15 之间 |
| 渔芯植入 | 1-2 处 | 仅图 7-8 软植入 |
| CTA | 主页/扣 1 | 不放微信号 |

## ⚠️ 小红书风控红线

| 行为 | 后果 |
|------|------|
| 一天发 ≥ 3 篇 | 限流 |
| 留微信号/二维码 | 封号 |
| 评论区大量引流 | 限流 |
| 标题/正文含"最""第一""绝对" | 违规词，限流 |
| 未养号直接发 | 几乎零曝光 |
| 多账号同 IP | 关联封号 |

## V1 兜底方案（推荐先用这个）

✅ **生成内容 + 人工养号 + 人工发**（每周 2 篇）
- 不强求自动化发布
- 先积累 50 篇优质笔记
- 形成账号权重后再考虑自动化

## 失败模式

| 现象 | 解决 |
|------|------|
| 标题被限流 | 换表述，避开"最""第一"等词 |
| 笔记零曝光 | 检查账号是否养号、IP 是否异常 |
| 评论区被折叠 | 不要在评论区放微信号 |
| 举报被封 | 内容严格自查，避免硬广 |

# yuxin-promoter-bilibili

渔芯科技 B站内容生成器。利用 B站技术/二次元氛围，做行业内容的人格化运营。

## 适用场景

- 渔芯技术团队/产品在 B站有面向年轻用户的认知建设需求
- 行业大佬/工程师人设建立
- 视频动态（轻量内容）填充

## 工作流（4 步）

### Step 1: 选题
- 输入：行业话题 + 风格（"硬核科普"/"轻松日常"/"工程实录"）
- 优先选 B站热门的"工程师视角"或"前沿黑科技"角度

### Step 2: 三种内容形态

#### 形态 A：B站动态（短文 + 图）
- 100-300 字
- 1-3 张图
- 适合：日常分享 / 行业新闻评论

#### 形态 B：B站专栏（长文）
- 1500-3000 字
- 多图 + 富文本
- 适合：技术深度 / 案例复盘

#### 形态 C：视频脚本（V2）
- 与抖音脚本类似但更长（3-5 分钟）
- 适合：工程实录 / 设备拆解

### Step 3: B站风格适配

| 维度 | 抖音 | B站 |
|------|------|-----|
| 语气 | 直接冲击 | 工程师式幽默（自嘲/玩梗） |
| 风格 | 强情绪 | 强信息密度 + 适度玩梗 |
| 配图 | 9:16 竖屏 | 16:9 横屏 / 方形 |
| 弹幕 | 不用考虑 | 留 1-2 个"梗点"引导弹幕 |
| 评论区 | 评论扣 1 | 提问/求资料 |

### Step 4: 输出 + 推送
- 保存 `output/bilibili_YYYY-MM-DD_<topic>_<type>.md`
- 推送飞书审核
- 通过后 V1 手工发，V2 接入 B站创作中心 API

## 关键参数

| 参数 | 动态 | 专栏 | 视频 |
|------|------|------|------|
| 字数 | 100-300 | 1500-3000 | 600-1500（脚本）|
| 配图 | 1-3 | 5-10 | 分镜图 |
| 时长 | 即时 | 5-10 分钟阅读 | 3-5 分钟 |
| 渔芯植入 | 0-1 | 1-2 | 1-2 |

## 验收清单

- [ ] 风格符合 B站工程师人设
- [ ] 玩梗自然（不刻意）
- [ ] 信息密度高
- [ ] 无广告感
- [ ] 留 1-2 个互动点

## 失败模式

| 现象 | 解决 |
|------|------|
| 太硬广被喷 | 删渔芯植入到 1 处 |
| 梗不自然 | 删掉不熟的黑话 |
| 像公众号 | 改 B站工程师口吻（自嘲+玩梗） |
| 没互动点 | 结尾加"求三连"/"评论区聊聊" |

## B站生态铁律

⚠️ **B站用户对广告极其敏感**，"赞助商"标签要明显
- 视频：必须挂"合作"标签（V2 接入时）
- 动态/专栏：避免硬性品牌词堆叠
- 一旦被标记"营销号"，权重暴跌

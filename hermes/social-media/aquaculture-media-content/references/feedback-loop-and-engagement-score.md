# L5 反馈闭环 + 互动分公式

> **作者**：Hermes Agent @ 2026-06-10
> **核心思想**：发布 → log 数据 → 周报 → 入库 RAG → 反哺 L1-L3 → 指导新选题
> **3 个工具脚本**：`log_post.py` / `weekly_stats.py` / `ingest_post_data.py`

## 互动分公式（**4 群商业化核心 KPI**）

| 互动类型 | 分数 | 为什么 |
|---|---|---|
| 点赞 | 1 分 | 基础反馈 |
| **收藏** | **2 分** | **比点赞有价值**——用户愿意回头看 |
| **评论** | **3 分** | **最有价值**——产生双向互动 |
| 分享 | 5 分 | 传播价值（**难量化**，单独记）|

**公式**：`互动分 = 点赞 + 收藏*2 + 评论*3`

## 30 天节奏

| 节奏 | 操作 | 时间 |
|---|---|---|
| **每日** | 发笔记 → log 数据 | 5 + 1 分钟 |
| **每周日** | weekly_stats 跑周报 → ingest 入库 | 2 + 1 分钟 |
| **每月** | 复盘 + 优化 L3 模板 | 30 分钟 |
| **每季** | 调整 4 群推送 + 商业化收尾 | 60 分钟 |

## log_post.py（5 秒记录）

```bash
# 用法
python log_post.py "标题" "标题类型" "平台" 点赞 收藏 评论

# 标题类型：反常识/悬念/数字反差/大厨背书/其他
# 平台：小红书/抖音/头条/视频号/微博

# 示例
python log_post.py "白灼虾最忌用水煮就错了" "反常识" "小红书" 300 100 50
```

**注意**：
- 参数顺序：title, title_type, platform, likes, saves, comments
- 函数签名：`log_post(title, platform, likes, saves, comments, title_type)`
- 调用时调换 type 和 platform 位置

## weekly_stats.py（周日跑）

```bash
python weekly_stats.py
```

**输出**：
- `C:\Users\Administrator\Desktop\知识库\发布数据\周报\YYYY-MM-DD_周报.md`
- 含总览 + Top 3 + 平台分布 + 标题类型分布 + 全部发布 + 洞察 + 下周计划

**互动分排序**：高 → 低（Top 3 = 印钞机）

## 30 天后 → 数据反哺 L3

**没有 L5 反馈闭环**：
- 凭感觉发 → 30 天后不知道什么好用
- 浪费精力 → 重复犯同样错误

**有了 L5 反馈闭环**：
- 数据指导 → 30 天后有自己的爆款公式
- 持续优化 → L3 模板不断升级（基于**你的真实数据**）
- 商业化 → Top 3 选题 = 印钞机

## 4 群推送时间规律

| 群 | 最佳时间 | 理由 |
|---|---|---|
| 🦐 美食 | 晚上 6-9 点 | 饭点前刷手机 |
| 🐟 养殖 | 早上 7-9 点 | 技术人员看 |
| ⚙️ 设备 | 下午 2-5 点 | 采购员看 |
| 🏢 公司 | 早上 9-10 点 | 投资人看 |

## 平台区分（**互动分权重**）

| 平台 | 重视指标 | 原因 |
|---|---|---|
| 小红书 | 收藏 > 点赞 | 用户重收藏 |
| 抖音 | 完播 + 评论 > 点赞 | 重互动 |
| 头条 | 阅读 + 评论 | 重内容 |
| 视频号 | 点赞 + 转发 | 社交传播 |

## 5 大反常识（30 天后你会发现）

1. **数字反差** 比 **反常识** 命中率高？（看你自己的数据）
2. **小红书** 比 **抖音** 收藏多？
3. **评论 > 点赞**（评论 1 = 点赞 3）
4. **Top 3** 贡献 70%+ 互动分
5. **公式可叠加**：反常识 + 数字反差 + 大厨背书 = 王炸

## 实战判断标准

**30 天目标**：
- 发布条数：30+
- 总互动分：5000+
- 平均互动分：150+
- Top 3 占比：50%+
- 选题复用率：30%+

**如果达不到**：
- 标题类型没选对（多用 Layer 3 模板）
- 平台没选对（看最佳平台数据）
- 时间没选对（按上表时间发）
- 钩子不够强（看 Layer 3 30 钩子句）

## 框架核心（4 维度 × 必带具体例子）

任何业务线的爆款标题反向分析都按这 4 维度展开。**关键约束：每个公式必须举 3 个真实例子**——不是写"反常识有 X 种"。

### 维度 1：标题公式（4 种 × 各 3 例）

| 公式 | 模式 | 频次（按业务线加权）|
|---|---|---|
| 🔴 **反常识** | "你以为的 XX 全错了" | 美食类 50%、养殖 30% |
| 🟡 **悬念/反问** | "到底是 XX 还是 XX" | 视频号/抖音 强；图文略弱 |
| 🟢 **数字反差** | "用数字做承诺" | 设备/养殖 70%（节能 20% / 增产 50% / 成本降 50%）|
| 🔵 **大厨/老渔民/专家背书** | "权威人物代言" | 美食 90%、养殖 50% |

### 维度 2：钩子句模板（**黄金 3 句**）

按业务线给具体模板 + 频次：

| 业务线 | 黄金钩子 | 例子 |
|---|---|---|
| 美食 | "xxx 就错了/不对！教你正确方法" | 白灼大虾放油放盐都不对 / 用水煮就错了 |
| 养殖 | "xxx 别猛喂/别直接……，五个诀窍少亏钱" | 高温养虾别猛喂 / 持续阴雨天养虾核心技巧 |
| 设备 | "看似简单其实全是坑" + "X 个设备必不可少" | 建循环水系统 3 个设备必不可少 / 教你避开 90% 新手会踩的坑 |
| 公司 | "机构调研 + 分红 + 海外战略" | 海大集团接待 UBS 等 104 家机构 / 派发 18 亿元现金分红 |

### 维度 3：选题打分（**TOP 5 候选 + 评分函数**）

**可复制评分函数**（2026-06-22 8 点 cron 实战验证）：

```python
def score(t):
    s = 0
    if re.search('(错了|不对|大错|误区)', t): s += 3          # 反常识（最强信号）
    if re.search('(从来不|别再|从不|我家从来)', t): s += 3    # 否定旧习惯
    if re.search('(大厨|渔民|海边)', t): s += 2              # 身份背书
    if re.search(r'\d', t) and re.search('(斤|万|倍|招|点)', t): s += 2  # 数字反差
    if '?' in t or '？' in t: s += 2                          # 悬念
    if 15 <= len(t) <= 30: s += 2                            # 黄金字数
    if re.search('(保姆级|坦白局|避坑|新手|干货)', t): s += 2  # 价值信号词
    if 'Q弹' in t or '鲜嫩' in t or '清香' in t: s += 1       # 美食利益点
    return s
```

**经验阈值**：8-10 分 = 必拍爆款；5-7 分 = 候选；≤4 分 = 备选。

### 维度 4：节奏规律（**数据说话**）

| 指标 | 数值（2026-06-12 实测）| 数值（2026-06-22 实测，84 条）| 启示 |
|---|---|---|---|
| 标题字数均值 | 21.2 字 | **22.2 字** | 黄金 18-25，**不要超 30** |
| 字数 ≤ 15 字 | 24% | — | 美食类偏短 |
| 字数 26-35 字 | 34% | — | 养殖/设备类需装技术词 |
| 感叹号 | 13% | **13.1%** | **不要滥**——美食钩子可以，新闻稿不要 |
| 问号 | 10% | **13.1%** | 强悬念（"5 分钟还是 10 分钟？"），视频号适配 |
| emoji | 0% | **0%** | **头条/搜狗端几乎不用**；小红书/抖音可加 🦐🐟 |
| # 标签 | — | **0%** | 头条/搜狗不流行；小红书可加 2-3 个 |

**核心结论**：爆款 = **18-25 字 + 反常识钩子 + 数字/大厨背书**。超 30 字直接划走。

**6-22 实战发现**：84 条样本里只有 **3 条反常识**（< 4%）、但**这 3 条全部进入 Top 2**——验证了"反常识是稀缺高价值公式"的判断，**老大短视频选题应优先反常识**。

### 去重

```python
import re
all_titles = []
seen = set()
for kw, titles in raw_dict.items():
    for t in titles:
        t2 = re.sub(r'[_\-\|/].*$', '', t).strip()
        key = re.sub(r'\s+', '', t).lower()
        if key not in seen and len(t) > 4:
            seen.add(key)
            all_titles.append((kw, t))
```

**为什么用 `\s+` + `lower()`**：
- 头条/搜狗常返回 2 条几乎相同的（中英文标点不同）
- 如 "白灼大虾，放油、放盐都不对!" 和 "白灼大虾，放油、放盐都不对！" —— 实际是同一标题

## 复用此框架到其他业务线

### 美食（如：白灼虾/红烧肉/烤鱼）

- **关键词模板**：菜名 + "做法" / 菜名 + "配方" / 菜名 + "教程"
- **公式优先级**：反常识 > 大厨 > 数字 > 悬念
- **钩子模板**：xxx 就错了！xxx 别直接加水煮！xxx 不用去饭店！

### 养殖（如：对虾/罗非鱼/海参）

- **关键词模板**：物种 + "养殖" / "技术" / "成本"
- **公式优先级**：数字反差 > 钩子（诀窍）> 悬念 > 大厨
- **钩子模板**：xxx 别猛喂！xxx 五个投喂诀窍 / 教你避开 90% 新手会踩的坑

### 设备（如：循环水/蛋白分离/UV）

- **关键词模板**：设备名 + "原理" / "选型" / "节能"
- **公式优先级**：数字反差 > 钩子（避坑）> 反常识
- **钩子模板**：xx 设备怎么选？xx 系统节能 20% / 这 3 个设备必不可少

### 公司（如：海大/通威/獐子岛）

- **关键词模板**：公司名 + "财报" / "公告" / "调研"
- **公式优先级**：数字反差 > 反常识（增收不增利）> 大机构背书
- **钩子模板**：接待 X 家机构 / X 亿分红 / 海外战略 / 管理层架构调整

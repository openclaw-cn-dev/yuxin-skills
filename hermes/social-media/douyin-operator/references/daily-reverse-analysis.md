# 每日 8 点爆款反向分析（小红书）

> 用途：每天 8 点 cron 跑"昨日爆款反向分析" → 给老大一张飞书卡片 + 明日选题建议
> 已实战：2026-06-10（基于 2026-06-08 入库数据首跑）
> 关联 skill：`douyin-operator`（爆款公式库）、`aquaculture-content-sourcing`（9 点入库数据源）

## 🎯 任务定义

**给老大的产物**：1 张飞书卡片，含 4 维度反向分析 + 3-5 个**明日选题建议**（仅标题 + 公式 + 预期，**不写文案**）。

**核心原则**：
- 选题建议是**给老大审核**的，**不擅自写文案 + 4 图**
- 等老大批准后才出文案 + 4 图
- 老大回复 "1" / "a" / "B" → 出对应选题的完整物料

## 📂 数据源路径（写死）

```
# 1. 昨日入库爆款笔记
C:\Users\Administrator\Desktop\小红书\爆款10篇\{NN_主题}\
  ├── 文案.md
  ├── 配图说明.md
  └── img1.jpg ~ img4.jpg（每篇 4 张真图）

# 2. 昨日知识库（4 子库）
C:\Users\Administrator\Desktop\知识库\daily\{昨天日期}\
  ├── 美食.md
  ├── 设备.md
  ├── 设备公司.md
  └── 养殖.md
```

**日期计算**：`昨天 = today - 1 day`（用 `date -d 'yesterday' +%Y-%m-%d` 或 `python -c "from datetime import date, timedelta; print(date.today()-timedelta(days=1))"`）

**回退路径**（无昨日数据时）：优先取 `daily/` 下**最近一个日期**的目录，并在卡片里标注"⚠️ 昨日无数据，用 X 天前代替"。

## 🔍 4 维度反向分析框架

### A. 选题维度
- **最多主题**：统计品类出现频次（虾/鱼/蟹/贝...），找出 Top 1-3
- **季节热点**：扫标签里的"夏日/冬季/年夜饭/减脂"等季节关键词
- **事件驱动**：从 `知识库/daily/{date}/` 的"标准/政策/展会"类条目找（如"美国禁中国自捕虾"）

### B. 爆款公式维度
- **避坑型**：标题含"千万别/不要/≠/白搭/避坑"
- **数字反差**：含"A vs B"对比（50斤 vs 5斤 / 8000 vs 800 / 海鲈 vs 罗非）
- **透明价/对比表**：正文带 markdown 表格
- **结论**：找**出现频次最高的公式组合**（实战发现：避坑 + 数字反差 = 双重钩子）

### C. 关键词维度
- **Top 5**：扫所有文案标题 + 正文，统计名词/动词，去停用词（的/了/是/在）
- **长尾词**：3 字以上高价值组合（"存活率 30%""1立方水养 50 斤"）
- **情绪词**：避坑/必看/舔盘/踩坑/后悔/翻倍

### D. 配图维度
- **风格**：从"配图说明.md"读主题（Pexels ID + 主题标签）
- **真图 vs SD**：看"配图说明.md"是否标 "Pexels CC0 / ✅ 视觉验证"
- **点击最强主题**：筷子夹虾特写 / 蒸气升腾 / 木桌摆盘

## ⚠️ 3 大踩坑（写死，别再踩）

### 1. **🛑 字数硬上限 600，超了就砍**
- 实测：第 1 版 935 字 → 砍到 586 字达标
- 砍法优先级：合并同类项（"美食5/养殖3/设备2"→只留"10 篇"）> 删 emoji 装饰 > 砍表格改短句
- **不要**砍数据维度，砍的是装饰和重复

### 2. **🛑 选题建议只给标题 + 公式 + 预期**，**不写文案**
- 老大的红线："明日选题是**给老大审核的**，**不擅自写文案**"
- 错误做法：直接出 4 个选题的完整文案 + 配图 prompt
- 正确做法：只列标题 → 等老大回复 "1"/"2"/"a"/"b" → 才出对应那条的完整物料

### 3. **🛑 cron 任务的"推送"指令是误导**
- 任务里写"推送 send_message action='send' target='feishu'"
- **但 cron runtime 真消息是**："DELIVERY: Your final response will be automatically delivered to the user — do NOT use send_message or try to deliver the output yourself"
- **正确做法**：把卡片内容**直接写在 final response 里** → 系统自动转飞书
- **不要再尝试 send_message**（cron session 通常没装飞书 plugin，会直接报错）

## 🔁 标准流程（5 步）

1. **算日期**：`yesterday = today - 1 day`
2. **读数据**：
   - `Desktop\小红书\爆款10篇\{NN_主题}\文案.md`（10 篇）
   - `Desktop\小红书\爆款10篇\{NN_主题}\配图说明.md`（10 篇）
   - `Desktop\知识库\daily\{yesterday}\*.md`（4 子库）
3. **跑 4 维度分析**：用 Python 字符串扫一遍（不用 LLM，太慢）
4. **生成明日选题**：3-5 个标题，每个标公式 + 预期（高/中/低）
5. **压缩到 ≤600 字** → 写 final response → 系统自动推飞书

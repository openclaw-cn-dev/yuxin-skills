# 4 群 RAG 部署完整流程（实战验证 2026-06-10）

## 适用场景

老板要建 N 个业务群（美食/养殖/设备/公司...），每群配独立 RAG 客服。

## 6 步流程

### Step 1：建 4 群（老大手动）

飞书 App → 右上角 `+` → 创建群 → 普通群。

**4 群命名建议**（**直接复制**）：

| 群名 | 群描述 |
|---|---|
| 🦐 水产美食社 | 食谱 / 选品 / 评测 / 避坑 |
| 🐟 水产养殖圈 | 技术 / 行情 / 设备 / 培训 |
| ⚙️ 水产设备库 | 工厂化 / 循环水 / 蛋白分离 / IoT |
| 🏢 水产上市公司 | 财报 / 公告 / 行业研究 / 投资 |

### Step 2：拉机器人（老大手动 + 必做）

4 群都拉小弟机器人。

**关键**：**必须真拉到群里**——**没拉 = `230002 Bot/User can NOT be out of the chat` 错误**。

操作：
1. 飞书管理后台 → 应用 → 找小弟机器人
2. 打开群 → 群设置 → 群机器人 → 添加 → 选小弟
3. 给发消息权限
4. 4 群都加

### Step 3：获取 chat_id

老大手动操作：
- 在群里发一条消息
- 飞书开放平台 → 事件订阅 → 消息接收 → 看 webhook 日志
- 找 `chat_id`（格式 `oc_xxx` 32 位 hex）

或者问小弟（小弟能从飞书 API 拉群列表）。

### Step 4：填 groups_config.json

```json
{
  "groups": [
    {"name": "🦐 水产美食社", "chat_id": "oc_xxxxx", "topic": "美食", "status": "active"},
    {"name": "🐟 水产养殖圈", "chat_id": "oc_xxxxx", "topic": "养殖", "status": "active"},
    {"name": "⚙️ 水产设备库", "chat_id": "oc_xxxxx", "topic": "设备", "status": "active"},
    {"name": "🏢 水产上市公司", "chat_id": "oc_xxxxx", "topic": "公司", "status": "active"}
  ]
}
```

### Step 5：RAG 主题化推送

每群推一个**主题化**的 RAG 查询（**避免 4 群重复**）：

```python
queries = [
    ('白灼虾怎么做', '美食'),
    ('对虾养殖技术要点', '养殖'),
    ('工厂化循环水养殖的原理', '设备'),
    ('恒兴股份有哪些产品', '公司'),
]
for q, topic in queries:
    chat_id = groups_map[topic]
    answer = query_rag(q)
    send_message(target=f"feishu:{chat_id}", message=answer)
```

### Step 6：升级召回精准度（重要！）

**RAG 召回不精准 ≠ 引擎错，是知识库颗粒度不够**。

补 5-10 篇目标主题的细颗粒文档：

| 群 | 补什么 | 数量 |
|---|---|---|
| 🦐 美食 | 食谱（白灼虾/蒜蓉虾/椒盐虾/海鲜汤/一鱼两吃）| 5 篇 |
| 🐟 养殖 | 技术档（溶解氧/pH/水温/密度/亚硝酸盐）| 5 篇 |
| ⚙️ 设备 | 原理档（循环水/蛋白分离/生物滤/UV/增氧）| 5 篇 |
| 🏢 公司 | 财报档（恒兴/海大/通威/獐子岛/东方海洋/好当家/粤海）| 7 篇 |

跑 `rag_setup.py` 重建索引 → 4 群召回精准度大幅提升。

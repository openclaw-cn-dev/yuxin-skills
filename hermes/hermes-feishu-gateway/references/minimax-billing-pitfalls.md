# MiniMax 平台充值陷阱 — 2026-06-07 真实踩坑

**症状**：key 配对正确（probe 200）、`hermes chat` / gateway 仍返 `HTTP 402: insufficient balance (1008)`。老大说"账号有钱"但机器人就是不出字。

**根因（MiniMax 平台特有，外部文档不写）**：

MiniMax 平台有 **2 个完全独立的计费池**，**充错地方 = 钱白充**：

| 计费池 | 平台 UI 位置 | 适用场景 | key 能不能用 |
|---|---|---|---|
| **主钱包 / 现金余额** | 「我的钱包」/「账户余额」 | MaaS、订阅、包月卡、模型市场 | ❌ **不能用** key 调用 |
| **API 按量账户** | 「**API 余额** / **Billing** / **Credits**」 | `api.minimaxi.com` API key 按 token 扣费 | ✅ 唯一能让 key 工作的余额 |

**两个余额分开**——主钱包充 1 万块，API 账户仍 0；API 账户充 1 万块，主钱包 0。**老大常见误区**："我看账户有钱了"——其实只看了主钱包，**API 按量账户没动**。

---

## 5 秒诊断（必做）

让老大在 platform.minimaxi.com **截「API 余额」页**发小弟，**不要截图主钱包**。具体路径：

1. 登录 https://platform.minimaxi.com
2. 左侧菜单找「**账户 / Billing / 充值**」
3. 点「**API 余额** / **API 充值** / **Credits**」子页（**不是「我的钱包」也不是「总览」**）
4. 关键数字：
   - **API 余额**（按量扣费池，**这个才是 key 用的**）
   - **钱包余额**（主账户，充了也没用）
   - **订阅 / 套餐状态**（包月卡）
5. 截图发小弟

**如果 API 余额 = 0** → 之前充错地方。**点"充值"时看清楚选的是"钱包"还是"API 账户"**——MiniMax 有些地方会默认跳到主钱包。

**如果 API 余额 > 0** → 截图发小弟，可能是平台 bug 或新 key 同步延迟。

---

## 5 个换 key 不解决的硬信号

🛑 **换 key 不解决账户问题**。如果出现以下任一信号，**立刻停止换 key，直接去查 API 账户余额**：

1. **Key A 402** → 换 Key B → **仍 402** = 不是 key 问题
2. **`GET /v1/models` 返 200**（key 有效）+ **`POST /v1/chat/completions` 返 402**（余额不足）= 永远账户问题
3. **两个不同前缀 key（`sk-api-x` + `sk-cp-L`）都 402** = 同一账户没钱
4. **老大说"充了" / "有钱"** = 大概率充的主钱包，不是 API 账户
5. **报错有 `(1008)` 错误码** = MiniMax 平台标准"账户余额不足"，**不是 key 错**

---

## 正确充钱操作（5 步）

1. 打开 https://platform.minimaxi.com 登录
2. 左侧菜单「**账户 / 充值**」
3. 找「**API 余额**」或「**API 充值**」**子页**（不是「钱包」或「总览」）
4. 点「充值 / Top up」选金额（¥50-100 试水，MiniMax-M3 价 ¥0.3/百万 token）
5. **付款前再次确认选的是"API 账户"**，不是"主钱包"

充完跟小弟说"充了"，小弟立刻 `hermes chat -p X -q "hi"` 验证。

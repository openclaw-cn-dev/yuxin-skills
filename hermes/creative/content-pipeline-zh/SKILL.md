# 中文内容生产流水线

## 适用场景

用户要从一个主题（如"水产物美"、"工厂化养殖"）产出 1 篇或多篇可发布的中文短内容 + 配图 + 推送。

## 标准流水线（4 步）

```
1. 选题（爆款公式）
2. 文案（第一人称 + 数字 + 反差 + 避坑 + 互动）
3. 配图（4 张/篇，必经 vision 验真图）
4. 落地（桌面文件夹 + 飞书卡片推送）
```

## 关键原则（用户红线）

- **结果导向**：不要问"要不要做"、"哪个好"，直接出方案 + 交付
- **不要 AI 腔**：禁"首先/其次/最后"、禁"绝绝子/家人们"
- **数字+表格+emoji**：用户偏好可视化结构
- **不要复述**：交付完不总结、不解释"我刚才做了什么"
- **"看着办" = 自决**：选最强方案直接干
- **绝对不要编 ID/数字**：Pexels ID、worker ID、job ID 等可以验的，全部要验证

## 爆款公式（已实战验证）

```
标题 = 痛点 + 数字 + 反差
正文 = 第一人称 + 数字证据 + 反常识 + 避坑 + 互动钩子
标签 = 5-10 个 #，蹭大流量 + 行业精准词
```

示例爆款标题（实战转化率 8-12%）：
- 「煮了 10 年虾才知道❗️千万别冷水下锅」
- 「救命🆘 我怎么没早点学会煮虾」
- 「一只海鲈鱼 2 道菜🐟80 块吃出 200 块」
- 「海鲈 vs 罗非 哪个更赚钱🤔3 年白干 vs 年入 30 万」

## 老大亲测有效的"老渔民女儿"人设模板（2026-06-13 一晚上写 20 篇验证）

> 这是老大**自己跑通的爆款 IP**——别再问"用什么人设"了，**直接套这个**。

**人设核心**（**3 个必带元素**）：

1. **身份**："老渔民女儿" / "30 年渔民家" / "我从小在海边长大"（**渔民 + 女儿 = 温度 + 信任**）
2. **反差钩子**：饭店价 / 在家价 = **数字反差**（**88/30、168/60、188/80** 是 3 个标杆）
3. **灵魂元素**：**老渔民家传秘方** + **妈妈教的** / **爸爸教的** 1 个小心机（**每篇必带**）

**正文结构**（**7 段式 / 650-750 字**）：

```
❌ 误区开场（**99% 人都做错这 3 步**，**3 大错误**用 emoji 列出）
   → 数字反差（**饭店 XX / 在家 YY**）
   → "我之前自己也翻车" 真实感
   → "后来妈妈/爸爸教我 1 招" 转折

✅ 3 步法（**数字编号 + 每步 3-5 个 ✅**）
   第 1 步：选材（**决定 80% 口感**）
   第 2 步：处理（**时间 + 数字**）
   第 3 步：灵魂步骤（**金蒜 / 紫苏 / 啤酒等老渔民独家**）

🍴 灵魂蘸料/配方（**配比数字**）
🌟 爸爸/妈妈 1 个小心机（**老渔民家传**）

💬 互动钩子
   → "你做 XX 有翻车过吗？"
   → "评论区扣 XX → 送你 YY"

📌 关键数字速记（**截图/收藏率高**）
#hashtags（**5-8 个**）
```

**标题公式**（**5 大金刚**）：

| 公式 | 模板 | 案例 |
|---|---|---|
| **数字反差** | 饭店 XX / 在家 YY | "饭店 168，在家 60 块搞定" |
| **反常识** | 千万别 XX | "白灼大虾千万别直接水煮" |
| **3 大错误** | 99% 人都做错 | "99% 的人都做错这 3 步" |
| **数字证据** | 1 平方 = XX 斤 = 年入 XX 万 | "1 平方 35 斤虾 = 年入 90 万" |
| **避坑** | 90% 老板/新手都踩 | "90% 新手第 1 件就买错" |

**3 业务线内容池**（**每线 5-10 篇轮换**）：

| 业务线 | 占比 | 钩子库 | 变现 |
|---|---|---|---|
| 🦐 美食 | 50% | 数字反差 + 老渔民 | 配方 + 探店 + 礼盒 |
| 🐟 养殖 | 25% | 数字 + 探秘 | 苗 + 饲料 + 培训 |
| ⚙️ 设备 | 25% | 避坑 + 数字 | 设备销售 + 设计 + 培训 |

**30 天排期模板**（**批量生产 SOP**）：

```
Week 1：美食引流 5 篇（涨粉）
Week 2：养殖专业 5 篇（质量 + 私域）
Week 3：设备变现 5 篇（私域 + 变现）
Week 4：复盘 + 深度变现 5 篇

每篇 650-750 字 + 6 张 SD prompt + 1 分钟短视频脚本
3 业务线联动：美食结尾→养殖，养殖结尾→设备，设备结尾→老板案例
```

**关键铁律**（**这 1 周踩过的坑**）：

- ✅ 每篇**必带 1 个老渔民家传小心机** = 评论区必互动
- ✅ 数字要**精确**（"30 秒" / "15 头/斤" / "180℃" / "5-8%"）—— **不要"几分钟"**
- ✅ 标签**5-8 个**就行，**不要 20+ 个**
- ❌ 不要写"30 年渔民女儿"—— 写"**从小在海边长大，30 年渔民家**"（**更新鲜**）
- ❌ 不要用"首先/其次/最后" AI 腔
- ❌ 不要结尾加客套话（"希望对您有帮助"）

## 已知限制

- 设备/养殖类主题，配图主题贴切度难，**但 Bing + 中文关键词够用**（2026-06-09 验证）
  - ✅ 06-10 设备篇 5 篇 ×4 张 =20 张全部 Bing 抓出真图（工厂化车间、对虾塘、罗非鱼、蛋白分离器、增氧机）
  - ❌ **英文关键词基本 0 结果**（"indoor recirculating aquaculture" / "RAS facility" 全部无 murl 命中）
  - ✅ **中文关键词一抓一个准**（"工厂化循环水养殖 车间" → 35 个 murl）
- ⚠️ 国内 CDN 图常带水印（渔帮手、装饰画、商家 logo）—— 抓完**必须** vision 验图，**第一遍 09 篇挂出过"禅"字装饰画、沙漠岩石、汽修工人**
- 抽 1-2 张图用 vision_analyze 验明主题，不验=50% 翻车
- Stable Horde worker 经常返 92B 假图（hack 节点骗 kudos）
- Polinations image.pollinations.ai 现在要 USD Coin 付费
- HuggingFace Inference API 在本机 SSL 全挂
- 抖音搜索需要 X-Bogus 签名
- ⚠️ **"做的怎么样了"重复问是求救信号，不是问进度**——上一次是因为 09 篇配图真没干完 + Windows 打开文件夹 explorer 反复被 gateway 截断。修复：交付总结里直接给"✅ N/M + 文件路径"表格，不要说"已就位"等模糊词；GUI 启动用 Python `os.startfile` 不用 bash `&`

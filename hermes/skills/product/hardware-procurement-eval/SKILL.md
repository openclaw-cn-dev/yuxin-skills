# 硬件采购评估与报价核价

## 触发条件
- 华哥转发外部配置报价单要求对比市场价（"帮我做个性价比对比"）
- 问某台现有机型的升级价值（"机带RAM 16G 3200MHz 够不够/要不要加"）
- AI 开发机/训练机选型、GPU 显存档位选择
- 渔芯硬件设备（服务器/工作站）采购前评估

## 铁律
1. **结论先行**：第一句话给判定（值/不值/虚高多少），然后才是表。华哥不要长铺垫（用户档案明确）。
2. **外部报价单一律当"外部AI初稿"对待**：交叉核价不盲信（同"豆包出初稿玉芬整理"模式）。2026-10 实战：外部报价单虚高 50-70%（内存报 4 倍、显卡报 1.5 倍）。
3. **价格必须当日检索**：存储/显卡价格周级别剧烈波动，引用价必须带日期戳，报告落款注明"下单前以当日京东自营价为准"。

## 核价六步法
1. 逐项列报价单 → web_search 每个配件市场价（京东自营优先，ZOL"手慢无"/什么值得买/B站装机行情/华强北商户报道佐证，≥2 源交叉）
2. 同配置合计 → 算溢价率
3. 成品整机对比（品牌装机店整机价 = 自配下限参照）
4. AI 开发视角三查：显存容量锚点 / 内存与显存花费占比合理性 / CPU 平台风险（Intel 13/14 代缩肛→盒装行货留凭证或改 AMD）
5. 产三档方案：A 同配置砍价 / B 同预算强化 / C 务实降配+云租，各标适合场景与价格
6. 归档：报告写入「研-如何配置合适的电脑」项目（路径见下），飞书回复带对比表+一句话结论

## 领域锚点（2026-10 基线，详见 references/market-sources-and-anchors.md）
- **显存决定论**：16G=7B-14B 量化推理+7B LoRA；24G=14B LoRA/32B 量化推理。训练瓶颈先看显存再看系统内存——报价单里内存接近显卡价 = 本末倒置信号。
- **报价单合理性直觉**：内存总价接近显卡总价 = 报假价（64G DDR5 现货 ~1500-2400，报 8000 必假）。
- **内存周期判断**：2026 年 DRAM 超级周期（AI 需求），暴涨后回落中。涨价期：老机不投钱升级、新机内存可观望；跌价通道：可下手。合约价与现货价背离时分开表述。
- **老机升级三查**：插槽余量 × 内存周期位置 × 平台代际。DDR4→DDR5 淘汰期只做零成本利用，不大额加装。
- 判代际：3200MHz 及以下=DDR4；4800+ =DDR5。Windows"机带RAM"=原装内存。

## 交付格式（华哥偏好，已验证有效）
1. 结论先行一句话（虚高 X 元 / 溢价 Y%，不建议成交）
2. 逐项对比表：配件 | 报价 | 市场参考价 | 判定（✅/⚠️/❌）
3. 整机市场对比小表
4. 三档方案表（A/B/C + 价格 + 适合场景）
5. 风险提醒 ≤2 条（缩肛 / 显存天花板 / 时机）
6. 收尾主动提议下一步（"要不要按京东实时价出可下单清单"）

## Pitfalls
- 搜索"型号+价格"常被电商 SEO 页污染：加年份词限定 + 优先京东/ZOL/smzdm 结果
- 内存报道"暴跌"与"涨20%"并存是常态——合约价 vs 现货价背离，写作必须区分，否则结论打架
- 国行建议价 ≠ 成交价（5070Ti 建议价 6299，京东活动 5799-6802），以活动价为准
- 报价单可能来自"关系户"：结论只给市场价弹药供华哥砍价，不替他做人情判断

# 渔芯知识库 · 调研结论入库（主动上传路线）

> 2026-11-06 华哥定调：智能体调研数据走**主动上传**（MCP `kb_ingest` → `POST /v1/admin/ingest`），
> 定时扫目录仅作兜底。MCP `yuxin-kb` 已接生产（读写同一库）。

## 何时用

- 完成一次调研/资料整理，结论需要**长期可检索**时；
- 华哥说「存进知识库 / 入库 / 沉淀一下 / 记到库里」。

## 怎么做（MCP 工具 `kb_ingest`，已接好）

| 参数 | 必填 | 规则 |
|---|---|---|
| `title` | 是 | ≤300 字，具体到主题/对象（如「YJ-150 增氧机现场调试参数」） |
| `content` | 是 | Markdown 正文，≤200 万字符；结论 + 关键数据 + 来源 + 日期 |
| `domain` | 是 | `aqua` 养殖 / `eng` 工程 / `ai` 智能 / `life` 生活 |
| `source_url` | 否 | 原始链接（调研来源） |

正文建议结构：**结论先行 → 关键事实/数据 → 来源链接 → 日期**。
相同正文重复写入会返回 `duplicate` + 原 `doc_id`，不会重复入库（内容哈希去重）。

## 域判定（判不准就问华哥，不要猜）

- 养殖设备 / 工艺 / 病害 / 水质 / 品种 → `aqua`
- 图纸 / 结算 / 合同 / 报价 / 工程规范 → `eng`
- 论文 / 代码 / 提示词 / 评测 / AI 工具 → `ai`
- 笔记 / 灵感 / 生活 / 财务 / 健康 → `life`

## 验证

1. 写入返回 `doc_id` / 块数 / 向量化状态；
2. 用 `kb_search` 查标题关键词，确认命中；
3. MCP 已指向生产 `https://lookforge.net`（读写一致，不写本地开发库）。

## 失败处理

- `401/403`：token 失效（`KB_ADMIN_TOKEN` 在 `~/.hermes/.env`），不要反复重试；
- `429`：写入口限流（默认 30 次/分钟/客户端），稍后重试；
- `503` / 超时：API 不可用，记录后稍后重试，不要烧 token 空转。

## 铁律

- **四域必须显式**，禁止留空（空域 = 待复审脏数据）；
- 不把密码/密钥/手机号等敏感信息写进正文；
- 一次调研产出一篇，不要把多篇拼成一个文档；
- 写库前若正文含外部原文大段复制，先摘要改写，避免版权与噪声。

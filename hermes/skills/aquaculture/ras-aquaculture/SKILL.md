## 一、RAS系统核心组成

### 主要设备模块
| 模块 | 功能 | 关键设备 |
|------|------|----------|
| **固体过滤** | 去除粪便、残饵 | 微滤机、滚筒过滤 |
| **生物过滤** | 氨氮/亚硝酸盐转化 | 滴流滤池、移动床生物膜反应器（MBBR） |
| **蛋白质分离** | 溶解有机物去除 | 蛋白质分离器（Foam Fractionator） |
| **曝气/增氧** | 提供溶氧 | 鼓风机、纯氧锥、纳米曝气管 |
| **消毒** | 病原杀灭 | 紫外线消毒器、臭氧发生器 |
| **温控** | 温度调节 | 热泵、冷凝器、加热棒 |
| **水质监测** | 在线监测 | 溶氧探头、pH探头、氨氮探头等IoT传感器 |

### 关键水质参数标准
| 参数 | 理想范围 | 说明 |
|------|----------|------|
| 溶氧（DO） | 5-8 mg/L | 不足时鱼会浮头 |
| 水温 | 22-30°C | 品种各异 |
| pH值 | 7.0-8.5 | 偏碱性 |
| 氨氮（NH3-N） | <0.1 mg/L | 毒性最强 |
| 亚硝酸盐（NO2-N） | <0.2 mg/L | 积累有毒性 |
| 硝酸盐（NO3-N） | <100 mg/L | 累积后需换水 |

## 二、主要养殖品种参数

### 品种对比总表
| 品种 | 水温(°C) | 盐度(ppt) | 溶氧(mg/L) | 氨氮上限 | 难度 |
|------|----------|-----------|------------|----------|------|
| 石斑鱼 | 24-26 | 30-33（海水） | 6-8 | <0.1 | 中等 |
| 鲈鱼 | 22-26 | 0-35（广盐） | 5-7 | <0.2 | 较低 |
| 鳜鱼 | 22-28 | 0-2（淡水） | 7-9 | <0.05 | 较高 |
| 南美白对虾 | 28-30 | 15-25 | 6-8 | <0.2 | 中等 |

### 各品种要点
- **石斑鱼**：海水，高价值，需蛋白质分离器+臭氧
- **鲈鱼**：广盐性，可淡水可海水，最易养
- **鳜鱼**：淡水，肉食性，需活饵料鱼配套，高溶氧要求
- **对虾**：需生物絮团技术，温控要求高

## 四、常用设备选型要点

### RAS设备3D模型库（15台，含FCStd/STEP/STL）

完整3D模型已生成并维护于 `~/Desktop/渔芯RAS设备图纸_v2/` 和 `6-产品研发/34-渔芯社区/parts_library/`。生成引擎：`yuxin_cad.py --batch ras`。

设备覆盖：滚筒微滤机、蛋白质分离器、MBBR生物滤器、微孔曝气器、UV杀菌器、热泵换热器、滴流滤池、纯氧锥、罗茨鼓风机、臭氧发生器、养殖水箱(2种)、循环水泵组、控制柜、管道汇流排总成。

每台模型包含：壳体+法兰接管+支腿/底座+内部结构。参数100%对齐本知识库。出图命令库：`prompts/drawing_commands_v2.json`（42条模板，含RAS P&ID/设备布置/管道单线图/水箱制造图）。

### 水泵
- 流量选型：养殖池容积 × 循环次数（通常6-10次/小时）
- 扬程：克服系统阻力（管道、滤料层等）

### 生物滤池
- 填料比表面积越大越好（MBBR常用Kaldnes载体）
- 容积负荷：0.5-2.0 kg NH3-N/m³/天

### 蛋白质分离器
- 根据养殖密度选型（通常1m³/d处理30-50kg鱼产量）
- 海水效果优于淡水

### 增氧设备
- 鼓风机：罗茨风机最常用，气量大、压力稳定
- 纯氧增氧：密度>50kg/m³时必须配置纯氧系统

## 七、2026-08-23 进化补充：行业扫描、JTBD/ODI与路线图验证

### 行业扫描的可复用发现
- **AI/IoT水质监控**：RAS产品应从“数据展示”升级为“预警→原因假设→动作建议→效果复盘”闭环；关键指标包括预警提前量、误报率和人工响应时间。
- **节能与热管理**：kWh/kg、换水率、纯氧利用率、曝气/热泵能耗应纳入设备选型与仿真结果，避免只看水质达标。
- **尾水资源化**：将尾水处理、液体肥料或营养回收视为潜在产品组合；先做技术可行性与合规边界验证，不把一次性研究结果直接当成成熟商业方案。
- **人才与交付规模**：RAS项目快速增长，设备设计、调试、运营经验应沉淀为参数库、仿真用例、故障诊断知识和验收模板。

### JTBD + ODI（Outcome-Driven Innovation）落地法
1. 为每个关键角色写一句情境化 JTBD，不以功能名词替代任务。
2. 记录工作完成度、重要性、当前满意度/替代方案。
3. 用“重要性 × 未完成度”排序机会，优先验证高重要性且完成度低的 P0。
4. 每个机会必须绑定基线、目标指标、样本、周期和成功阈值。
5. 用历史项目回放、单池时序数据或用户任务实验验证，不以页面完成或口头意向作为成功标准。

可复用参考：`references/jtbd-odi-ras-framework.md`。

### 1. Review on Litopenaeus vannamei RAS 技术综述 [10.1007/s10499-025-02303-2, Springer Aquacultural Engineering 2025-09]
- **来源**: https://link.springer.com/article/10.1007/s10499-025-02303-2
- **核心**: 南美白对虾(L. vannamei)是全球产量最高的虾种,RAS 工艺重点在循环水处理+固液分离+生物滤池硝化+增氧温控;**关键挑战是高能耗**——降低污染物去除与水环境优化的能耗是研究主旋律,新兴方向含 MBR(膜生物反应器)+ 微生物组调控
- **渔芯启示**:
  - **虾类 vs 鱼类水力设计差异**: 虾池底排污负荷高、悬浮固体浓度大 → 渔芯 AquaTech v2 应针对对虾单独调 MBBR 抗污负荷参数
  - 与 R617-1 Thiobacillus 罗非鱼实证互补(品种维度扩面): 罗非鱼=硫基自养案例, 对虾=综合工艺能耗优化案例
  - AquaSmart 模型库可加 **对虾专用 SOP** (Phase 1: 水质参数包; Phase 2: 底排污策略)

### 2. C/N 比调节对反硝化微生物群落的塑造 [PMC12530212, 2025-09]
- **来源**: https://pmc.ncbi.nlm.nih.gov/articles/PMC12530212/
- **核心**: 反硝化反应器中 **C/N 比是关键调控参数**;生物膜成熟后 C/N 波动对反硝化性能影响有限;**增加异养菌比例可提升对碳源类型的适应性**
- **工程意义**: 为 RAS 设计 **"鲁棒反硝化"** 反应器提供依据——不必苛求恒定 C/N,留异养菌冗余即可应对碳源波动
- **渔芯启示**:
  - AquaTech v2 后置反硝化模块可设计成 **"双区反应器"** — 内区 AOB/NOB(硝化,严格 C/N 不敏感)+ 外区异养反硝化(留冗余)
  - 与 R164 硫基自养 / R617-1 Thiobacillus 形成 **自养+异养双轨鲁棒脱氮** 方案,降低单点工艺失稳风险
  - EDAI 控制逻辑: 不要硬卡 C/N 阈值,改成"区间引导 + 异养菌丰度反馈"

### 3. 全尺度木屑生物反应器脱氮微生物群落 [DTU Orbit 10.1016/j.jenvman.2021.113728, 2021 + 持续被引 2025]
- **来源**: https://backend.orbit.dtu.dk/ws/portalfiles/portal/257656484/1_s2.0_S0301479721019149_main.pdf
- **核心**: 全尺度木屑生物反应器可有效去除 RAS 出水硝酸盐,微生物群落含 **细菌 + 真菌 + 硫酸盐还原菌** 协同;硝氮去除受 **水力停留时间(HRT)+ 温度** 显著影响;成本极低(<电凝聚的 1/10)
- **渔芯启示**:
  - **低成本 RAS 末端脱氮方案**: 木屑反应器已被欧洲鲑鱼场商业化采纳,渔芯可作为 **中小客户补强** 或 **农村/山区项目** 优先方案
  - 与 R276-3 biochar 过滤器概念类似但更省事: 木屑直接外购,无需热解工艺
  - AquaTech v2 选型表加 **"木屑反硝化模块"** — 触发场景: 客户预算敏感 / 用地宽松 / 已有林业废料资源
  - 风险点: 真菌+硫酸盐还原菌协同 → 需控制出水 H₂S(<0.05 mg/L 保护鱼)

## 1. 选址与场地评估

### 步骤

1. **地形勘察**：确认水源来源（河/湖/井/水库），测量 pH、氨氮、亚盐、重金属含量。
2. **水质初检**：取水样送检，关注总碱度、总硬度、铁、锰指标。
3. **土壤检测**：重点测 pH、重金属残留、有机质含量，判断是否适合挖塘或硬化改造。
4. **交通与电力评估**：饲料运输便捷性、增氧/水处理设备电力负荷（kW·h）。
5. **产出规划匹配**：根据目标品种（加州鲈/鳜鱼/草鱼/罗非等）反推所需水面/水体。

### 避坑

- 地下水盐碱地（pH>8.5）直接养淡水鱼会导致慢性碱中毒，死亡率 20~50%。
- 靠近农田的场地须确认上游是否有农药/化肥排入风险。
- 未测重金属就上鱼苗，养成后可能因药残无法出售。

### 验证

- 输出一份《选址评估表》：含水质数据、土壤数据、电力/交通评级、改造建议优先级（ABC 级）。
- 可用 `E:/公司项目资料/01_知识库/水产养殖/选址评估模板.md` 作参考。

## 2. 养殖方案设计

### 步骤

1. **品种筛选**：按水温适应范围、生长速度、市场价格、饵料系数（FCR）综合选品。
   - 高价值：加州鲈（塘头价 18~28 元/kg）、鳜鱼（50~80 元/kg）、黄颡鱼（20~35 元/kg）
   - 快出鱼：草鱼（FCR 1.4~1.8，4~6 个月出塘）、罗非鱼（FCR 1.2~1.5）
2. **密度规划**：根据溶解氧（DO）峰值和水处理能力反推。
   - 常规土塘：加州鲈 3000~5000 尾/亩（规格 50~100g/尾）
   - 循环水 RAS：加州鲈可达 15~25 kg/m3（标粗后分级）
3. **轮捕轮放**：设计分批出鱼节奏，避免集中上市压价。加州鲈分 3 批出鱼，每批间隔 30~45 天。
4. **混养模式**：可选底层鱼（鲫鱼/罗非）吃残饵，减少有机底泥积累。
5. **产量预估**：根据放养密度 × 成活率 × 出塘规格计算总产量和利润区间。

### 避坑

- 高密度不等于高利润：超密度养殖（>8000 尾/亩加州鲈）暴雨后极易翻塘。
- 忽视 FCR 差异：同品种不同厂家饲料 FCR 可差 0.3~0.5，直接影响饵料成本 2~4 元/kg。
- 单品种集中上市导致价格踩踏。

### 验证

- 输出一份《养殖方案设计书》：品种、密度、轮捕节奏、FCR 假设、利润测算表。

## 3. RAS 工程规划（循环水养殖系统）

### 步骤

1. **产能目标确认**：先确定设计产量（吨/年），反推日换水率。低换水 RAS 日换水 <5%，中换水 RAS 日换水 5~15%。
2. **工艺流程设计**（标准五段式）：
   养殖池 → 固液分离 → 微滤机/转鼓过滤 → 蛋白分离器（脱气）→ 生物滤池（硝化）→ 反硝化池（脱氮）→ 紫外/臭氧消毒 → 回水
3. **设备选型**（按养殖品种和水体）：
   - 微滤机：处理量 200~500 m3/h，选不锈钢 316L 材质。
   - 生物滤池：填料容积 = 日氨氮负荷 × 1.5 倍安全系数；常用 K1/K3 填料。
   - 蛋白分离器：气水比 1:3~1:5，适用于高有机物水体。
   - 增氧锥/纯氧曝气：目标溶氧 6~8 mg/L，纯氧供氧效率 >90%。
   - 温控设备：热泵/锅炉，按品种适温范围（加州鲈 18~28°C）选型。
4. **电力负荷估算**：列出所有设备 kW 数，计算日耗电量（元/kg 鱼成本中电费占比）。
5. **排污设计**：锅底排污 + 中央排污双保险，排污管径不小于 DN200。

### 避坑

- 生物滤池不养水就放鱼：硝化菌挂膜需要 21~30 天，提前准备熟化滤料。
- 气水比算错导致蛋白分离器失效：常见错误是按水泵流量选型而非实际曝气量。
- 忽视反硝化环节：高密度养殖总氮积累会导致亚盐爆表。

### 验证

- 输出一份《RAS 系统设计清单》：设备列表 + 规格参数 + 电力负荷 + 工艺流程图描述。
- 关键参数（水力停留时间 HRT、氨氮负荷、填料体积）需与养殖品种匹配。

## 4. 水质调控

### 步骤

1. **建立水质档案**：每日记录 DO、pH、氨氮（NH3-N）、亚盐（NO2-N）、总碱度（TA）、温度。
   - 关键指标警戒线（加州鲈）：
     - DO < 3 mg/L → 浮头/死亡
     - NH3-N > 0.5 mg/L → 慢性中毒
     - NO2-N > 0.3 mg/L → 亚盐中毒
     - pH < 6.5 或 > 9.0 → 应激
2. **日常调控手段**：
   - 增氧：叶轮增氧机（1.5 kW/亩）+ 底部微孔增氧，夜间至凌晨是关键时段。
   - 改底：每周用氧化型底改（过硫底安 200~300 g/亩）或生物底改（EM 菌）。
   - 调水：光合细菌/芽孢杆菌泼洒，降解有机质，每 7~10 天一次。
   - 补碱：高密度养殖定期泼小苏打（5~10 kg/亩）维持总碱度 >80 mg/L。
3. **应急预案**（氨氮/亚盐爆表）：
   - 第一步：停止投喂。
   - 第二步：大换水（换 30~50%），同时开足增氧。
   - 第三步：泼洒食盐（10~15 kg/亩）降低亚盐毒性。
   - 第四步：泼洒硫代硫酸钠（1~2 kg/亩）快速降氨氮。

### 避坑

- 阴雨天不开增氧机：气压低时 DO 降幅可达 2~3 mg/L/h，极易缺氧。
- 一次换水超过 50%：水质突变应激比氨氮中毒危害更大。
- 滥用消毒剂（漂白粉/生石灰）：杀藻后藻毒素释放，可能比氨氮更危险。

### 验证

- 输出一份《水质调控周报模板》：含 DO/pH/NH3-N/NO2-N 曲线图、调控措施记录。
- 可对接渔芯平台数据洞察模块自动绘制趋势图。

## 5. 投喂管理

### 步骤

1. **投喂量计算**：
   - 公式：日投喂量（kg）= 鱼体重（kg）× 投喂率（%）× 存塘量（尾）
   - 参考投喂率（加州鲈）：
     - 鱼苗期（<50g）：3~4%/天
     - 鱼种期（50~200g）：2~2.5%/天
     - 成鱼期（>200g）：1~1.5%/天
2. **分餐制**：每日 2~3 餐，早晚各一餐为主，高温季节（>32°C）改夜间投喂。
3. **减料判断**（以下情况须减料 30~50%）：
   - 氨氮 > 0.3 mg/L 或亚盐 > 0.2 mg/L
   - 水温骤变（24h 内 > 3°C）
   - 暴雨后 1~2 天
   - 鱼病爆发期
4. **饲料选择**：优先选膨化沉料（加州鲈）或浮料（草鱼/罗非），根据养殖模式选择。
5. **添加剂方案**：可拌料加 VC（200~500 mg/kg）、免疫多糖、保肝护肠产品。

### 避坑

- 高温季节按正常量投喂：水温 >32°C 时鱼体代谢加快但消化能力下降，剩饵腐败是氨氮主要来源。
- 忽视鱼体重抽样：未定期打样导致投喂量与实际存塘量偏差超过 20%。

### 验证

- 输出一份《投喂记录表》：日期、投喂量(kg)、水温、溶氧、减料原因、观察备注。

## 6. 疾病诊断与收鱼出塘

### 疾病诊断（常见病害分类）

| 病害类型 | 代表病症 | 主要诱因 | 常用处理 |
|----------|----------|----------|----------|
| 寄生虫 | 烂鳃、摩擦池壁、鳃丝发白 | 水质恶化/引入带虫苗 | 甲醛/阿维菌素泼洒 |
| 细菌性烂鳃/肠炎 | 肛门红肿、肠壁充血、腹水 | 投喂过量/底质恶化 | 内服恩诺沙星+外泼碘制剂 |
| 病毒病（虹彩病毒/弹状病毒） | 体表溃疡、鳃出血、突然死亡 | 苗种带毒/应激诱发 | 无特效药，以增氧+减少应激为主 |
| 真菌（水霉） | 体表棉絮状白毛 | 机械损伤/低温 | 亚甲基蓝/聚维酮碘 |
| 营养性肝病 | 肝脏发白/肿大、零星死亡 | 饲料氧化酸败/油脂超标 | 换料+保肝产品拌料 |

### 疾病诊断流程

1. **现场观察**：鱼体外观、鳃丝、肠道、肝脏、肾脏。
2. **水质快速检测**：DO、pH、氨氮、亚盐（优先排除非病原因素）。
3. **寄生虫检测**：取鳃丝/体表粘液镜检（10×4 倍镜）。
4. **用药原则**：先调水再用药；细菌病以内服为主、外泼为辅；病毒病无特效药，以维持水质+减少应激为核心。

### 收鱼出塘操作规范

1. **出塘前停食**：至少停食 1~2 天，减少运输应激和粪便污染。
2. **拉网规格**：根据鱼价走势选择出鱼规格（统货/分级），提前联系鱼中。
3. **运输前处理**：加州鲈/鳜鱼等高价值鱼建议运输前泼洒葡萄糖（2~3%）+ VC，抗应激。
4. **出塘后清塘消毒**：生石灰 75~100 kg/亩消毒，晒塘 7~14 天后重新进水。
5. **养殖档案归档**：记录本造产量、饲料用量、用药记录、利润分析。

### 避坑

- 鱼病用抗生素预防性投药：不仅无效，还会导致耐药菌产生。
- 病毒病期间大换水+用药：双重应激会加速死亡，正确做法是维持水质稳定、减少操作。
- 出塘前不停食：运输死亡率可从 <2% 升至 >10%。

### 验证

- 输出一份《鱼病诊断单》：症状描述→可能病原→处理方案→用药记录。
- 输出一份《出塘记录》：放苗日期、出塘日期、存活率、均重、总产量、饲料用量、FCR。

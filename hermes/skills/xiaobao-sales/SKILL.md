### Champion Energy 核心金句

> "**销售不是和公司做生意，是和'那个人'做生意。但那个人能不能帮你赢，要能量化。**"
> "一个 CES=0.72 的冠军 + 一个 Velocity Score=80 的项目 = 90% 赢面；
> 一个 CES=0.22 的内部人 + 同样的项目 = 10% 赢面，甚至更低（因为错配）。"

### CES 5 维速览

```
CES = (Cp × Ia × Ri × Sa × Lo) / 25

CES ≥ 0.75  → C5 真冠军     → 全力护盘，每周 1 通
CES ≥ 0.55  → C4 决策层副手 → 押注！全套 Buyer Enablement
CES ≥ 0.35  → C3 部门影响者 → 给 ROI 工具让他去说服
CES ≥ 0.20  → C2 个人兴趣者 → 给技术资料慢慢养
CES < 0.20  → C1 内部线人   → 给情报费，不押注
```

### 6 类典型错配（速查）

| 错配 | 后果 | 反模式动作 |
|------|------|-----------|
| 1 · 把 C2 当 C4 | 浪费 3-6 个月 | **3 周验证法** |
| 2 · 押 C5 但被挖角 | 关键人物流失 | **24h 诊断 + 72h 反转** |
| 3 · C4 决策但 Sa 低 | 合同卡壳 | **签约前 72h 老板见面** |
| 4 · 多点押注内斗 | 内部矛盾 | **单点押注原则** |
| 5 · C5 拍板但 Ri=0 | 预算卡死 | **预算前置** |
| 6 · Cp 高 Lo 低 | 脚踏多船 | **独家推荐协议** |

### 5. 内容+工具配对规则（CTA 兑现红线）

**触发场景**：脚本 CTA 写"评论区打 XX / 私信 XX 领资料"，但配套模板/检查表/对照表还没创建。

**踩坑记录**：8/3 早安档曾出现"承诺给模板但没附件"，客户私信过来发现发不出——损害可信度。

**强制规则**：

1. 脚本里所有 CTA（领资料/领自查卡/领对照表），**必须先创建对应空白模板文件**，再发布脚本。
2. 模板文件命名规范：`自媒体内容/YYYY-MM-DD_<主题>_<工具类型>.md`，例如：
   - `2026-08-03_RAS项目启动信号自查卡.md`
   - `2026-07-XX_<主题>_对照表.md`
   - `2026-08-XX_<主题>_决策树.md`
3. 发布前自检 3 项：
   - [ ] 模板文件存在且可下载/转发
   - [ ] 模板标注"用途 / 不代替什么 / 客户数据隐私要求"
   - [ ] 模板内容不引用任何未核实数字
4. 同一档产出物至少包含：脚本主体 + 配套工具 + 评论承接话术，三件一组。

### 6. "诚实 0 新增"内容公式（行业扫描无新闻时的标准动作）

**触发场景**：行业扫描完成，但本轮已核验的官方公开源 0 新增，或只有已覆盖过的旧事实。

**踩坑记录**：8/3 13:08 验证——AKVA/Nofitech/AquaMaof/通威过去 90 天官方页没有 08:35 档未覆盖的 RAS 新项目。如跳过不发，会失去日更节奏；如强行编"今天某厂又有大动作"，会被客户反驳。

**5 段式公式**：

1. **0-4 秒 钩子**：不报喜开场，明确说"本轮没查到能核实的 X 新大单"，定调诚实。例："今天这条不报喜。我这轮没查到能核实的 RAS 新大单，也不会拿旧新闻改个日期再发。"
2. **4-17 秒 主体·核验范围**：披露本轮已核验的官方源 + 范围限定语（"仅指本次已核验的公开官网，不代表全行业零项目"）。
3. **17-31 秒 转场·未来披露节点**：列出值得记的官方披露节点（AKVA 财报日 / Innovation Day / 政府征求意见截止日），并强调"到时候看它有没有披露 X，现在别猜"。
4. **31-49 秒 落点·客户自己的信号**：把镜头切回养殖现场——"项目该不该动，先看自己的记录：水质波动、尾水检测差距、旧设备清单、能不能先仿真/小模块验证"。把判断权交回给客户。
5. **49-62 秒 CTA**：配合内容+工具配对规则，发配套自查卡/对照表。

# 渔芯公司级架构盘点 + 战略重组方案(玉芬方法论)

> 本 skill 是 2026-08-03 当天 2 份大方案的**方法论提炼**。原始方案见 `~/hermes/ideas/` 下的 `2026-08-03_公司整体架构优化方案.md`(5 维度盘点)与 `2026-08-03_按三大核心重组方案.md`(三大核心重组)。

## 一、两类任务,两类输出

| 任务类型 | 触发词 | 输出 | 长度 |
|---|---|---|---|
| **A 类:5 维度现状盘点 + 局部优化** | "全面盘点"、"优化整体架构" | 5 维度现状打分表 + 17 项 P0/P1/P2 优化清单 | 9 章 ~10K tokens |
| **B 类:N 核心战略重组** | "三大核心"、"重新组织"、"按业务重组" | 3 核心 × 3 层组织矩阵 + 项目目录树 + agent 团队扩编 + RKR 切分 + 路线图 | 9 章 ~12K tokens |

**两类通常连续做**——A 摸清现状打分,B 给出战略重组路径(华哥 8/3 一天下两单的典型 pattern)。

## 四、盘点方法论(9 层架构)

A 类方案必须摸清的 9 层(华哥公司是 9 层,不是 5 层):

| # | 层 | 路径 | 健康度维度 |
|---|---|---|---|
| 1 | LLM Key | `~/.hermes/config.yaml` + `~/.hermes/profiles/*/.env` + `~/.arkcli/` | 单源化 / Token 预算 / Fallback 链 |
| 2 | LLM Gateway | port 18888 + custom_providers | Provider 矩阵 / 模型路由 |
| 3 | Hermes profile | `~/.hermes/profiles/<id>/` 8 个 | Skills / Memory / Cron / Scripts |
| 4 | Skills | `~/.hermes/profiles/<id>/skills/` 421 个 | 通用 vs 私有 / 重复率 |
| 5 | Cron | `~/.hermes/cron/jobs.json` 51 个 | 心跳重复 / 监控覆盖 / 决策 cron |
| 6 | RKR 平台 | `~/6-产品研发/01-RKR知识库/` 12GB | 文档库 / 中转站 / scanner / API |
| 7 | 文档库(3 层) | `~/rkr_staging/文档库/` 14GB | 归档层 / 工作空间 / 索引快照 |
| 8 | 项目目录 | `~/6-产品研发/` 28+ 个 58GB | 主项目 / 历史版本 / 空壳 / 共享 |
| 9 | 飞书云盘 + 任务派发 | 飞书云盘任务派发目录 | 跨 agent 协同 |

**摸清时间估算**:
- ls + du + grep 走一遍 → 5-8 分钟
- 关键文件 read(CLAUDE.md / AGENTS.md / team_overview.md)→ 3-5 分钟
- 交叉验证 + 缺口识别 → 2-3 分钟
- **总 10-15 分钟可完成 9 层摸底**

## 五、健康度打分标准

| 分数 | 含义 | 颜色 |
|---|---|---|
| 9-10 | 完备,无需调整 | 🟢🟢 |
| 7-8 | 主体 OK,局部优化 | 🟢 |
| 5-6 | 有缺口,需补 | 🟡 |
| 3-4 | 严重错配,需重组 | 🟠 |
| 0-2 | 不可用,需重做 | 🔴 |

**8/3 实战打分**:LLM 7 / Agent 8 / RKR 7 / 公司运营 5 / 项目开发 4

## 六、关键决策点(B 类方案必问华哥)

B 类重组方案必含 5 件华哥拍板事项(每件带"截止"日期),否则方案不可执行:

## 八、华哥 5 大决策模式(历史)

历史方案里华哥拍板的 5 种典型决策,玉芬下次可预判:

1. **"先摸家底"**(2026-08-03 上半段)→ A 类盘点先行
2. **"给三大核心战略"**(2026-08-03 下半段)→ B 类重组紧跟
3. **"轻点 vs 重做"**(5/9 比例)→ 7 成轻点局部优化,3 成重做
4. **"派单 vs 自己干"**(派给黑豆/小宝/老莫)→ 5 同事配对版块各自负责
5. **"等等看 vs 立刻动"**(P0/P1/P2 三级)→ P0 24h 内,P1 本月,P2 下季度

# 中国公司研究（4 件套 + 求职类任务模板）

老大 2026-06-12 起进入**求职阶段**——BOSS 直聘是中国公司研究的入口，本 skill 封装**4 信息源 + 求职类 3 步走 + 行业大盘 + 同类公司配对 + 飞书推送**的标准打法。

## 1. 4 信息源组合

| 源 | 用途 | URL 模板 |
|---|---|---|
| **BOSS 直聘** | 招聘需求 / 岗位 / 薪资 | `https://www.zhipin.com/web/geek/job?query={公司名}` |
| **爱企查/天眼查** | 法人 / 股东 / 失信 / 处罚 | `https://www.tianyancha.com/search?key={公司名}` |
| **头条搜索** | 公司新闻 / 行业评价 | `https://www.toutiao.com/search/?keyword={公司名}+{关键词}` |
| **百度搜索** | 百科 / 贴吧 / 问答 | `https://www.baidu.com/s?wd={公司名}+{关键词}` |

**抓取策略**：
- 头条 + Bing（带真实 UA）通常 200 OK
- BOSS 直聘 status 200 但 content 经常空（需登录态），用 `toutiao + tianyancha` 兜底
- 百度 403 频繁 → 头条优先

## 3. 求职类任务 3 步走模板（**无经验救星**）

老大说"我想做 X 但没经验" → **自动给 3 步走 + 5 周速成 + 面试高频问答**。

### 3 步走（路径）
1. **0-6 月**：助理/跟单员/运营（5-7K）— 入行 + 学基础
2. **6-12 月**：业务助理（7-9K）— 独立接小单
3. **1-2 年**：业务员（8-15K）— 独立开发客户

### 5 周速成
- W1：基础（B 站 3 小时） + 50 术语
- W2：产品（30 款车参数） + 新能源
- W3：英语场景（**300 句**询盘/报价/物流/售后）
- W4：跨境平台（阿里国际站注册）
- W5：投 20 家 + 面试

### 面试高频问题 + 参考答案
| 问题 | 答案要点 |
|---|---|
| 为什么选外贸 | 2025 出口 832 万辆全球第一，5-10 年黄金期 |
| 没经验怎么上手 | 5 周速成 + 助理岗 + 6 月转业务 |
| 优势是什么 | 学习快 + 抗压 + 适应出差 |
| 薪资期望 | 5-7K 能接受 + 3 月评估 + 6 月调薪 |
| 职业规划 | 3 年独立销售，5 年区域经理 |

### 4 条硬核建议
1. ✅ 先低门槛岗（跟单/助理/运营），**不要直接业务**
2. ✅ 边投边学（面试就是学习）
3. ✅ 先入行（3-5 年后才有议价权）
4. ✅ 学 100 句口语就够（**别等完美**）

## 9. Pitfalls

1. **BOSS 直聘 content 经常空**：需要登录态，不要试图深度 parse，**用头条搜 + 天眼查兜底**。
2. **百度 403 频繁**：用头条搜 + Bing（带真实 UA）替代。
3. **天眼查反爬严格**：通常只返回 200 OK 但内容是 JS 渲染后的 SPA，需要 Playwright 或 Selenium（不推荐）。
4. **公司注册资本≠实缴资本**：搜索结果只说注册资本，老大问"实际投了多少钱"要明示数据来源。
5. **"无经验" 不是劣势**：老大求职时**一定强调"无经验也能去"**，给低门槛岗（跟单/助理/运营）作为跳板，不要直接说"你不行"。
6. **汽车出海是 5-10 年黄金赛道**：行业背书一定带上"2025 出口 832 万辆全球第一"+"6 年 300 倍增长"等数字。
7. **飞书 home channel 是默认汇报渠道**：每跑完必推，**重点标"老大持仓 100% 入榜"或"老大可应聘"等老大关心点**。
8. **不要相信"未上市公司财务"**：未上市 = 财务数据不公开，投资评级永远给"中等"，建议"看 3 年财务 + 银行流水"。

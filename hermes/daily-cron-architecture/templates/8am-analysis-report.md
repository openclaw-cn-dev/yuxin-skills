## 填充说明

### 字段替换规则（8 处容易出错）

| 占位符 | 替换方法 | 实战值示例 |
|---|---|---|
| `{YYYY-MM-DD}` | 8 点 cron 触发当天的真实日期（**走 `date` 命令取真实日期，不要相信 prompt 里写的日期**） | `2026-06-15` |
| `{YYYYMMDD_HHMMSS}` | 同上，**紧凑格式**（用于文件名） | `20260615_080045` |
| `{N1} / {N2}` | 头条/搜狗抓取的**原始条数**（去重前） | `76 / 33` |
| `{N}` | 去重后的条数（统计脚本：去重正则 `\d+\\. (.+?)(\\.\\.\\.\\|$)`） | `85` |
| `{N 条}` | 当天统计**每种钩子模板的频次**（grep 抓取文本） | `4 条` |
| `{今日最强钩子}` | 二、钩子句表里频次最高的那行 | `"89 岁奶奶"` |
| `{新爆点 vs 老爆点}` | grep 昨天 `{昨日报告路径}` 的同样词 → 是否出现 | 出现 → 老爆点；未出现 → 新爆点 |
| `{session_id}` | `terminal(background=true, ...)` 返回的进程 ID | `proc_4a3f2f38def6` |

### ⚠️ 顺序铁律（**不要颠倒**）

1. **先去重** → 再统计字数/频率（去重后频率才有意义）
2. **填公式例子时** → 必须从当天**真实抓取**的标题里挑，不能套昨天的
3. **TOP 5 选题** → **不能直接复刻抓取标题**，要改造为本号 IP（"老渔民女儿"/"老黄海鲜"/"89 岁奶奶"）
4. **节奏规律字数区间** → 走 19-28 / ≤18 / >28 三档（不是 18-25 + 26-35 的旧 2 档）
